# 紫微斗数术语词典

> 术语库 + 与子平派对照。后续笔记如首次出现某术语，必须链接本词典。
> 不按 7 区块格式（本身是工具书）。

## A. 基础结构术语

| 术语 | 拼音 | 古文出处 / 含义 | 子平派对照 |
|---|---|---|---|
| **命盘** | mìng pán | 紫微术数推算的盘面，共 12 宫 | 八字四柱（不同形态） |
| **12 宫位** | shí'èr gōng wèi | 命 / 兄 / 夫妻 / 子女 / 财帛 / 疾厄 / 迁移 / 交友 / 官禄 / 田宅 / 福德 / 父母 | 子平靠十神涵盖六亲，无对应物 |
| **命宫** | mìng gōng | 本人主宫，由生月与生时定 | 日主 + 月令（功能近似） |
| **身宫** | shēn gōng | 后天发力点，叠加在 6 宫之一 | 子平无对应 |
| **大限** | dà xiàn | 10 年一限的大运 | 大运（直接对应） |
| **小限** | xiǎo xiàn | 流年的辅助看法（1 岁起算） | 小运（部分对应） |
| **流年** | liú nián | 按当年地支落宫 | 流年（直接对应） |
| **流月** | liú yuè | 按当月推算 | 流月（直接对应） |
| **流日 / 流时** | liú rì / liú shí | 精细推算单位 | 子平可推但不常用到流时 |
| **三方四正** | sān fāng sì zhèng | 本宫 + 对宫 + 三合二宫，共 4 宫联动 | 五行生克联动（功能近似但形态不同） |
| **对宫** | duì gōng | 命盘上正对面的宫，相隔 7 位 | 子平日主对宫（如甲对庚） |
| **三合** | sān hé | 本宫前后各 4 位的两宫 | 子平三合（地支三合，逻辑相通） |

## C. 辅星杂耀术语

### C.1 六吉（增辉）

| 术语 | 拼音 | 主要意义 |
|---|---|---|
| **左辅 / 右弼** | zuǒ fǔ / yòu bì | 辅佐之星，主助力、贵人、合作 |
| **文昌 / 文曲** | wén chāng / wén qū | 文星，主才华、学业、文书；昌主理科 / 曲主文科与口才 |
| **天魁 / 天钺** | tiān kuí / tiān yuè | 贵人星，主提携、机遇；魁主男贵人 / 钺主女贵人（古义，现代不严格） |

### C.2 禄存

| 术语 | 拼音 | 主要意义 |
|---|---|---|
| **禄存** | lù cún | 财禄之星，主积蓄、稳定收入；与化禄不同（禄存是常驻星，化禄是动态化气） |

### C.3 六煞（减辉 / 激变）

| 术语 | 拼音 | 主要意义 |
|---|---|---|
| **火星 / 铃星** | huǒ xīng / líng xīng | 暴烈性煞星，主突发、冲突、急躁；与贪狼同宫成"火贪 / 铃贪格"反凶为吉 |
| **擎羊 / 陀罗**（也作"羊刃 / 陀罗") | qíng yáng / tuó luó | 刑伤之煞，主刑罚、损伤、磨难；擎羊外伤 / 陀罗内伤拖延 |
| **地空 / 地劫** | dì kōng / dì jié | 空亡之煞，主破耗、虚无、思想超脱；地空内空 / 地劫外劫 |

### C.4 四化（化曜，动态变量）

| 术语 | 拼音 | 主要意义 |
|---|---|---|
| **化禄** | huà lù | 增益、贵气、财利、缘分 |
| **化权** | huà quán | 强化、权力、主导、争胜 |
| **化科** | huà kē | 名声、学业、贵人、缓和 |
| **化忌** | huà jì | 阻滞、是非、损耗、执念 |

（详见 [02-动态系统/四化-禄权科忌.md](../02-动态系统/四化-禄权科忌.md)）

### C.5 杂耀（修饰性，谨慎使用）

| 术语 | 主要意义 | 项目立场 |
|---|---|---|
| **天马** | 驿马，主迁动、外出、行业流动 | 中性，常用 |
| **天刑** | 刑罚、医术、法律，主自律 | 中性 |
| **天姚** | 桃花、应酬，主人际魅力 | 中性，不与"咸池"混 |
| **红鸾 / 天喜** | 婚喜之星 | 仅作修饰，不单独定婚期 |
| **孤辰 / 寡宿** | 孤独感受 | 仅作修饰，反对"必孤"断法 |
| **华盖** | 孤高、宗教、艺术倾向 | 中性，反对"必出家"断法 |
| **咸池 / 沐浴** | 古义桃花 | **反对单独以咸池论邪淫** |
| **天空** | 空亡、超脱 | 中性 |
| **截空 / 旬空** | 时间性空亡 | 修饰，不独断 |

## D. 排盘与五行术语

| 术语 | 拼音 | 含义 |
|---|---|---|
| **五行局** | wǔ xíng jú | 命主所属局，分水二局、木三局、金四局、土五局、火六局；决定大限起岁和紫微落宫 |
| **水二局** | shuǐ èr jú | 大限 2-11 岁起 |
| **木三局** | mù sān jú | 大限 3-12 岁起 |
| **金四局** | jīn sì jú | 大限 4-13 岁起 |
| **土五局** | tǔ wǔ jú | 大限 5-14 岁起 |
| **火六局** | huǒ liù jú | 大限 6-15 岁起 |
| **庙旺利平闲陷** | miào wàng lì píng xián xiàn | 星曜在不同地支宫位的强度等级（6 级）；庙旺为强，闲陷为弱 |
| **五虎遁** | wǔ hǔ dùn | 由生年天干推月令天干的口诀，"甲己之年丙作首…" |
| **真太阳时** | zhēn tài yáng shí | 出生地实际太阳时间，校正后用于排盘；公式 = 钟表时间 ± 经度时差 ± 均时差 |
| **均时差** | jūn shí chā | 因地球公转椭圆性导致的太阳时偏差，约 ±16 分钟内浮动 |

## F. 与子平派的术语对照（横向桥）

| 紫微术语 | 子平派近义术语 | 关键差异 |
|---|---|---|
| 命宫主星 | 日主 + 月令格 | 紫微以星情画像，子平以五行能量结构 |
| 三方四正 | 五行生克 + 神煞会照 | 紫微"位"联动，子平"气"流通 |
| 大限 | 大运 | 直接对应（10 年） |
| 化忌 | 七杀 / 伤官（破格因子） | 都是"破"，但作用机制不同 |
| 格局（紫府同宫等） | 格局（正格 / 变格） | 概念同源，具体内容不重叠 |
| 12 宫细分 | （无对应） | 子平六亲事业用十神涵盖，颗粒粗 |
| 真太阳时校正 | 真太阳时校正 | 两派都要校正，紫微对错时辰更敏感 |
| 五行局（水二木三…） | （无对应） | 紫微专有 |
| 庙旺利平闲陷 | 旺相休囚死 | 概念近，紫微更细分 6 级 |
| 化禄化权化科 | 食神 / 比劫 / 印星（部分对应） | 不完全对应，桥接时要小心 |

**桥接规则**：
1. 概念可以横向对照（如大限 ↔ 大运），但**结论必须各跑各的**
2. 同一命主用两套独立分析 → 最后**对照结论**而非"用紫微验证子平"或反之
3. 写笔记禁止"日主辛金 + 破军坐命"这种混血表达
