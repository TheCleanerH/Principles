# 紫微斗数流派立场

> 锚定文件。后续任何笔记的"流派分歧"区块，必须显式引用本文件的分类。
> 本笔记不按 7 区块格式（它本身就是元规则）。

## 1. 流派全景图

```
紫微斗数
├─ 古典源流
│   ├─ 三合派传统（《紫微斗数全书》《紫微斗数全集》体系，张果老—陈希夷—罗洪先）
│   └─ 十八飞星派源流（《十八飞星策天紫微斗数全集》）
├─ 现代主要流派
│   ├─ 中州派（王亭之 / 陆斌兆延续）              ← 本项目主线
│   ├─ 钦天四化派 / 飞星派（梁若瑜 / 蔡明宏 等）   ← 本项目辅线
│   ├─ 透天派（吴明修 等，强调四化飞星）
│   ├─ 河洛派（楚皇 等）
│   ├─ 占验派 / 紫云派（紫云：三十六岁前后论）     ← 现代参考
│   ├─ 慧心斋主（女命专论）                       ← 现代参考
│   └─ 现代综合派（陆斌兆：八字嫁接紫微）         ← 现代参考
└─ 民间杂派
    └─ 神煞决贵贱 / 童子煞改运 / 桃花咸池论邪淫    ← 反对
```

## 2. 主线 vs 辅线 vs 反对（操作守则）

### 主线 — 默认结论来源

| 流派 | 核心方法 | 关键人物 / 著作 |
|---|---|---|
| **中州派** | 重 14 主星本质、三方四正联动、本命四化为主、反过度神煞 | 王亭之《中州派紫微斗数讲义》《紫微斗数初级讲义》《斗数详批》 |
| **三合派传统** | 经典三合四正 + 格局论 + 古籍诗赋断诀 | 《紫微斗数全书》（陈希夷传 / 罗洪先编） |

**写笔记时**：如果一条结论同时见于中州派和三合派传统，不需要特别标注（默认即此）。

### 辅线 — 必须显式标注

| 流派 | 核心方法 | 关键人物 |
|---|---|---|
| **飞星派 / 钦天四化派** | 四化飞星互冲互应、宫位之间四化串联看人生剧情 | 梁若瑜《飞星紫微斗数》、蔡明宏 |
| **透天派** | 强调四化飞星 + 自创"自化"概念 | 吴明修 |
| **十八飞星派** | 古典源流，明清后影响减弱 | 《十八飞星策天紫微斗数全集》 |

**写笔记时**：任何引用必须前缀 "飞星派认为…" 或 "透天派认为…"，且与中州派结论并列呈现，不混入主线段落。

### 现代参考 — 标注作者

| 学者 | 贡献 / 立场 |
|---|---|
| 紫云 | 三十六岁前后论：36 岁前主参考父母宫，36 岁后主看夫妻宫 / 福德宫 |
| 慧心斋主 | 女命独立论，反对"以夫为天"式断法 |
| 陆斌兆 | 八字嫁接紫微 — 用日干判断喜忌，再对照紫微星情 |
| 了无居士 | 现代化、白话化解释 |

**写笔记时**：引用必须明示作者，如 "紫云在《紫微斗数看人生》提出…"。

### 反对 — 永不输出

| 类型 | 反对理由 |
|---|---|
| 神煞决贵贱 | 把咸池、华盖、孤辰寡宿等杂耀单独拿出来下结论，违背三方四正联动原则 |
| 命定论 | 把"X 命就是 X"作为定论，否定后天调整空间，违背"运" "命主" 双层模型 |
| 童子煞改运 | 民间巫俗化输入，与紫微古典体系无关 |
| 报具体财富数字 | "百万""千万"是预言而非结构性判断，违背命理框架边界 |
| 桃花咸池论邪淫 | 性别歧视残留，慧心斋主已批驳 |
| 混入子平派术语 | 两套语言独立，混说会模糊判断来源 |

## 3. 中州派 vs 飞星派的关键分歧（笔记中最常踩雷区）

| 议题 | 中州派立场 | 飞星派立场 | 笔记中如何处理 |
|---|---|---|---|
| **四化重要性** | 本命四化为主，其他次之 | 四化全盘飞动是核心方法，本命只是起点 | 主述中州派，独立段落讲飞星派飞法 |
| **自化** | 不强调"自化"概念 | "自化"是核心（宫位自身天干引发四化飞回本宫） | 飞星派四化补充.md 单独讲 |
| **杂耀（如咸池红鸾天姚）** | 谨慎对待，重星情而非定贵贱 | 飞星派也谨慎，但更重"四化触发杂耀" | 主述中州派立场，谨慎中性化 |
| **十干四化版本** | 以《全书》《全集》主流版本为准（戊干化科 = 右弼） | 飞星派部分分支主张戊干化科 = 太阳 / 太阴 / 弼 | 列多版本，标流派归属 |
| **看盘起手宫** | 命宫为主，三方四正联动 | 命宫 + 飞星轨迹，看四化跨宫流动 | 主述中州派看盘流程 |
| **应期推法** | 大限 → 流年 → 流月（由粗到细） | 大限 + 流年 + 飞星触发，更细但更易过度解读 | 应期推法.md 主述中州派，对照飞星派 |

## 4. 我的引用纪律（自我约束）

写任何笔记时：

1. **每个结论标流派**：除主线默认外，飞星派 / 现代学者必须前缀说明
2. **古籍引用必引原文**：不允许"《全书》大意是…"这种二手转述
3. **古文存疑标"待考"**：对原文版本不确定时，注明并保留多版本
4. **杂耀不下死断**：杂耀只作辅助修饰，不作单独结论支撑
5. **数字预言绝不出**：永远不报具体的金额、年龄、人数
6. **结构性概率给区间**：60-75%、40-55%，并注"这是结构性而非实证概率"

## 5. 给命主的一句校准

> 当你听到 Claude 说"紫微在 X 宫主 Y"时，你应该问的不是"是不是真的"，而是 **"这是哪一派说的？反方怎么说？古籍原文怎么说？"** 三问之后再判断。
