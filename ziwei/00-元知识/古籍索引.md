## 4. 资源获取优先级

1. **ctext.org** — 中国哲学书电子化计划，古籍主要来源，相对稳定
2. **维基文库** — wikisource 中文，部分版本可查
3. **个人博客 / 紫微论坛** — 20-40% 链接会失效，仅作交叉验证用
4. **PDF / 实体书** — 现代著作主要靠 PDF；放在 `资料/` 目录归档

## 5. 引用规范（强制）

每篇笔记的"古籍出处"区块必须：

1. **引原文**：1-3 句完整原文，不允许"《全书》大意是…"式转述
2. **标篇目**：精确到卷 / 篇，如 "《紫微斗数全书·卷二·诸星问答论·紫微篇》"
3. **标版本疑**：如原文不同版本有差异，列两版并注 "（**待考版本**）"
4. **附 URL + 访问日期**：URL 来自上述优先级，访问日期写"2026-XX-XX"
5. **古文 + 白话**：原文后附一句白话翻译，并标注"白话翻译为笔者所加"

### 引用示例

> **古籍出处**
> 
> 《紫微斗数全书·卷二·诸星问答论·紫微篇》：
> > 紫微，乃中天斗数之主，为众星之枢纽，为造化之枢机，行藏举止，皆为依之而定。
> 
> 白话翻译（笔者所加）：紫微星是斗数体系的核心，地位类比皇帝，其他星都围绕它定位。
> 
> URL：https://ctext.org/wiki.pl?if=gb&res=857569 — 访问 2026-05-27
> 待考：本句在《全集》中为"乃中天星主"，"斗数之主"为《全书》版（**待核**）
