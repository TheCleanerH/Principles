# 紫微 14 步精读法（Capstone）

> 本文件是整合 W1 + W2 + W3 所有笔记的**看盘流程总结**。
> 给定任何一个命主，按本流程从头到尾走一遍。
> 14 步对应 14 主星 — 是一种意象，不是 14 主星与 14 步——对应。

## Step 1：真太阳时校正

**目的**：紫微对时辰极敏感，错一个时辰整盘飞走。

**步骤**：
1. 拿到命主**出生地经度**（精确到县 / 区）
2. 计算**经度时差** = (出生地经度 - 时区中心经度) × 4 分钟
3. 查**均时差**（按生日，±16 分钟内）
4. **夏令时调整**（如出生于中国 1986-1991 年 5-9 月或韩国 1948-1988 间断期）
5. 真太阳时 = 钟表时间 + 经度时差 + 均时差 - 夏令时

**临界生时处理**：如真太阳时落在两个时辰边界 5 分钟内 → **两个时辰都排盘**，对照命主已知人生事件确定哪个更合。

参考：[01-基础结构/排盘原理.md](../01-基础结构/排盘原理.md)

---

## Step 2：排盘（命宫 + 五行局 + 大限）

**目的**：建立命盘的核心坐标系。

**步骤**：
1. 定**命宫**地支（"寅起正月顺数生月、起子时逆数生时"）
2. 定**身宫**地支（由生年地支决定，叠加在 6 宫之一）
3. 用**五虎遁**推命宫天干
4. 用**纳音五行**定**五行局**（水二 / 木三 / 金四 / 土五 / 火六）
5. 起**大限**（按五行局确定起始岁 + 男阳女阴顺逆）
6. 定 12 宫地支位 + 12 宫天干

参考：[01-基础结构/排盘原理.md](../01-基础结构/排盘原理.md)

---

## Step 3：安 14 主星

**目的**：填充命盘的"主语"。

**步骤**：
1. 用**起紫微星表**（按五行局 + 生日）定紫微落宫
2. 紫微定后，**紫微系顺布**（紫微 → 隔 N 宫安天机 / 太阳 / 武曲 / 天同 / 廉贞）
3. 由紫微宫推**天府宫**（按对称关系）
4. **天府系顺布**（天府 → 紧邻安太阴 / 隔 2 宫安贪狼 / 隔 3 宫安巨门 / 隔 4 宫安天相 / 隔 5 宫安天梁 / 隔 6 宫安七杀 / 隔 10 宫安破军）

完成后 14 主星全部就位。

参考：[01-基础结构/排盘原理.md](../01-基础结构/排盘原理.md) + 各 [14主星/X.md](../01-基础结构/14主星/)

## Step 4：安辅星杂耀

**目的**：填充修饰性变量。

**步骤**：
1. 安**六吉**：左辅、右弼（生月）/ 文昌、文曲（生时）/ 天魁、天钺（生年干）
2. 安**禄存**（生年干）+ **擎羊陀罗**（禄存前后）
3. 安**火星铃星**（生年支 + 生时）
4. 安**地空地劫**（生时）
5. 安**杂耀**（天马 / 天刑 / 天姚 / 红鸾天喜 / 孤辰寡宿 / 华盖 / 咸池 / 解神 / 三台八座 / 恩光天贵 等）

参考：[01-基础结构/辅星杂耀.md](../01-基础结构/辅星杂耀.md)

## Step 5：安四化（本命）

**目的**：定本命动态变量。

**步骤**：
1. 看**生年天干** → 查**十干四化表**
2. 飞 4 颗化曜（化禄 / 化权 / 化科 / 化忌）附在 4 颗主星 / 辅星上
3. **流派校验**：戊 / 庚 / 壬 干的化科 / 化忌取**中州派主流版本**（戊化右弼 / 庚化太阴 / 壬化左辅 / 庚忌天同）

参考：[02-动态系统/四化-禄权科忌.md](../02-动态系统/四化-禄权科忌.md)

## Step 6：命宫主星 + 三方四正（命三方）

**目的**：定命主的核心人格 + 一生大方向。

**步骤**：
1. 看**命宫主星**：哪些 14 主星 / 辅星驻命宫？
2. 看**对宫（迁移宫）**主星
3. 看**三合宫 1（财帛）**主星
4. 看**三合宫 2（官禄）**主星
5. **联动判读**：命三方 = 命 + 迁 + 财 + 官，四宫共同决定人生主干
6. **命无正曜**：如命宫无 14 主星，借对宫看
7. 看**辅星 / 煞星**对命三方的影响（左右昌曲魁钺 → 助力；火铃陀羊空劫 → 减辉）
8. 看**化禄 / 化忌**在命三方的位置

参考：[01-基础结构/12宫位.md](../01-基础结构/12宫位.md) + [02-动态系统/三方四正与对宫.md](../02-动态系统/三方四正与对宫.md)

## Step 7：身宫位置

**目的**：定后天发力点。

**步骤**：
1. 看**身宫**叠加在哪个 6 宫之一（命 / 夫妻 / 财帛 / 迁移 / 官禄 / 福德）

## Step 8：格局识别

**目的**：识别命格类型 → 决定判读侧重。

**步骤**：扫描以下 8 大格局是否成立：

| 格局 | 关键判断 |
|---|---|
| **紫府同宫** | 紫微 + 天府同坐命宫（仅寅 / 申） |
| **杀破狼** | 七杀 / 破军 / 贪狼分坐命三方 |
| **机月同梁** | 天机 / 太阴 / 天同 / 天梁分坐命三方 |
| **君臣庆会** | 紫微 + 左右昌曲魁钺多星会聚 |
| **日月并明** | 太阳 + 太阴同庙旺会照 |
| **火贪 / 铃贪** | 贪狼 + 火星 / 铃星同宫且庙旺 |
| **刑忌夹印** | 天相被擎羊 + 化忌夹击 |
| **马头带剑** | 天马 + 擎羊会照 |

**判断**：
- 主格成立 + 辅星辅佐 → 命格高
- 主格成立 + 破格 → 名实不符 / 早发晚衰
- 多格叠加（如紫府同宫 + 君臣庆会 + 火贪格）→ 极顶级
- 无主格 → 普通命格

参考：[03-格局应期/格局/](../03-格局应期/格局/)

## Step 9：六亲宫（夫妻 / 父母 / 子女 / 兄弟）

**目的**：看命主与各类亲属的关系倾向。

**步骤**：

### 9a. 夫妻宫
- 主星 + 三方四正
- 化曜（化禄好 / 化忌警惕）
- 男女命差异（用慧心斋主立场）
- 反对死断"克夫 / 克妻"

### 9b. 父母宫
- 主星 + 三方四正
- 化曜
- 紫云"36 岁前看父母塑造"
- 反对死断"父早逝"

### 9c. 子女宫
- 主星 + 三方四正
- 化曜
- **现代延伸**：创造性输出 / 创业作品也归此宫看
- 反对死断"无子"

### 9d. 兄弟宫
- 主星 + 三方四正
- **现代延伸**：合伙人、合作伙伴

## Step 10：疾厄宫（健康）

**目的**：看命主健康倾向。

**步骤**：
1. 主星 + 三方四正
2. 关键主星对应身体部位：
   - 紫微：头 / 心血管
   - 武曲：呼吸道 / 牙齿 / 金属外伤
   - 廉贞：心脏 / 血光 / 妇科 / 性病
   - 巨门：口腔 / 食道 / 胃
   - 太阴：生殖 / 泌尿 / 内分泌
   - 太阳：心血管 / 眼睛 / 头部
   - 天梁：脾胃 / 长寿 / 慢性病
3. 化忌触发应期
4. 煞星会照（火铃陀羊 → 外伤；空劫 → 慢性）

**严格立场**：紫微疾厄宫给出"倾向" + "风险点"，**不是医学诊断**。任何身体不适应**先就医**。

## Step 11：官禄 / 财帛 / 福德

**目的**：看事业 + 财富 + 精神福分。

### 11a. 官禄宫（事业）
- 主星 → 适合行业
- 三方四正 = 官三方（官 + 夫 + 命 + 财）
- 化禄 / 化权 / 化忌
- 大限 / 流年的事业触发点

### 11b. 财帛宫（钱）
- 主星 → 财源类型
- 三方四正 = 财三方（财 + 福 + 命 + 官）
- 化禄好 / 化忌警惕
- 不报具体金额

### 11c. 福德宫（精神）
- 主星 → 内心驱动
- **慧心斋主：女命福德特别重要**
- 福德好 → 心安自得；福德差 → 富贵也心烦

## Step 14：综合结论 + 反神秘化校验

**目的**：把 Step 1-13 的结果整合成可执行的结论 + 自我校验。

**结论部分**：
1. **命格类型**：高 / 中 / 低（结构性）+ 主要格局
2. **大方向**：适合什么职业 / 人生路径
3. **关键风险**：哪些大限 / 流年要警惕
4. **关键机遇**：哪些大限 / 流年是窗口期
5. **六亲关系**：夫妻 / 父母 / 子女 / 兄弟的主要倾向
6. **健康**：主要风险点 + 体检建议（**非诊断**）
7. **诚实概率区间**：每个判断给 X-Y% 区间，标"结构性"

**反神秘化校验**：
- ❌ 是否报了具体金额（"百万千万"）？应删
- ❌ 是否单凭神煞下结论？应改三方四正联动
- ❌ 是否说"必然 X"？应改为"X-Y% 倾向"
- ❌ 是否混入子平派术语？应分开
- ❌ 是否用了童子煞 / 桃花咸池论邪淫 / 命定论？应删
- ❌ 是否引飞星派结论冒充中州派？应显式标注
- ✅ 古籍原文是否引了 + 篇目 + 链接？应有
- ✅ 流派分歧是否标注？应有
- ✅ 结论是否带"结构性而非实证"提醒？应有

参考：[00-元知识/流派立场.md](./流派立场.md)
