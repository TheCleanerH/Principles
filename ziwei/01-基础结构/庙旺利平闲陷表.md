# 庙旺利平闲陷表 · 14 主星 × 12 地支

> 紫微斗数的"星曜强度等级"表。
> 同一颗主星在不同地支宫位**强度不同**，影响判读权重。
> 本表按中州派 + 三合派传统主流版本编制（**部分细节有流派差异，标"待考"**）。

## 等级定义

| 等级 | 别称 | 强度 | 判读 |
|---|---|---|---|
| **庙** | 入庙 / 庙旺 | ★★★★★ | 主星全功能发挥，主吉 |
| **旺** | 旺地 | ★★★★ | 主星功能良好，主吉 |
| **利** | 得利 / 得地 | ★★★ | 主星中等发挥，中性 |
| **平** | 平地 | ★★ | 主星功能减弱，平淡 |
| **闲** | 不得地 | ★ | 主星功能弱，主小凶 |
| **陷** | 落陷 | ☆ | 主星功能极弱 / 易主凶 |

**实用判读**：
- 庙旺：星情完全发挥（吉则大吉 / 凶则需配煞才显凶）
- 闲陷：星情大打折扣（吉则小吉甚至无吉 / 凶则大凶）

## 重点解读

### 紫微：处处吉
- 庙：丑、寅、午、未、申
- 闲：辰、戌
- 紫微**没有真正的"陷"** — 帝星本性使然
- 最佳：午宫（"紫微居午"为最贵之一）

### 太阳：午最旺，陷在西方
- 庙：午
- 旺：寅、卯、辰、巳
- 陷：戌、亥
- 太阳"日出于东 / 中天于午 / 西沉戌亥"的天文意象

### 太阴：亥子最旺，陷在东方
- 庙：子、亥
- 旺：戌、酉
- 陷：寅、卯、辰、巳、午
- 太阴"月升于西 / 中天于子亥 / 落于东方"的天文意象
- **重要**：太阴庙旺陷与太阳**完全相反**（日月之对）

### 武曲：四墓宫（辰戌丑未）最旺
- 庙：丑、辰、戌、未
- 武曲为金，土生金 → 四墓土宫旺
- 闲：寅、申（木气克金）

### 廉贞：寅申最旺
- 庙：寅、申
- 廉贞 + 太阳 / 巨门在寅申最旺（巨日格的基础）

### 天府：处处稳定
- 庙：子、丑、寅、辰、午、未、戌
- 天府是"库"，处处可藏 — 强度高度稳定
- **天府没有"陷"** — 与紫微类似

### 贪狼：四墓宫最旺
- 庙：丑、辰、未、戌
- 贪狼 + 四墓 → 火贪 / 铃贪格的最佳地支基础
- 陷：巳、亥（贪狼陷地 + 廉贞同宫 = 双桃花格）

### 巨门：寅卯申酉最旺，辰戌丑未陷
- 庙：寅、卯、申、酉
- 陷：丑、未、辰、戌
- **巨门 + 太阳在寅 / 申** = 巨日格（最旺位）

### 天相：处处稳定
- 庙：子、丑、寅、辰、午、未、申、戌
- 与天府类似，强度高度稳定

### 天梁：庙旺最多
- 庙：子、寅、卯、辰、戌
- 旺：丑、午、未
- 闲：巳、申、酉、亥
- 天梁主长寿 / 庇荫，处处主稳

### 七杀：庙位多
- 庙：寅、辰、申、戌
- 旺：子、午
- 七杀是"将星"，处处有威

### 破军：子午最旺
- 庙：子、午
- 旺：丑、辰、戌、未
- 破军在子 / 午"无煞凑，官资清显"

## 双主星组合的"加权"

当两主星同宫时，强度按**两星各自的庙旺陷**加权：

| 组合 | 加权方式 |
|---|---|
| 两星都庙旺 | 双倍强 → 大格局 |
| 一庙一陷 | 中等，看谁是主导 |
| 两星都陷 | 弱 → 难成大格 |
| 一旺一闲 | 中等偏弱 |

例：紫府同宫**在寅**
- 紫微在寅：庙
- 天府在寅：庙
- **双庙叠加** → 顶级紫府同宫格

例：紫府同宫**在申**
- 紫微在申：庙
- 天府在申：旺
- 庙 + 旺 → 上格但略低于寅宫紫府

## 庙旺陷与"格局成立"的关系

**主格局成立**的隐含要求是**主星在庙旺**：

| 格局 | 庙旺要求 |
|---|---|
| 紫府同宫 | 紫府都庙旺（在寅 / 申满足） |
| 君臣庆会 | 紫微庙旺 + 辅星齐 |
| 杀破狼 | 七杀破军贪狼至少一颗庙旺 |
| 机月同梁 | 四星中至少 2-3 颗庙旺 |
| 日月并明 | 太阳 + 太阴都庙旺 |
| 火贪 / 铃贪 | 贪狼庙旺 + 火 / 铃庙旺（四墓宫最佳） |
| 阳梁昌禄 | 太阳 + 天梁都庙旺 + 文昌庙旺 |

**陷地破格**：
- 紫微陷地 + 君臣庆会 = 君臣失序
- 太阳陷地 + 日月并明 = 日月反背（半破）
- 贪狼陷地 + 火 / 铃 = 暴而无功
