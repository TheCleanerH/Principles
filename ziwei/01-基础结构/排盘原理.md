# 排盘原理

## 1. 核心定义

**排盘**（pái pán）：根据命主的真太阳时出生年月日时，按既定算法在 12 宫盘面上安立紫微、天府等 14 主星，以及辅星杂耀和四化的过程。

紫微斗数排盘有**严格的算法路径**，与子平派不同：
- 子平派输入"年月日时"四柱 → 直接得 8 个干支
- 紫微斗数输入"年月日时" → 先定**五行局** → 再起**紫微星** → 顺安天府系 → 再安辅星 / 杂耀 / 四化

紫微对**时辰**极敏感：错一个时辰，命宫和身宫整盘飞走，整张盘判读完全错位。

排盘的**核心步骤**（5 步）：
1. 真太阳时校正（必须先做）
2. 定 12 宫地支位 + 命宫
3. 定五行局
4. 起紫微星 + 安 14 主星
5. 安辅星杂耀 + 四化

现代实务：**用程序排盘**（电脑紫微 / 紫微大师 / Astrolog 等），但命主必须**理解每一步的逻辑**，否则无法核验结果是否正确。本笔记重在原理。

## 2. 古籍出处

### 2.1 起紫微星诀（《紫微斗数全书·卷一·安星诀》）

> **起紫微诀**：
> > 六五四三二，酉午亥辰丑；
> > 局数除日数，商数宫前走；
> > 若见数无余，便要起虎口；
> > 寄生时顺数，宫宫不离丑。

白话翻译（笔者所加）：以五行局数（水二 / 木三 / 金四 / 土五 / 火六）作除数除生日数，按既定表格定紫微落宫。

（**待考**：上述歌诀有多个版本，《全书》《全集》文字略有差异）

### 2.2 12 宫定位诀

> 《紫微斗数全书·卷一·安命宫诀》：
> > **正月起寅顺数**至生月止，**再从该宫起子时**，**逆数**至生时止，安命宫。

白话翻译（笔者所加）：先在地支盘上从寅位顺数到生月所在地支，再从该地支起子时逆数到生时所在地支，该地支即命宫。

## 3. 现代解释

### 3.1 第一步：真太阳时校正

中州派 / 三合派 / 飞星派**一致要求**真太阳时（无分歧）。

公式：

```
真太阳时 = 钟表时间
         + 经度时差（出生地经度 - 时区中心经度）× 4 分钟
         + 均时差（按出生日期查表，±16 分钟内）
         - 夏令时调整（如适用）
```

**中国大陆**（北京时间，时区中心东经 120°）：

| 出生地 | 经度（约） | 经度时差 |
|---|---|---|
| 哈尔滨 | 东经 126.6° | +26 分钟（晚于 BJT） |
| 北京 | 东经 116.4° | -14 分钟（早于 BJT） |
| 上海 | 东经 121.5° | +6 分钟 |
| 广州 | 东经 113.3° | -27 分钟 |
| 乌鲁木齐 | 东经 87.6° | -130 分钟 |
| 拉萨 | 东经 91.1° | -116 分钟 |

**韩国**（首尔标准时，时区中心东经 135°）：

| 出生地 | 经度（约） | 经度时差 |
|---|---|---|
| 首尔 | 东经 127° | -32 分钟（早于 KST） |
| 釜山 | 东经 129° | -24 分钟 |
| 大邱 | 东经 128.6° | -25.6 分钟 |

**夏令时**：中国大陆 1986-1991 年实施过夏令时（5-9 月），韩国 1948-1988 间断实施过。命主若在该期间出生，须减去 1 小时。

均时差：以"出生日期查表"为准，举例：
- 春分秋分附近：约 -7 ～ -10 分钟
- 夏至冬至附近：约 +1 ～ +4 分钟
- 2 月中旬：约 -14 分钟（最低点）
- 11 月上旬：约 +16 分钟（最高点）

**临界生时处理**：如真太阳时落在两个时辰边界（如 12:59-13:01 之间），**必须两个时辰都排盘**，对照命主已知人生事件确定哪个更合。

### 3.2 第二步：定 12 宫地支位 + 命宫

12 宫地支位**固定**在盘面（无论命盘是什么样的盘，地支宫位都是这样排）：

```
      ┌─────┬─────┬─────┬─────┐
      │  巳 │  午 │  未 │  申 │
      ├─────┼─────┴─────┼─────┤
      │  辰 │   命盘中央  │  酉 │
      ├─────┤             ├─────┤
      │  卯 │             │  戌 │
      ├─────┼─────┬─────┼─────┤
      │  寅 │  丑 │  子 │  亥 │
      └─────┴─────┴─────┴─────┘
```

**注意**：以上是常见显示方式之一，地支顺时针流转的方向因软件而异。**逻辑上**地支按 子 → 丑 → 寅 → 卯 → … → 亥 → 子 顺行。

**命宫定位**：

```
Step 1: 从寅宫起正月，顺数（寅卯辰巳…）至本生月所在宫
Step 2: 从该宫起子时，逆数（…亥戌酉申）至本生时所在宫
Step 3: 第 2 步的终点即命宫
```

示例：生于农历四月寅时
- Step 1: 寅起正月 → 卯=二月 → 辰=三月 → **巳=四月**（停）
- Step 2: 巳起子时 → 辰=丑时 → 卯=**寅时**（停）
- Step 3: 命宫在卯

**12 宫顺序**（命宫定后，**逆时针**布其他 11 宫）：

```
命宫 → 兄弟 → 夫妻 → 子女 → 财帛 → 疾厄 → 迁移 → 交友（奴仆） → 官禄 → 田宅 → 福德 → 父母
```

按地支顺序，命宫在卯则：兄弟在寅、夫妻在丑、子女在子、财帛在亥…

**身宫定位**（叠加在 6 宫之一）：

| 生年地支 | 身宫位置 |
|---|---|
| 子 / 午 | 命宫 |
| 丑 / 未 | 福德 |
| 寅 / 申 | 官禄 |
| 卯 / 酉 | 迁移 |
| 辰 / 戌 | 财帛 |
| 巳 / 亥 | 夫妻 |

身宫**不独立成宫**，与某宫共占。**身宫宫位**是后天发力点，35 岁后影响显著（紫云"三十六岁前后论"重点之一）。

### 3.3 第三步：定五行局

五行局由**命宫宫位天干**和**纳音五行**决定。

**Step A**：由生年干推命宫干（用"五虎遁"口诀）

```
甲己之年丙作首  （甲己年正月寅宫起丙寅）
乙庚之岁戊为头  （乙庚年正月寅宫起戊寅）
丙辛必定寻庚起  （丙辛年正月寅宫起庚寅）
丁壬壬位顺行流  （丁壬年正月寅宫起壬寅）
戊癸之年何处起，甲寅之上好推求  （戊癸年正月寅宫起甲寅）
```

由此推算命宫所在地支配什么天干。

**Step B**：命宫干支配**纳音五行**（六十甲子纳音表）

例如：
- 甲子乙丑「海中金」→ 金四局
- 丙寅丁卯「炉中火」→ 火六局
- 戊辰己巳「大林木」→ 木三局
- 庚午辛未「路旁土」→ 土五局
- 壬申癸酉「剑锋金」→ 金四局
- …

完整 60 甲子纳音表见附录（在本文件末尾）。

## 4. 例子（示意，非实证）

**虚构案例**：1990 年 5 月 1 日 12:30 出生于哈尔滨

Step 1: 真太阳时校正
- 出生地哈尔滨东经 126.6°，时差 +26 分钟
- 5 月 1 日均时差约 +3 分钟
- 1990 年中国实施夏令时（4 月 15 日起）→ -60 分钟
- 真太阳时 = 12:30 + 26 + 3 - 60 = **11:59**（午时刚开始前 1 分钟，**临界生时**）

→ **建议两个时辰都排**：巳时（9:00-10:59）和午时（11:00-12:59）
→ 11:59 真太阳时落在午时，但因为离巳时只差 1 分钟，**强烈建议核对家长回忆**

Step 2: 1990 年农历四月初七（公历 5 月 1 日对应农历）
- 生月四月，从寅起正月：寅=正、卯=二、辰=三、巳=四
- 巳起子时（顺数 12 时辰应逆数到生时）：巳=子时、辰=丑时、卯=寅时、寅=卯时、丑=辰时、子=巳时、亥=午时
- 若午时 → 命宫**亥**
- 若巳时 → 命宫**子**

→ 命宫差一个地支，整盘判读完全不同

Step 3-5: 略（需完整排盘软件验证）

**这个例子的意义**：演示真太阳时校正的实际重要性 + 临界生时必须双排盘的原则。

## 5. 流派分歧

| 议题 | 中州派 | 飞星派 | 处理 |
|---|---|---|---|
| 真太阳时校正必要性 | 必须 | 必须 | 无分歧 |
| 闰月命主排盘 | 按闰月所在月份的中气划分 | 同 | 无重大分歧 |
| 子时跨日 | 早子时归前一日（23:00-23:59）/ 晚子时归当日（00:00-00:59） | 同 | 无分歧 |
| 起紫微星表 | 按《全书》原表 | 同 | 无分歧 |
| 安星系顺序 | 紫微系顺布 / 天府系顺布 | 同 | 无分歧 |
| 五行局争议 | 按命宫纳音五行（主流） | 同 | 部分流派主张按"年命"纳音，**少数说法**，主线不采纳 |

**结论**：排盘机制层面，中州派和飞星派**基本无分歧**。分歧集中在排盘后的**解读阶段**。
