# 贪狼

## 1. 核心定义

**贪狼**（Tān Láng，Star of Greed / Desire）：天府系主星，正桃花主，欲望与机遇之星。

| 属性 | 内容 |
|---|---|
| 星系 | 天府系（北斗第一星，部分主张南北斗交叉，**待考**） |
| 五行 | 木兼水（甲木 + 癸水） |
| 化气 | 桃花（正桃花）/ 解厄（与化禄同时主转祸为福） |
| 司掌 | 桃花 / 欲望 / 才艺 / 应酬 / 多才多艺 |
| 男女 | 男女皆主桃花强 |
| 度数 | 12 度 |

**性格关键词**：欲望强 / 多才多艺 / 应酬高手 / 桃花多 / 喜新厌旧 / 学习快 / 兴趣广 / 不耐沉闷 / 享受派 / 神秘倾向

**优点**：才艺多、学习快、人缘好、应酬能力强、对机会敏感、有领导魅力
**缺点**：欲望过强、感情复杂、易染恶习（酒色赌）、不耐久、肤浅倾向

**贪狼的"双重身份"**：
1. **正桃花主**：感情应酬最盛
2. **解厄之神**：贪狼化禄能转祸为福，是少数的"逆袭"星

**贪狼最有名格局**：
- **火贪格**（贪狼 + 火星）：暴发格，但来得快去得快
- **铃贪格**（贪狼 + 铃星）：同上
- 详见 [03-格局应期/格局/火贪铃贪.md](../../03-格局应期/格局/火贪铃贪.md)

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷二·诸星问答论·贪狼篇》

> 贪狼，北斗**解厄之神**，**化气为桃花**，**乃**主祸福之神。

白话翻译（笔者所加）：贪狼是北斗解厄之神，化气为桃花，主祸福转化。

### 2.2 《紫微斗数全书·卷四·骨髓赋》

> 贪狼**火星居庙旺，**名镇诸邦**。

白话翻译（笔者所加）：贪狼与火星同宫且在庙旺位，主大名（火贪格的古典依据）。

### 2.3 《紫微斗数全书·卷四·女命骨髓赋》

> 贪狼陀罗在**寅宫**，号曰**风流彩杖**。

白话翻译（笔者所加）：贪狼 + 陀罗在寅宫的女命，主感情复杂 / 风流（古义带贬，**慧心斋主反对字面贬义**）。

## 3. 现代解释

### 3.1 中州派（王亭之）

贪狼的核心是**"欲"** — 不只是色欲，更是对**一切机会的渴望**。三种典型：

1. **贪狼独坐**（在子 / 午 / 寅 / 申）：标准桃花 + 应酬命格
2. **贪狼 + 紫微**（卯 / 酉）：桃花犯主格 / 应酬带政治
3. **贪狼 + 武曲**（丑 / 未）：先贫后富格 / 30 后发
4. **贪狼 + 廉贞**（巳 / 亥）：双桃花格 / 极复杂感情
5. **贪狼 + 火 / 铃**：暴发格 / 但易暴落

**贪狼最忌"空 / 劫"**：贪狼 + 地空 / 地劫 = **欲望被空** = 反而清心、可入宗教 / 学术。这是古籍少有的"空劫遇贪反成好"的格局。

贪狼在 12 宫意义：

| 宫位 | 贪狼在此宫的意义 |
|---|---|
| 命宫 | 多才多艺 / 应酬高手 / 欲望强烈；需控制感情 |
| 兄弟 | 兄弟多才 / 关系应酬型 |
| **夫妻** | **重灾**：感情复杂 / 配偶有故事 / 婚前感情多 |
| 子女 | 子女聪明多才 / 桃花强 |
| 财帛 | 财来自应酬 / 多元 / 不稳定 |
| 疾厄 | **生殖 / 肝 / 神经**问题；酒色伤身风险 |
| 迁移 | 外出多机遇 + 桃花 |
| 交友 | 朋友多元 / 应酬密集 |
| 官禄 | 适合销售 / 公关 / 娱乐 / 媒体 / 应酬业 |
| 田宅 | 家中布置多元 / 喜变化 |
| 福德 | 享受派 / 欲望强 / 易酒色 |
| 父母 | 父母外向 / 应酬型 |

### 3.2 飞星派（梁若瑜）

贪狼化禄（**戊干**）：欲望带财 / 应酬有助
贪狼化权（**己干**）：欲望主导 / 应酬掌控力强
贪狼化忌（**癸干**）：欲望受挫 / 感情失败 / 应酬失败

**贪狼无化科**（飞星派立场）

### 3.3 现代实证派

贪狼命主在现代特别适合**社交密集型职业**：销售、公关、娱乐圈、媒体、KOL、企业家（应酬型）。

慧心斋主：女命贪狼**不等于风流** — 现代女命贪狼多为**自信 / 多才 / 善社交**的女性。

紫云：贪狼命主**婚姻稳定度低**，需主动节制 + 找耐心配偶。

## 4. 例子（结构性，非实证）

**案例 A**：贪狼 + 武曲在丑（先贫后富格）

- 倾向：早年贫困或不显，35 后发
- 事业：实业 + 应酬 = 制造业老板、贸易商
- 注意：早年勿急功近利

**案例 B**：贪狼 + 火星（火贪格）

- 倾向：突发机遇 / 暴发 / 但易暴落
- 建议：抓住时机但同时建退路

**案例 C**：女命贪狼 + 陀罗在寅（古"风流彩杖"）

- 古义：感情复杂 / 风流
- 现代：感情多但未必"贬义"；可能是自信 + 多才 + 善社交的现代女性
- 反对：直接断"必出轨"
