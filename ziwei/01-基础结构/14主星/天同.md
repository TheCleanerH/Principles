# 天同

## 1. 核心定义

**天同**（Tiān Tóng，Star of Fortune / Bliss）：紫微系第五颗主星，福德之星。

| 属性 | 内容 |
|---|---|
| 星系 | 紫微系（南斗第四星） |
| 五行 | 水（壬水） |
| 化气 | 福（享福 / 安逸 / 慵懒） |
| 司掌 | 福德主 |
| 男女 | 男女皆主温和、安逸 |
| 度数 | 12 度 |

**性格关键词**：温和 / 慈祥 / 安逸 / 慵懒 / 易享福 / 不喜竞争 / 情感丰富 / 易胖 / 易拖延

**优点**：性情温和、人缘好、有福相、家庭幸福、心宽
**缺点**：缺乏拼劲、易享福而失斗志、容易拖延、被动型人格

**关键：天同适合"被磨炼"** — 命格里有适当煞星反成助力（如**天同 + 巨门 + 擎羊** = 化煞为权 / 反败为胜）

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷二·诸星问答论·天同篇》

> 天同，南斗第四星也，**化气为福**，**主**人**福德**之主。

白话翻译（笔者所加）：天同主福德、享福、温和之气。

### 2.2 《紫微斗数全书·卷四·骨髓赋》

> 天同居戌不为吉，丁人化吉**主大贵**。

白话翻译（笔者所加）：天同在戌位本非吉位，但丁年生人化天同为权 / 化禄，反主大贵。

### 2.3 《紫微斗数全书·卷四·形性赋》

> 天同**肥满**，眉清目秀。

白话翻译（笔者所加）：天同坐命者多肥满，眉目清秀。

## 3. 现代解释

### 3.1 中州派（王亭之）

天同的核心是**"懒"** — 不是无能而是缺动机。三种典型：

1. **天同 + 太阴**（在子 / 午）：水水相生，主柔和富贵 / 福寿；子位优于午位
2. **天同 + 巨门**（在丑 / 未）：天同被巨门暗气拖累，易是非
3. **天同 + 天梁**（在寅 / 申）：福德 + 荫星，主长寿安稳；机月同梁格的一员

天同**不怕煞星**（与紫微 / 太阳相反）— 适度煞星反激发斗志。

天同在 12 宫意义：

| 宫位 | 天同在此宫的意义 |
|---|---|
| 命宫 | 福相、温和、易享福 / 易懒散；需逼自己保持斗志 |
| 兄弟 | 兄弟温和、关系融洽 |
| 夫妻 | 配偶温和、可靠；婚姻多平稳 |
| 子女 | 子女乖巧、福气重 |
| 财帛 | 财来不易但守得住；偏正财兼有 |
| 疾厄 | 消化系统 / 肾脏 / 易胖 / 水肿 |
| 迁移 | 外出受人欢迎；不宜艰苦地区 |
| 交友 | 朋友多温和型 |
| 官禄 | 适合服务业 / 餐饮 / 文教 / 公益 / 安稳职业 |
| 田宅 | 家中温馨 / 安稳 |
| 福德 | 福德主驻福德宫 — 本位极旺 / 享受多 |
| 父母 | 父母慈和 |

### 3.2 飞星派（梁若瑜）

天同化禄（**丙干**）：享福 + 财
天同化权（**丁干**）：被动激发主动，反成大用
天同化科（**庚干，部分主张**）：温和扬名
天同化忌（**庚干**）：福气受损 / 慵懒成病（拖延 / 抑郁）

天同化忌是**慢性病 / 抑郁 / 拖延症**的核心标志（飞星派立场）。

### 3.3 现代实证派

天同命主在现代社会**易得抑郁 + 慵懒病**（紫云观点）— 当代物质条件好，天同更易"福气养出毛病"。建议命主**主动设挑战目标**而非等机遇。

## 4. 例子（结构性，非实证）

**案例 A**：天同 + 太阴在子（同阴格）

- 性格：温和柔顺、内心丰富
- 事业：文教 / 艺术 / 设计 / 心理学
- 注意：太软易被欺、需培养硬度

**案例 B**：天同 + 巨门在丑

- 倾向：温和但易卷入口舌是非
- 建议：警惕被人利用，远离搬弄是非

**案例 C**：天同坐命 + 擎羊会照（丁年生人）

- 古籍：丁年生人化吉主大贵
- 解读：擎羊激发天同的潜力，命主反在竞争中得益
- 现代：适合**有挑战的环境**而非舒适区
