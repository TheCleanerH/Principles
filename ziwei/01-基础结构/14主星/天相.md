# 天相

## 1. 核心定义

**天相**（Tiān Xiàng，Star of Minister / Seal）：天府系主星，印星 / 宰相之星。

| 属性 | 内容 |
|---|---|
| 星系 | 天府系（南斗第二星） |
| 五行 | 水（壬水） |
| 化气 | 印（贵气 / 印鉴 / 辅佐） |
| 司掌 | 印星 / 贵气 / 辅佐 / 衣食 / 仪表 |
| 男女 | 男女皆主端正、辅佐型 |
| 度数 | 12 度 |

**性格关键词**：稳重 / 端庄 / 辅佐型 / 重仪表 / 善协调 / 不抢风头 / 中庸 / 谨慎 / 有福相

**优点**：性格稳重、人际圆融、重仪表与礼仪、善于辅佐与协调、有福相
**缺点**：缺乏主见、容易被夹击影响、过于谨慎、不擅独断

**关键：天相最忌"刑忌夹印"**
- 天相**两侧夹宫**为擎羊 + 化忌（化忌的星在邻宫）→ **刑忌夹印格** → 重大刑伤 / 是非 / 失业
- 详见 [03-格局应期/格局/刑忌夹印.md](../../03-格局应期/格局/刑忌夹印.md)

**天相是"辅星型主星"** — 性格本身带辅佐属性，独坐时反不显，与其他主星组合时最佳。

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷二·诸星问答论·天相篇》

> 天相，南斗第二星也，**化气为印**，**为官禄之主**，**司**爵禄之**司**，**主**衣食**之享**。

白话翻译（笔者所加）：天相是南斗第二星，化气为印星，主官禄、爵禄、衣食。

### 2.2 《紫微斗数全书·卷四·骨髓赋》

> 天相天梁**居夫妻宫**，主**夫荣妻贵**。

白话翻译（笔者所加）：天相 + 天梁在夫妻宫，主夫妻俱贵显。

### 2.3 《紫微斗数全书·卷四·形性赋》

> 天相**端庄**，重仪表。

白话翻译（笔者所加）：天相坐命者端庄重仪表。

## 3. 现代解释

### 3.1 中州派（王亭之）

天相的核心是**"辅"** — 性格本身具辅佐特质。三种典型：

1. **天相独坐**（在丑 / 卯 / 巳 / 未 / 酉 / 亥）：标准辅佐命格
2. **天相 + 紫微**（辰 / 戌）：宰相辅帝 / 格局高
3. **天相 + 武曲**（寅 / 申）：印星合财 / 公职财
4. **天相 + 廉贞**（子 / 午）：印 + 复杂 / 公职 + 公关

**天相最忌"刑忌夹印"** — **必须看天相两侧邻宫**：
- 邻宫 1：化忌（任何主星化忌）
- 邻宫 2：擎羊
- 二者夹天相 → **刑忌夹印** → 重灾

天相在 12 宫意义：

| 宫位 | 天相在此宫的意义 |
|---|---|
| 命宫 | 稳重 + 辅佐命格；适合做"二把手" |
| 兄弟 | 兄弟稳重、关系融洽 |
| 夫妻 | 配偶端庄、稳重 / 有印星气（贵气） |
| 子女 | 子女稳重、有礼 |
| 财帛 | 财源稳 / 正财为主 |
| 疾厄 | 泌尿 / 膀胱 / 皮肤问题（水气） |
| 迁移 | 外出有贵人助 / 受人尊重 |
| 交友 | 朋友稳重 / 长期关系 |
| 官禄 | 适合公职 / 秘书 / 顾问 / 辅佐型职位 / 法律 / 金融 |
| 田宅 | 家中端庄、有礼仪氛围 |
| 福德 | 享受稳定 |
| 父母 | 父母端庄、有礼 |

### 3.2 飞星派（梁若瑜）

天相**无化禄、无化权、无化忌**（14 主星中比较特殊，只入化科 — **待考**）

部分说法：天相化科（**辛干**？或不入化科）— **多数主流认为天相不入四化系统**

正因天相不入四化，飞星派特别看重**夹宫四化**：
- 天相被化忌夹一边 + 擎羊夹另一边 = 刑忌夹印（重灾）

### 3.3 现代实证派

天相命主在现代特别适合**"二把手"职业**：副总、秘书长、顾问、首席法务、CFO（辅佐 CEO） — 命主性格本身不爱抢风头，做辅佐反舒服。

紫云：天相 + 紫微的"宰相辅帝"格在政商界都有大用。

## 4. 例子（结构性，非实证）

**案例 A**：天相 + 紫微在辰

- 性格：辅佐 + 帝王气
- 事业：大企业副总 / 政界辅佐高位 / 顾问首席
- 注意：才能高但需找对"帝王"

**案例 B**：天相 + 刑忌夹印（重灾格）

- 倾向：刑伤 / 是非 / 失业 / 法律纠纷
- 建议：避险驾驶 / 远离法律边界 / 定期体检
- 反对：直接断"必有大灾"

**案例 C**：女命天相坐夫妻

- 倾向：配偶端庄稳重 / 婚姻平和
- 慧心斋主：女命天相在夫妻宫为吉，不需"以夫为天"

## 5. 流派分歧

| 议题 | 中州派 | 飞星派 | 现代 |
|---|---|---|---|
| 天相是否入四化 | 主流不入（或仅化科） | 同 | 同 |
| 刑忌夹印严重性 | 大忌 | **重灾** | 同 |
| 天相辅佐性质 | 强 | 强 | 同 |
| 天相 + 紫微地位 | 顶级辅佐格 | 同 | 同 |
