# 七杀

## 1. 核心定义

**七杀**（Qī Shā，General Star / Star of Death）：天府系主星，将星之首，杀破狼格之核心。

| 属性 | 内容 |
|---|---|
| 星系 | 天府系（南斗第六星） |
| 五行 | 金兼火（庚金 + 丁火） |
| 化气 | 权（将星 / 武权 / 杀伐） |
| 司掌 | 武权 / 决断 / 杀伐 / 创业 |
| 男女 | 男女皆主刚强决断 |
| 度数 | 12 度 |

**性格关键词**：刚强 / 决断 / 独立 / 不服管 / 创业 / 冒险 / 杀伐果断 / 不善人情 / 独行 / 早熟

**优点**：决断力强、行动力强、不畏挑战、有创业精神、独立性强
**缺点**：太刚强、不擅人情、易孤独、冒险过度、不善合作

**关键：七杀是"杀破狼格"主角之一**
- 七杀 + 破军 + 贪狼形成三方四正 = 杀破狼格
- 主**动态命格**：人生波动大，但有大成就潜力
- 详见 [03-格局应期/格局/杀破狼.md](../../03-格局应期/格局/杀破狼.md)

**七杀的"先苦后甜"特质**：
- 七杀早年多苦 / 多挫折
- 30+ 后渐入佳境
- 适合**自创事业**而非依附他人

## 2. 古籍出处

> 七杀，南斗**主将**之星，**化气为将**，**主**权威。

白话翻译（笔者所加）：七杀是南斗主将之星，化气为将星 / 权威。

### 2.2 《紫微斗数全书·卷四·骨髓赋》

> 七杀**朝斗**，爵禄昌荣。
> 七杀廉贞**同位**，路上埋尸。

白话翻译（笔者所加）：七杀朝向北斗位（庙旺），主荣华；七杀 + 廉贞（在丑 / 未）若再加煞，主刑伤夭亡（古夸张说法，**现代不字面理解**）。

> 七杀**目大**，面色**青黄**。

白话翻译（笔者所加）：七杀坐命者眼睛大、面色青黄。

## 3. 现代解释

### 3.1 中州派（王亭之）

七杀的核心是**"杀"** — 不是杀人，而是**杀伐决断 / 不留情面**。三种典型：

1. **七杀独坐**（在子 / 午 / 寅 / 申）：标准将星命格
2. **七杀 + 紫微**（巳 / 亥）：紫杀格 / 帝王 + 将 / 主大权
3. **七杀 + 武曲**（卯 / 酉）：因财持刀格 / 须防刑伤
4. **七杀 + 廉贞**（丑 / 未）：积富格 / 实业老板

**七杀最忌煞星过多**：
- 七杀 + 火铃陀羊全凑 → 易刑伤 / 事故
- 七杀 + 化忌（不直接化，但邻宫化忌冲） → 重灾

七杀在 12 宫意义：

| 宫位 | 七杀在此宫的意义 |
|---|---|
| 命宫 | 刚强 / 独立 / 决断 / 适合创业 |
| 兄弟 | 兄弟刚强 / 关系疏远 |
| **夫妻** | **重灾**：婚姻冷 / 配偶刚硬 / 易冲突；晚婚为宜 |
| 子女 | 子女刚强 / 不易管教 |
| 财帛 | 财来财去 / 大起大落 / 适合创业财 |
| 疾厄 | **金属外伤 / 手术 / 呼吸道 / 肝胆**风险 |
| 迁移 | 外出动荡 / 适合远行打拼 |
| 交友 | 朋友少而精 / 多刚强型 |
| 官禄 | 适合武职 / 创业 / 工程 / 体育 / 警察 / 军人 |
| 田宅 | 不动产易变 / 家中刚硬气 |
| 福德 | 不喜享受 / 心硬 |
| 父母 | 父母刚硬 / 与父母情薄 |

### 3.2 飞星派（梁若瑜）

七杀**无化禄、无化权、无化科、无化忌**（与天府类似，14 主星中不入四化系统）

**待考**：部分流派有 "七杀化权" 说，但主流不取。

正因七杀不入四化，飞星派看七杀重**邻宫四化冲撞** + **大限七杀宫触发应期**。

### 3.3 现代实证派

七杀命主在现代**特别适合创业**：
- 创业型 CEO / 工程师 / 科技公司创始人 / 体育 / 武术 / 警察 / 军人
- **不适合**温和型职业（公关 / 服务）

紫云：七杀命主**婚姻晚发**为吉，**30 后**渐入佳境，年轻时勿强求婚姻。

## 4. 例子（结构性，非实证）

**案例 A**：七杀朝斗格（七杀在寅 / 申朝向斗位）

- 性格：刚强 + 高远
- 事业：将才 / 政界军方 / 大企业 CEO
- 注意：仍需主动协调人际

**案例 B**：紫杀格（七杀 + 紫微在巳）

- 性格：帝王气 + 将气
- 事业：政商高位 / 大型组织领导
- 注意：易孤独

**案例 C**：女命七杀坐命

- 古义："孤克"
- 现代：女强人 / 企业家 / 独立性强女性
- 慧心斋主：反对"孤克"古义，现代女命七杀多是事业型独立女性

## 5. 流派分歧

| 议题 | 中州派 | 飞星派 | 慧心斋主 |
|---|---|---|---|
| 七杀是否入四化 | 主流不入 | 不入 | 同 |
| 七杀 + 廉贞 "路上埋尸" | 古夸张，需看煞 | 看四化触发 | 反对古夸张 |
| 女命七杀坐命 | "孤克"古义不取 | 同 | **反对**孤克说 |
| 七杀晚发 | 30+ 渐佳 | 大限四化触发 | 同 |
| 七杀创业适应 | 强 | 强 | 同 |
