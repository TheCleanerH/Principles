# 廉贞

## 1. 核心定义

**廉贞**（Lián Zhēn，Star of Restraint / Imprisonment）：紫微系第六颗主星，性质最复杂的星之一。

| 属性 | 内容 |
|---|---|
| 星系 | 紫微系（北斗第五星） |
| 五行 | 火（丁火） |
| 化气 | 囚（被关 / 被限制 / 自我约束）；次桃花 |
| 司掌 | 官禄 / 桃花（次于贪狼的桃花主） |
| 男女 | 男女皆主复杂个性 |
| 度数 | 12 度 |

**性格关键词**：复杂 / 双面 / 公关力 / 桃花 / 法律 / 血光 / 自律 / 心机 / 艺术天赋 / 易染恶习

**优点**：公关能力强、有艺术天赋、自律有恒、复杂应变、有领导潜力
**缺点**：感情复杂、易染恶习、易血光、心机重、不稳定

**廉贞性质矛盾**：既是"次桃花"主交际，又"化气为囚"主自律 — 反映命主**内在常存冲突**（理性 vs 欲望）。

**廉贞最忌**：与化忌同宫 — "廉贞化忌"是最凶险的化曜组合之一，主**血光 / 法律纠纷 / 重大破财**。

## 2. 古籍出处

> 廉贞，北斗第五星也，**化气为囚**，**司**人**品职权**令，**为**次桃花**之星**。

白话翻译（笔者所加）：廉贞主品职权力 + 次桃花 + 化气为囚（自我约束）。

> 廉贞**眉宽口阔**，面横**色尖**。

白话翻译（笔者所加）：廉贞坐命的人眉宽嘴大，面带横气。

## 3. 现代解释

### 3.1 中州派（王亭之）

廉贞的核心是**"双面"** — 表面端正内心复杂 / 表面温和内心刚硬。三种典型：

1. **廉贞独坐**（在寅 / 申）：性格相对稳定，仍有"次桃花"气
2. **廉贞 + 七杀**（在丑 / 未）：积富 + 刚硬 / 实业型
3. **廉贞 + 破军**（在卯 / 酉）：变动 + 复杂 / 易意外
4. **廉贞 + 贪狼**（在巳 / 亥）：双重桃花 / 应酬密集
5. **廉贞 + 天府**（在辰 / 戌）：财库 + 复杂 / 商场老手
6. **廉贞 + 天相**（在子 / 午）：印星 + 复杂 / 公职 + 公关

**廉贞 + 化忌** = **重灾**：
- 廉贞化忌（**丙干**）+ 大限 / 流年 → 血光 / 法律 / 重病
- 廉贞 + 擎羊 + 化忌 → 极凶（"廉贞遇羊忌"古籍重灾格）

廉贞在 12 宫意义：

| 宫位 | 廉贞在此宫的意义 |
|---|---|
| 命宫 | 性格复杂，公关与艺术兼有；自律性强但易内耗 |
| 兄弟 | 兄弟复杂 / 有公关力 |
| **夫妻** | **重灾**：感情复杂；易遇有故事的对象 |
| 子女 | 子女聪明但难管 |
| 财帛 | 财来财去；公关 / 中介 / 应酬性收入 |
| 疾厄 | **血光 / 心脏 / 妇科 / 性病**风险；火气过盛 |
| 迁移 | 外出多公关机会，易桃花 |
| 交友 | 朋友复杂，三教九流 |
| 官禄 | 适合公关 / 法律 / 文创 / 影视 / 销售 / 应酬业 |
| 田宅 | 家中复杂 / 不动产易变 |
| 福德 | 内心矛盾 / 享受复杂 |
| 父母 | 父母关系复杂 |

### 3.2 飞星派（梁若瑜）

廉贞化禄（**甲干**）：公关带财、桃花有助
廉贞化忌（**丙干**）：**血光 / 法律 / 重病 / 重大破财**（飞星派最凶化忌之一）

**廉贞无化权 / 化科**（14 主星中比较特殊）

### 3.3 现代实证派

廉贞命主在现代特别适合**公关 + 文创复合行业**：广告、影视、娱乐圈、律师、公关公司、销售总监 — 但**必须保持自律边界**，否则易染恶习。

紫云观点：廉贞命主的**双面性**导致情感生活复杂，**婚姻稳定度低于平均**，需主动节制。

## 4. 例子（结构性，非实证）

**案例 A**：廉贞 + 七杀在丑（积富格）

- 性格：刚硬 + 复杂 + 实业型
- 事业：制造 / 工程 / 金融实操 / 武职
- 注意：晚发 / 中年开始旺

**案例 B**：廉贞 + 贪狼在巳

- 倾向：应酬密集 / 公关能力强 / 桃花多
- 事业：娱乐 / 媒体 / 公关 / 销售
- 注意：易因桃花 / 应酬影响家庭

**案例 C**：廉贞化忌在大限疾厄宫

- 风险：血光 / 重病 / 法律
- 建议：定期体检、避险驾驶、远离法律边界
- 反对：直接断"必有大灾"

## 5. 流派分歧
