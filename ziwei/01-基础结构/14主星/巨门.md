# 巨门

## 1. 核心定义

**巨门**（Jù Mén，Star of the Dark Door / Mouth）：天府系主星，口舌之星，暗曜之首。

| 属性 | 内容 |
|---|---|
| 星系 | 天府系（北斗第二星） |
| 五行 | 水（癸水，部分主张兼土，**待考**） |
| 化气 | 暗（暗曜 / 是非 / 隐藏） |
| 司掌 | 口舌 / 是非 / 言论 / 暗中 / 灾难 |
| 男女 | 男女皆主口舌敏锐 |
| 度数 | 12 度 |

**性格关键词**：口才好 / 善辩 / 多疑 / 暗中思虑 / 善言论 / 易卷入是非 / 研究型 / 喜暗中观察 / 不易信人

**优点**：口才一流、善于研究分析、有敏锐的观察力、适合用嘴吃饭的行业
**缺点**：多疑、易遭口舌之灾、易卷入是非、不易信人、性格内向偏暗

**关键：巨门最爱"太阳化煞为权"**
- 巨门 + 太阳（在寅 / 申）：**太阳光照巨门** → 把"暗"化为"明" → 主清贵 / 外国 / 跨文化
- 巨门陷地无太阳照 → 主小人 / 是非 / 暗病

**巨门是"嘴吃饭"星** — 教师、律师、销售、主持人、咨询师、医生（问诊）、播音员、网红 — 都属巨门优势行业。

## 3. 现代解释

### 3.1 中州派（王亭之）

巨门的核心是**"嘴"** — 用嘴的能力是优势，但也是灾源。三种典型：

1. **巨门 + 太阳**（寅 / 申）：太阳光照巨门，**化暗为明** → 主大用 / 外国 / 清贵
2. **巨门 + 天同**（丑 / 未）：暗 + 福 → 易享福但是非多
3. **巨门 + 天机**（卯 / 酉）：机巨格 → 聪明 + 善辩 → 律师 / 咨询 / 教师

**巨门最忌"化忌"**：
- 巨门化忌（**丁干**）= **重灾**：口舌官司 / 是非 / 暗病 / 法律纠纷

巨门在 12 宫意义：

| 宫位 | 巨门在此宫的意义 |
|---|---|
| 命宫 | 口才好命格 / 善辩 / 多疑；适合用嘴的职业 |
| 兄弟 | 兄弟有口才 / 易争吵 |
| **夫妻** | **重灾**：夫妻间口舌多 / 易冷战；需主动沟通 |
| 子女 | 子女口才好 / 与父母言语冲突 |
| 财帛 | 靠嘴赚钱 / 口才型收入（讲课、销售、咨询） |
| 疾厄 | **口腔 / 食道 / 胃 / 喉咙**问题 |
| 迁移 | 外出多口舌 / 宜外国发展（巨日格特别有助） |
| 交友 | 朋友多元但口舌多 |
| 官禄 | 适合教师 / 律师 / 销售 / 主持 / 咨询 / 演讲 / 医生 / 网红 |
| 田宅 | 家中口舌多 / 邻里多事 |
| 福德 | 多思多虑 / 易暗中担忧 |
| 父母 | 父母间口舌 / 与父母言语冲突 |

### 3.2 飞星派（梁若瑜）

巨门化禄（**辛干**）：口才带财 / 言论之利
巨门化权（**癸干**）：口才主导 / 演讲有力
巨门化忌（**丁干**）：**口舌官司 / 是非 / 暗病 / 食物中毒**

巨门 + 化忌 + 流年触发 = 重要应期。

### 3.3 现代实证派

巨门命主在现代社会**特别有利**：自媒体、网红、播客、KOL、培训师、销售高管、律师 — 都是巨门优势行业。

紫云：巨门 + 太阳的"巨日格"在**跨文化 / 出国 / 外资工作**中特别有利 — 命主在韩国留学若有此格是**结构性吻合**。

## 4. 例子（结构性，非实证）

**案例 A**：巨日格（巨门 + 太阳在寅）

- 性格：光明 + 善言
- 事业：跨国企业 / 外交 / 外语 / 律师 / 国际媒体
- 注意：直率易得罪人

**案例 B**：机巨格（巨门 + 天机在卯）

- 事业：律师 / 咨询师 / 教师 / 媒体
- 注意：口舌是非多

**案例 C**：巨门化忌坐疾厄宫

- 倾向：口腔 / 食道 / 胃部问题
- 建议：少吃辛辣 / 戒烟酒 / 定期检查口腔
- 反对：直接断"必得胃癌"
