# 天府

## 1. 核心定义

**天府**（Tiān Fǔ，Treasury Star）：天府系主星，南斗主，财库之星。

| 属性 | 内容 |
|---|---|
| 星系 | 天府系（南斗主） |
| 五行 | 土（戊土） |
| 化气 | 令（库藏 / 收藏 / 稳重） |
| 司掌 | 财帛 / 田宅 / 兼禄寿 |
| 男女 | 男女皆主稳重保守 |
| 度数 | 14 度（与紫微并列最高） |

**性格关键词**：稳重 / 保守 / 厚道 / 守财 / 兼容 / 圆融 / 不冒险 / 有储蓄观 / 务实 / 平和

**优点**：性格沉稳、有福气、理财稳健、人际圆融、不易树敌
**缺点**：过于保守、缺乏创新、容易满足现状、有时显得圆滑

**天府是"对照紫微"的次帝星** — 紫微为"动态领导"，天府为"静态守成"。**两星永远不可能同时坐命**（除寅 / 申宫紫府同宫格外）。

天府**最大特质**：**库** — 储蓄、保守、不漏财。

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷二·诸星问答论·天府篇》

> 天府，**南斗令星**，**司天上财帛之库**，**为禄库**，主**财帛、田宅**，化气为令（库藏）。

白话翻译（笔者所加）：天府是南斗的"令星"（统帅），掌天上财帛库，主财帛宫和田宅宫。

### 2.2 《紫微斗数全书·卷四·骨髓赋》

> 天府临戌有星拱，**腰金衣紫**。

白话翻译（笔者所加）：天府在戌宫且会照吉星，主大贵（穿金紫朝服 = 高官）。

### 2.3 《紫微斗数全书·卷四·形性赋》

> 天府**面方圆**，**温和厚重**。

白话翻译（笔者所加）：天府坐命的人面相方圆，温和厚重。

## 3. 现代解释

### 3.1 中州派（王亭之）

天府的核心是**"守"** — 不进取但善守成。三种典型：

1. **天府独坐**（在丑 / 卯 / 巳 / 未 / 酉 / 亥）：标准守财命格
2. **紫府同宫**（寅 / 申）：双帝合体，主大格局 — 详见 [03-格局应期/格局/紫府同宫.md](../../03-格局应期/格局/紫府同宫.md)
3. **天府 + 武曲**（在子 / 午）：双财星合一，主大富
4. **天府 + 廉贞**（在辰 / 戌）：财库 + 复杂气，商场老手

**天府最忌"空库"**：
- 天府 + 地空 / 地劫 = **空露库** = 财库无实
- 天府 + 化忌邻宫（夹库） = 库被夹 = 财气受困

天府在 12 宫意义：

| 宫位 | 天府在此宫的意义 |
|---|---|
| 命宫 | 稳重命格、守财、保守 / 不冒险 |
| 兄弟 | 兄弟厚道 / 关系平和 |
| 夫妻 | 配偶稳重、年长 / 长相福相 |
| 子女 | 子女厚道 / 子女缘佳 |
| 财帛 | 财库主驻财帛 — 本位极旺 / 主财源稳厚 |
| 疾厄 | 脾胃 / 消化 / 易胖（土气） |
| 迁移 | 外出稳定，得贵人助 |
| 交友 | 朋友厚道 / 长期关系 |
| 官禄 | 适合金融 / 财务 / 不动产 / 保险 / 稳健行业 |
| 田宅 | 田宅主驻田宅 — 本位极旺 / 不动产丰 |
| 福德 | 享福稳重 |
| 父母 | 父母厚道、福相 |

### 3.2 飞星派（梁若瑜）

天府**无化禄、无化权、无化科、无化忌**（14 主星中唯一不入四化系统的主星，**待考**：部分流派有"丁干 天府化科"说，但主流不取）

正因天府不入四化系统，飞星派认为天府**性质极稳定**，主"恒"。

### 3.3 现代实证派

天府命主在现代适合**长期稳健型职业**：会计、银行、保险、不动产、公务员、教师。**不适合**创业 / 高风险投资。

紫云观点：天府命主**婚姻稳定度高于平均**，但**晚婚率也较高**（因不冒险性格）。

## 4. 例子（结构性，非实证）

**案例 A**：紫府同宫在寅（最高格之一）

- 性格：稳重 + 帝王气
- 事业：体制内高层 / 大企业领导 / 金融业
- 注意：易因保守错过机遇，需主动突破

**案例 B**：天府 + 地空 + 地劫（空露库）

- 倾向：守财能力被破坏 / 易遭意外破财
- 建议：财务分散管理 / 不放大笔现金于单一账户

**案例 C**：天府坐命 + 武曲在三方

- 性格：稳健 + 决断
- 事业：金融 / 不动产 / 财务管理
- 优势：理财能力强

## 5. 流派分歧

| 议题 | 中州派 | 飞星派 | 现代 |
|---|---|---|---|
| 天府是否入四化 | 主流不入（少数说丁干化科） | 不入 | 同 |
| 天府空露库严重性 | 重灾 | 看四化飞动 | 同 |
| 紫府同宫地位 | 顶级格局 | 同 | 同 |
| 天府守财能力 | 强 | 强 | 同 |
