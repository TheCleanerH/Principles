# 太阴

## 1. 核心定义

**太阴**（Tài Yīn，Moon Star）：天府系主星，与太阳相对，主月光、阴柔、田宅、富。

| 属性 | 内容 |
|---|---|
| 星系 | 天府系（中天主星之一，与太阳对应） |
| 五行 | 水（癸水） |
| 化气 | 富（财富 / 母性 / 阴柔之气） |
| 司掌 | 男命：母亲 + 妻子；女命：母亲 / 自身；田宅 / 财帛 / 母亲 / 配偶（男命） |
| 男女 | 男女有别（古义） |
| 度数 | 12 度 |

**性格关键词**：阴柔 / 内敛 / 多情 / 浪漫 / 母性 / 谨慎 / 不善表达 / 重感情 / 想象力丰富 / 易郁 / 易胖

**优点**：心思细腻、有艺术天赋、人缘佳（特别女性人际）、有储蓄观、家庭观念强
**缺点**：内向不善表达、易陷入情绪化、想得多做得少、易抑郁

**关键：太阴重"庙旺陷"**（与太阳相反）
- 太阴在**酉 / 戌 / 亥 / 子 / 丑**为**庙旺**（夜晚 / 月光满）
- 太阴在**寅 / 卯 / 辰 / 巳 / 午**为**陷**（白天 / 月光被遮）
- 太阴**最旺在亥**（"月朗天门"格）

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷二·诸星问答论·太阴篇》

> 太阴，**乃中天之主**，**化气为富**，**司**田宅，**主**妻、母。

白话翻译（笔者所加）：太阴是中天主星之一，化气为富，主管田宅宫，代表妻 / 母。

### 2.2 《紫微斗数全书·卷四·骨髓赋》

> 太阴居亥，**月朗天门**，**至贵**。

白话翻译（笔者所加）：太阴在亥位（最旺），主大贵。

### 2.3 《紫微斗数全书·卷四·形性赋》

> 太阴**面圆白**，**身材**端正。

白话翻译（笔者所加）：太阴坐命的人面圆肤白，身材端正。

## 3. 现代解释

### 3.1 中州派（王亭之）

太阴的核心是**"藏"** — 内敛、收藏、不外露。三种典型：

1. **太阴独坐在亥**（月朗天门格）：主大贵 / 富 / 名声
2. **太阴 + 天同**（在子 / 午）：同阴格 / 柔和富贵
3. **太阴 + 天机**（在寅 / 申）：机阴格 / 智巧 + 阴柔
4. **太阴 + 太阳**（在丑 / 未）：日月同临格 / 名利双全但起伏大

太阴**最关键**：庙旺陷。**陷地太阴**主**情感波动 / 财运不稳 / 母 / 妻缘淡**。

太阴在 12 宫意义：

| 宫位 | 太阴在此宫的意义 |
|---|---|
| 命宫 | 阴柔内敛命格；女命温柔有母性；男命有阴柔气（古义"娘娘腔"，现代不取此说） |
| 兄弟 | 兄弟（特别姐妹）感情深 |
| 夫妻 | 男命太阴坐夫妻 = 妻子温柔；女命太阴坐夫妻 = 配偶有阴柔气 |
| 子女 | 子女乖巧 / 女孩多于男孩倾向（古义） |
| 财帛 | 财源稳 / 偏正财兼有 / 储蓄观强 |
| 疾厄 | **生殖 / 泌尿 / 内分泌**问题；女命易经期不调 |
| 迁移 | 外出宜与女性合作 |
| 交友 | 朋友多女性 / 关系深 |
| 官禄 | 适合艺术 / 文学 / 美容 / 服务 / 教育 |
| 田宅 | 田宅主驻田宅 — 本位极旺 / 不动产丰 |
| 福德 | 多情多思 / 易抑郁但富享受 |
| 父母 | 母亲为主导（古义） / 与母关系深 |

### 3.2 飞星派（梁若瑜）

太阴化禄（**丁干**）：阴柔之财 / 不动产之利
太阴化权（**戊干**）：太阴之富显，掌财权（女命主能干）
太阴化科（**癸干**）：阴柔之名 / 艺术 / 文教扬名
太阴化忌（**乙干**）：母 / 妻 / 女性人物缘分淡；男命主妻不顺；女命主自身阴柔受损 / 经期不调 / 抑郁

太阴化忌是**女性人物缘分 / 情绪健康**的核心标志（飞星派立场）。

### 3.3 现代实证派（慧心斋主）

慧心斋主：**女命太阴坐命**不是"必克夫" — 反而是**情感丰富 / 母性强 / 适合家庭事业平衡**的标志。

紫云：太阴的"内敛"特质易导致**情绪堆积**，命主必须**学会表达**，否则陷地时易抑郁。

## 4. 例子（结构性，非实证）

**案例 A**：太阴在亥（月朗天门格）

- 性格：阴柔 + 富贵气
- 事业：金融 / 房地产 / 艺术 / 教育
- 注意：易因情绪化做错决定

**案例 B**：太阴 + 天同在子（同阴格）

- 性格：温柔 + 福相
- 事业：服务 / 文教 / 设计 / 心理咨询

**案例 C**：男命太阴化忌

- 倾向：与母 / 妻关系紧张 / 自身情绪波动
- 建议：主动经营与女性家人关系 + 心理调节
- 反对：直接断"必克妻"
