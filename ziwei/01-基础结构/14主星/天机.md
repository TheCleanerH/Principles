# 天机

## 1. 核心定义

**天机**（Tiān Jī，Star of Wisdom / Heavenly Mechanism）：紫微系第二颗主星，主智慧、机变、思考力。

| 属性 | 内容 |
|---|---|
| 星系 | 紫微系（南斗第三星，部分主张北斗，**待考**） |
| 五行 | 木（乙木） |
| 化气 | 善（善变 / 善思考） |
| 司掌 | 兄弟主（"兄弟宫"的代表星） |
| 男女 | 男女皆主智巧 |
| 度数 | 12 度 |

**性格关键词**：聪明 / 善变 / 机敏 / 多思 / 神经质 / 学习快 / 兴趣广 / 不耐久 / 善谋划 / 易焦虑

**优点**：智商高、反应快、学习能力强、善于规划与策略
**缺点**：神经过敏、想得多做得少、容易焦虑、兴趣多但精度不够、不耐长期专注

**天机在 12 宫的不同表现**：天机在命 = 聪明型命格 / 在兄弟 = 兄弟姐妹有才智 / 在夫妻 = 配偶聪明且善变 / 在子女 = 子女机灵 / 在财帛 = 靠脑力赚钱 / 在疾厄 = 神经系统易问题…

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷二·诸星问答论·天机篇》

> 天机者，南斗益算之善星也，**化气为善**，主**人之兄弟，主谋略**。

白话翻译（笔者所加）：天机主善行、寿命延长、谋略，是兄弟宫的代表星。

> 天机为不长不短之资，**情怀好善**。

白话翻译（笔者所加）：天机坐命的人身材中等，性情向善。

> 机月同梁作吏人。

白话翻译（笔者所加）：天机 / 太阴 / 天同 / 天梁形成三方四正的"机月同梁格"，主公务员 / 行政职 / 文职。

## 3. 现代解释

### 3.1 中州派（王亭之）

天机的核心是**"动"** — 思维动 / 行动也动。三种典型：

1. **天机 + 太阴**（在寅 / 申）：智巧 + 阴柔思维，适合谋划 / 策划 / 文教
2. **天机 + 巨门**（在卯 / 酉）：智巧 + 口才，适合咨询 / 教师 / 律师 / 销售
3. **天机 + 天梁**（在辰 / 戌）：智巧 + 长者气质，适合参谋 / 顾问 / 中医

天机**怕煞星**（火铃陀羊冲）→ 易神经质、焦虑、失眠

天机在 12 宫意义：

| 宫位 | 天机在此宫的意义 |
|---|---|
| 命宫 | 聪明命格，宜从事脑力 / 策划 / 咨询类 |
| 兄弟 | 兄弟有才智但缘分淡（"机"性多变） |
| 夫妻 | 配偶聪明、善变；婚姻多变化 |
| 子女 | 子女机灵但不安分 |
| 财帛 | 靠脑力赚钱，财来财去 |
| 疾厄 | 神经系统 / 肝胆问题（木气） |
| 迁移 | 外出多机遇，宜跑动型工作 |
| 交友 | 朋友圈多智商型，但浮 |
| 官禄 | 适合咨询 / 策划 / 教育 / 中介 |
| 田宅 | 家中布置常变；不动产易迁 |
| 福德 | 思绪多，福德难安 |
| 父母 | 父母聪明 |

### 3.2 飞星派（梁若瑜）

天机化禄（**乙干**）：增加智慧型财源 / 策划带来收益
天机化权（**丙干**）：主导思维，决策力强
天机化科（**丁干**）：智慧扬名 / 学术出头
天机化忌（**戊干**）：神经质、思虑过度、计划落空

天机化忌是**心理问题**的重要标志（飞星派立场）。

### 3.3 现代实证派

天机命主在现代特别适合**信息时代职业**：程序员、数据分析、内容策划、咨询顾问、AI 研究 — 命主作为 AI 方向硕士，若命宫或官禄宫见天机，是**结构性吻合**。

## 4. 例子（结构性，非实证）

**案例 A**：天机 + 太阴在寅 — "机月格"

- 性格：聪明 + 阴柔思维，善规划
- 事业：策划 / 教育 / 文教 / 研究
- 注意：多想少做，需逼自己执行

**案例 B**：天机 + 巨门在卯 — "机巨格"

- 性格：聪明 + 口才好
- 事业：咨询 / 教师 / 律师 / 销售
- 注意：口舌是非多，言论需谨慎

**案例 C**：天机化忌坐疾厄

- 倾向：神经焦虑 / 失眠 / 肝胆问题
- 建议：定期心理咨询 / 中医调理
- 反对：把"天机化忌"作为"必然抑郁"的死断
