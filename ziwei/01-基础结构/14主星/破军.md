# 破军

## 1. 核心定义

**破军**（Pò Jūn，Breaker Star / Star of Destruction）：天府系主星，杀破狼格之一，先破后立。

| 属性 | 内容 |
|---|---|
| 星系 | 天府系（北斗第七星） |
| 五行 | 水（癸水） |
| 化气 | 耗（先破后立 / 消耗 / 变革） |
| 司掌 | 变革 / 破坏 / 创新 / 子女 / 奴仆 |
| 男女 | 男女皆主求变 |
| 度数 | 12 度 |

**性格关键词**：求变 / 不安稳 / 创新 / 破坏 / 冒险 / 不守旧 / 独行 / 急躁 / 不重传统 / 喜挑战

**优点**：创新力强、不畏改变、有改革精神、对新事物敏感、行动力强
**缺点**：易破财、不耐久、不重传统、易冒险过度、与家人难相处

**关键：破军是"杀破狼格"主角之一**
- 七杀 + 破军 + 贪狼三方四正 = 杀破狼格
- 详见 [03-格局应期/格局/杀破狼.md](../../03-格局应期/格局/杀破狼.md)

**破军的"先破后立"本质**：
- 必先破坏旧秩序才能立新
- 不适合守成、适合改革 / 创业 / 新兴行业
- 30+ 后破中有立，年轻时多损耗

## 3. 现代解释

### 3.1 中州派（王亭之）

破军的核心是**"破"** — 不是单纯破坏，而是**破旧立新**。三种典型：

1. **破军独坐**（在子 / 午 / 寅 / 申）：标准变革命格 / 子位最旺
2. **破军 + 紫微**（丑 / 未）：紫破格 / 帝王 + 变革 / 主大格
3. **破军 + 武曲**（巳 / 亥）：劳碌奔波 / 易破财
4. **破军 + 廉贞**（卯 / 酉）：双复杂格 / 易意外

**破军最适合"新兴行业"** — 科技、互联网、创新创业、改革型组织。

破军在 12 宫意义：

| 宫位 | 破军在此宫的意义 |
|---|---|
| 命宫 | 求变 / 不安稳 / 创新 / 冒险 / 早熟 |
| 兄弟 | 兄弟关系不稳定 |
| **夫妻** | **重灾**：婚姻多变 / 易离异 / 配偶刚硬 |
| 子女 | 子女个性独立 / 不易管教 |
| 财帛 | 财来财去 / 大起大落 / 不擅守财 |
| 疾厄 | 泌尿 / 生殖系统 / 寒湿 / 意外外伤 |
| 迁移 | 外出动荡 / 适合远行打拼 / 出国吉 |
| 交友 | 朋友变动多 |
| 官禄 | 适合创新 / 科技 / 创业 / 改革岗位 / 海外发展 |
| 田宅 | 不动产易变 / 家中变化多 |
| 福德 | 内心不安 / 喜冒险 |
| 父母 | 与父母代沟大 / 易远离家乡 |

### 3.2 飞星派（梁若瑜）

破军化禄（**癸干**）：破中得利 / 变革成功
破军化权（**甲干**）：变革之权 / 主改革
破军**无化科、无化忌**

破军 + 大限化禄 → "破后立"的应期机会窗口。

### 3.3 现代实证派

破军命主在现代**特别适合**：
- 互联网 / 科技创业 / AI / 区块链 / 新能源 / 海外业务 / 改革型组织
- **命主作为 AI 方向硕士**，破军命格是**结构性吻合**

紫云：破军命主**婚姻不稳定度高**，需主动经营 + 选耐变型配偶。

慧心斋主：女命破军**不等于克夫** — 现代女命破军多为**改革型女性 / 创业女性 / 独立性强**。

## 4. 例子（结构性，非实证）

**案例 A**：破军在子（庙旺）

- 性格：变革 + 创新
- 事业：科技 / 创业 / 新兴行业 / 海外业务
- 注意：年轻多动荡，30+ 后渐稳

**案例 B**：紫破格（破军 + 紫微在丑）

- 性格：帝王气 + 变革气
- 事业：政商高位 + 改革派 / 大型组织 CEO
- 注意：与家族 / 传统体制易冲突

**案例 C**：女命破军 + 化禄

- 倾向：改革型女性 / 创业 / 海外发展
- 现代：完全正面，反对古义"克夫"
