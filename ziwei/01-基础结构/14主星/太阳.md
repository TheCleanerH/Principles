# 太阳

## 1. 核心定义

**太阳**（Tài Yáng，Sun Star）：紫微系第三颗主星，光明、博爱、奉献之星。

| 属性 | 内容 |
|---|---|
| 星系 | 紫微系（中天主星之一，与太阴对应） |
| 五行 | 火（丙火） |
| 化气 | 贵（贵气 / 光明 / 正派） |
| 司掌 | 男命：父亲 + 自身 + 官禄 / 女命：丈夫 + 父亲 / 父星 |
| 男女 | 男女有别（古义） |
| 度数 | 12 度 |

**性格关键词**：光明 / 正直 / 博爱 / 慷慨 / 急躁 / 操劳 / 不计回报 / 易疲倦 / 重面子 / 易得罪人

**优点**：心胸宽广、为人公正、有奉献精神、阳光开朗、有领导才能
**缺点**：急躁、操劳过度、付出不求回报易透支、易得罪人（直率）、面子重于实际

**关键：太阳重"庙旺陷"**
- 太阳在**寅 / 卯 / 辰 / 巳 / 午**为**庙旺**（白天 / 上升期），主光明显达
- 太阳在**申 / 酉 / 戌 / 亥 / 子**为**陷**（夜晚 / 下落期），主操劳不显
- 太阳在**未 / 丑** 为利 / 平（边界）

太阳**最忌陷地** — 失辉则操劳无功、易郁。

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷二·诸星问答论·太阳篇》

> 太阳，乃中天之主星，**司光明之曜**，化气为贵，主官禄。

白话翻译（笔者所加）：太阳是中天主星，掌管光明之气，化气贵，主官禄宫。

### 2.2 《紫微斗数全书·卷四·骨髓赋》

> 太阳居午，谓之**"日丽中天"**，有专权之贵，敌国之富。

白话翻译（笔者所加）：太阳在午宫（最旺），主大富大贵，可执掌大权。

### 2.3 《紫微斗数全书·卷四·形性赋》

> 太阳乃**圆满之相**，相貌堂堂。

白话翻译（笔者所加）：太阳坐命的人面相圆满方正，相貌堂堂。

## 3. 现代解释

### 3.1 中州派（王亭之）

太阳的核心是**"奉献"** — 像太阳照大地，不计回报。三种典型：

1. **太阳 + 太阴**（在丑 / 未）：日月并明格，主名利双全 — 但太阳太阴**对峙**也常见冲突
2. **太阳 + 巨门**（在寅 / 申）：太阳化巨门之暗，主清贵；外国 / 跨文化领域有优势
3. **太阳 + 天梁**（在卯 / 酉）：**"日照雷门"**（卯位）/ 太阳偏弱（酉位），司法 / 教育 / 中医 / 顾问

太阳**最关键**：庙旺还是落陷。**陷地太阳的命主必须主动经营事业**，否则操劳无功。

太阳在 12 宫意义（**全部以庙旺为吉**）：

| 宫位 | 太阳在此宫的意义 |
|---|---|
| 命宫 | 阳光命格；男命主自身光明、有领导力；女命主性格男性化 / 事业心强 |
| 兄弟 | 兄弟正直、有事业；陷地则关系疏远 |
| 夫妻 | 男命太阳坐夫妻 = 配偶男性化；女命太阳坐夫妻 = 夫君光明 |
| 子女 | 子女正直、有事业；男孩多于女孩倾向（古义，**待考**） |
| 财帛 | 正财为主，靠光明事业赚钱 |
| 疾厄 | 心血管 / 眼睛 / 头部问题（火气） |
| 迁移 | 外出受人尊重，宜光明事业 |
| 交友 | 朋友层次高、正直 |
| 官禄 | 适合公职 / 体制 / 教育 / 法律 / 媒体 |
| 田宅 | 家中阳光、家族正派 |
| 福德 | 性情开朗 |
| 父母 | 父亲为主导、严肃 / 有事业 |

### 3.2 飞星派（梁若瑜）

太阳化禄（**庚干**）：光明带来财富、事业兴
太阳化权（**辛干**）：太阳之贵显，掌大权
太阳化科（**戊干**？或庚干，**待考**）：名声扬于光明事业
太阳化忌（**甲干**）：父亲 / 男性长辈缘分淡；男命自身受挫；女命配偶有问题

太阳化忌是**男性人物缘分**的核心标志（飞星派立场）。

### 3.3 现代实证派（慧心斋主）

慧心斋主重要观点：**女命太阳坐命**不等于"克夫" — 反而是**女命事业型 / 独立性强**的标志。

紫云观点：太阳的"奉献"特质易导致**情绪透支**，命主必须**学会拒绝**，否则陷地时易抑郁。

## 4. 例子（结构性，非实证）

**案例 A**：太阳在午（日丽中天格）

- 性格：光明磊落、有领导才能
- 事业：公职 / 教育 / 法律 / 大型企业
- 注意：易刚愎、易过劳

**案例 B**：太阳在子（陷地）

- 倾向：奉献多回报少；男命父缘淡 / 自身操劳
- 建议：主动经营人际、控制情绪、学会拒绝
- 反对："太阳陷地必抑郁"的死断

**案例 C**：太阳化忌坐父母宫

- 倾向：与父亲 / 男性长辈关系紧张
- 注意点：成长期需求自我调节；与父对立时双方都需让步
- 反对：直接断"父亲早逝"
