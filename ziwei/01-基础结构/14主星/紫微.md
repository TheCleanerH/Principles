# 紫微

## 1. 核心定义

**紫微**（Zǐ Wēi，Polar Star / Emperor Star）：紫微斗数最重要的主星，地位类比皇帝，故称"帝星"。

| 属性 | 内容 |
|---|---|
| 星系 | 紫微系（北斗主） |
| 五行 | 土（己土，戊土并存说法，主流取己土） |
| 化气 | 尊（尊贵 / 自尊 / 地位） |
| 司掌 | 官禄主（"官禄宫"和"事业"的代表星） |
| 男女 | 男命象征父亲、领导；女命象征自我成就感 / 强势 |
| 度数 | 14 度（古义"度数"指星情强度，14 是中等偏上） |

**性格关键词**：稳重 / 自尊 / 领导欲 / 端庄 / 不容轻慢 / 不擅低头 / 喜被尊敬 / 易孤 / 决策力强 / 重视面子 / 责任感

**优点**：天生具备领导气场，端庄稳重，重视长远规划，有决策力
**缺点**：自尊心过强，难低头，易孤独，喜被奉承（容易被左右），刚愎自用倾向

**紫微在 12 宫的不同表现**：紫微在命 = 帝王命格（看辅星定真高低）/ 在迁移 = 外出受尊重 / 在财帛 = 财位稳重但不擅快进快出 / 在官禄 = 适合体制内或大企业领导 …

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷二·诸星问答论·紫微篇》

> 紫微，**乃中天斗数之主，为众星之枢纽**，为造化之枢机，**人之主宰**，掌**爵禄之司，掌生死之权**，为帝座，号为帝星，化气曰尊。

白话翻译（笔者所加）：紫微星是斗数体系的核心，其他星都围绕它定位，地位类比皇帝。决定爵位、官禄、生死等大事。

### 2.2 《紫微斗数全书·卷四·骨髓赋》

> 紫微居子午，**科权禄拱**，为至贵。

白话翻译（笔者所加）：紫微在子 / 午（北 / 南极轴）位且有化科 / 化权 / 化禄会照时，是大贵格。

### 2.3 《紫微斗数全书·卷四·形性赋》

> 紫微肥满，**面紫色**。

白话翻译（笔者所加）：紫微坐命的人体型偏丰满，面带紫红气色（古人观察，未必绝对）。

### 2.4 《紫微斗数全书·卷四·女命骨髓赋》

> 紫微太阳星，早遇贤夫信可凭。

白话翻译（笔者所加）：女命紫微 + 太阳同宫或会照时，主早婚且配偶可靠。

## 3. 现代解释

### 3.1 中州派（王亭之）

紫微的核心是**"尊"**字 — 不是傲，而是不能被轻慢。三种典型：

1. **得辅佐**（左辅右弼夹 / 文昌文曲会 / 天魁天钺会）：成"君臣庆会格"，主大贵
2. **无辅佐**（孤君无臣）：**孤君无援**，自尊心却不减，反成"孤独的领导"
3. **遭煞冲**（火铃陀羊会照）：自尊心被打击，易抑郁或刚愎自用

紫微在 12 宫意义：

| 宫位 | 紫微在此宫的意义 |
|---|---|
| 命宫 | 帝王命格本质；自尊强、不擅低头；需看辅星定高低 |
| 兄弟 | 兄长 / 合伙人地位高于自己，受其领导 |
| 夫妻 | 配偶端庄、有地位、可能年长 / 阅历多 |
| 子女 | 子女有出息、性格端庄 |
| 财帛 | 财位稳重，正财为主，不擅投机 |
| 疾厄 | 心血管 / 头部 / 脾胃问题（土星之故）；情绪压抑 |
| 迁移 | 外出受尊重，适合远方发展 |
| 交友 | 朋友层次高，但易遇势利之交 |
| 官禄 | 适合体制内 / 大企业管理层 / 公职 |
| 田宅 | 家族环境好，住所讲究 |
| 福德 | 精神追求高，但易自我封闭 |
| 父母 | 父母有地位 / 严格 |

### 3.2 飞星派（梁若瑜）

紫微在飞星派中的解读重四化飞动：

- 紫微化权（**乙干**）：增强领导力 / 主导欲 / 决策硬度
- 紫微化科（**壬干**）：增强名声 / 学术地位 / 端庄气质（部分说法是壬干，**待考**）
- 紫微无化禄、无化忌（紫微不入禄 / 忌的化曜系统，14 主星中比较特殊）

### 3.3 现代实证派（紫云）

紫云强调紫微**孤君**问题：现代命主紫微独坐而无辅佐时，**易陷入"我是中心却没有支持"的孤独感**。建议命主主动培养辅佐（团队 / 合伙人 / 配偶），不可独行。

## 4. 例子（结构性，非实证）

**案例 A**：紫微在午、左辅右弼相夹、文昌文曲三合 — **君臣庆会格**

- 命主性格：端庄威严、领导力强、有团队
- 事业倾向：体制内高位、大企业领导、政治家
- 注意点：易因"被奉承包围"导致信息屏蔽，需主动建"信任的反方"（与命主已学的 Ray Dalio 原则相通）

**案例 B**：紫微在午、无辅星、火铃陀羊会照 — **孤君冲煞**

- 命主性格：自尊强但被现实打击，刚愎、易抑郁
- 事业倾向：可能高位但不稳定 / 早立晚衰
- 注意点：必须主动求外援，否则易自我封闭

**案例 C**：紫微 + 贪狼同宫（仅在卯 / 酉成立）— **桃花犯主格**

- 命主性格：领导欲 + 桃花本能并存
- 事业倾向：娱乐 / 媒体 / 公关 / 应酬密集行业
- 注意点：易因感情或应酬影响事业；可能成于桃花也败于桃花
