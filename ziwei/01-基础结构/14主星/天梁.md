# 天梁

## 1. 核心定义

**天梁**（Tiān Liáng，Star of Shade / Longevity）：天府系主星，荫星、寿星、孤星。

| 属性 | 内容 |
|---|---|
| 星系 | 天府系（南斗第二星，部分主张南斗第三，**待考**） |
| 五行 | 土（戊土） |
| 化气 | 荫（庇荫 / 长寿 / 孤独） |
| 司掌 | 父母荫 / 寿星 / 长辈 / 医药 / 慈善 |
| 男女 | 男女皆主长寿、孤高 |
| 度数 | 12 度 |

**性格关键词**：稳重 / 长辈气 / 慈善 / 孤高 / 不喜世俗 / 喜帮人 / 中医 / 宗教 / 不计回报 / 易孤独

**优点**：性格稳重、有长者风范、善于解人危难、长寿、有医道天赋
**缺点**：太孤高、不通人情 / 易曲高和寡、易孤独 / 不易结婚或晚婚

**关键：天梁与"父母荫"的关系**
- 天梁主"长辈助力"和"父母庇荫"
- 天梁庙旺 → 早年得长辈助 / 父母条件好
- 天梁陷地 → 早失父助 / 自立早

**天梁是"老年宜居"星**：年长越有福；年轻时反而显得格格不入。

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷二·诸星问答论·天梁篇》

> 天梁，南斗**司寿之星**，**化气为荫**，**主**寿、解厄、**父母**。

白话翻译（笔者所加）：天梁是南斗司寿之星，化气为荫，主长寿、解厄、父母庇荫。

### 2.2 《紫微斗数全书·卷四·骨髓赋》

> 天梁**月曜**，女命**贱而且淫**。

白话翻译（笔者所加）：天梁 + 月（太阴）在女命，古义贬为"贱淫"。

**慧心斋主明确反对此句**：现代女命天梁 + 太阴常为**慈悲 + 母性 + 多情**，并无"贱淫"含义。古义反映封建时代偏见，应批判性弃用。

### 2.3 《紫微斗数全书·卷四·形性赋》

> 天梁**性傲清高**。

白话翻译（笔者所加）：天梁坐命者性格清高傲然。

## 3. 现代解释

### 3.1 中州派（王亭之）

天梁的核心是**"荫"** — 受荫 + 庇荫他人。三种典型：

1. **天梁独坐**（在子 / 午 / 丑 / 未 / 寅 / 申）：标准长者命格
2. **天梁 + 太阳**（卯 / 酉）：日照雷门格（卯位最旺）/ 主清贵 / 司法 / 教育
3. **天梁 + 天机**（辰 / 戌）：机梁格 / 智 + 荫 / 中医 / 顾问

**天梁特别忌"孤独"**：
- 天梁 + 孤辰 / 寡宿 → 孤独感强
- 天梁 + 化禄 → 主"自来财" 但易引争议（**飞星派"天梁化禄不喜"说**）

天梁在 12 宫意义：

| 宫位 | 天梁在此宫的意义 |
|---|---|
| 命宫 | 稳重 + 长者气 / 清高 / 慈善 |
| 兄弟 | 兄弟年长 / 受其荫 |
| 夫妻 | 配偶年长 / 稳重 / 有长者气 |
| 子女 | 子女稳重 / 早熟 |
| 财帛 | 财源稳 / 有长辈助 / 不重财 |
| 疾厄 | 脾胃 / 长寿 / 慢性病多 |
| 迁移 | 外出受长辈助 |
| 交友 | 朋友层次高 / 多长辈型 |
| 官禄 | 适合教育 / 医药 / 法律 / 顾问 / 慈善 / 公职 |
| 田宅 | 家族传承 / 不动产 |
| 福德 | 内心清高 / 喜慈善 |
| 父母 | 父母年长 / 有长辈风范 |

### 3.2 飞星派（梁若瑜）

天梁化禄（**壬干**）：**飞星派认为不喜** — 天梁本是"清贵不爱财"，化禄反引争议 / 是非财
天梁化权（**乙干**）：天梁之权显，主长辈型权威
天梁化科（**己干**）：天梁清名扬，学术 / 医道扬名
天梁**无化忌**

天梁化禄的"不喜"是飞星派的特别说法，与中州派看法略有差异。

### 3.3 现代实证派

天梁命主在现代特别适合**长者型职业**：教师、医生（特别中医）、顾问、律师（资深）、慈善机构、心理咨询师、宗教从业者。

紫云：天梁命主**晚婚率高**，30+ 后婚姻更稳。年轻时不必勉强配对。

慧心斋主：**坚决反对**古籍"天梁月曜女命贱淫"说，现代女命天梁多为慈悲、母性、有情怀的女性。

## 4. 例子（结构性，非实证）

**案例 A**：日照雷门格（天梁 + 太阳在卯）

- 性格：光明 + 长者气
- 事业：司法 / 教育 / 中医 / 公职
- 注意：清高易得罪人

**案例 B**：机梁格（天梁 + 天机在辰）

- 性格：智 + 慈
- 事业：中医 / 顾问 / 心理咨询师 / 教育研究
- 注意：易曲高和寡

**案例 C**：天梁化禄（飞星派"不喜"说）

- 倾向：本不爱财却得财 → 引争议 / 是非财
- 建议：得财后低调处理，避免引人嫉妒
