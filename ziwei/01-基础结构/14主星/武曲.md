# 武曲

## 1. 核心定义

**武曲**（Wǔ Qǔ，Wealth Star / Martial Star）：紫微系第四颗主星，财星 + 将星双重身份。

| 属性 | 内容 |
|---|---|
| 星系 | 紫微系（北斗第六星） |
| 五行 | 金（辛金） |
| 化气 | 财（财富 / 决断 / 刚硬） |
| 司掌 | 财帛主（"财帛宫"的核心代表星） |
| 男女 | 男命主财 / 武职；女命因金气过刚易孤 |
| 度数 | 12 度 |

**性格关键词**：刚毅 / 决断 / 重财 / 直率 / 不善表达 / 行动派 / 不重感情 / 适合武职或财务

**优点**：行动力强、决断快、理财能力强、不畏挑战、有义气
**缺点**：太过刚硬、不擅表达感情、易孤独、易因钱与感情冲突、性格冷

**关键格局**：
- **武曲 + 贪狼**（在丑 / 未）：先贫后富格 / 大运后期发财
- **武曲 + 七杀**（在卯 / 酉）：因财持刀格 / 须防意外刑伤
- **武曲 + 破军**（在巳 / 亥）：劳碌奔波 / 易破财
- **武曲 + 天府**（在子 / 午）：财库丰盈格 / 稳健财
- **武曲 + 天相**（在寅 / 申）：印星合财 / 公职财

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷二·诸星问答论·武曲篇》

> 武曲，北斗第六星也，**化气为财**，**司天上掌财权**，**乃将星**，威猛刚直。

白话翻译（笔者所加）：武曲是北斗第六星，化气为财，掌天上财权，是"将星"，性威猛刚直。

### 2.2 《紫微斗数全书·卷四·骨髓赋》

> 武曲庙垣，**威名赫赫**。
> 武曲贪狼，**先贫而后富**。

白话翻译（笔者所加）：武曲在庙旺位主威名显赫；武曲贪狼同宫主早年贫困晚年富贵。

### 2.3 《紫微斗数全书·卷四·形性赋》

> 武曲乃**短小之资**，性刚果决。

白话翻译（笔者所加）：武曲坐命的人身材偏短小，性格刚毅决断。

## 3. 现代解释

### 3.1 中州派（王亭之）

武曲的核心是**"硬"** — 性格硬、行动硬、对钱也硬。三种典型：

1. **武曲独坐**（在辰 / 戌 / 丑 / 未）：庙旺位主财，但需配辅星定档次
2. **武曲化禄**（己干）：财源旺；流年走至大利
3. **武曲化忌**（壬干）：金气受伤 — 主**破财 / 手术 / 牙齿 / 呼吸道 / 金属外伤**

武曲在 12 宫意义：

| 宫位 | 武曲在此宫的意义 |
|---|---|
| 命宫 | 性格刚硬、行动派、重钱不善情；适合武职 / 财务 / 工程 |
| 兄弟 | 兄弟性格刚 / 不易亲近，但讲义气 |
| **夫妻** | **重灾**：武曲性刚加金气克木，主婚姻冷淡 / 易冲突；女命武曲坐夫妻易克夫古义（**慧心斋主反对字面理解**） |
| 子女 | 子女性格刚 / 与父母交流少 |
| 财帛 | 财帛主驻财帛宫 — **本位极旺**，主财源丰且稳 |
| 疾厄 | 呼吸道 / 牙齿 / 金属外伤 / 手术 |
| 迁移 | 外出主财，宜远方发展 |
| 交友 | 朋友讲义气，但易因钱反目 |
| 官禄 | 适合财务 / 工程 / 武职 / 金融 / 制造 |
| 田宅 | 不动产稳定 |
| 福德 | 享受少，心性刚硬 |
| 父母 | 父母严格 / 不善表达 |

### 3.2 飞星派（梁若瑜）

武曲化禄（**己干**）：财源旺、行动派 + 财
武曲化权（**庚干**）：财权强、决策硬
武曲化科（**甲干**）：财名兼得、稳健形象
武曲化忌（**壬干**）：破财 / 手术 / 金属伤 / 呼吸道问题 / 婚姻寒（夫妻宫见）

武曲化忌坐夫妻宫是飞星派**最严重的婚姻警告**之一。

### 3.3 现代实证派

陆斌兆（八字嫁接派）观点：武曲命主**最适合"实业型"经济活动**（制造、工程、金融实务），不适合"投机型"（赌、股票短线）。**待实证**。

慧心斋主：女命武曲不等于"克夫" — 现代社会女命武曲多为**事业型女强人**、企业家、财务高管。

## 4. 例子（结构性，非实证）

**案例 A**：武曲 + 天府坐财帛宫（财库丰盈格）

- 性格：理财稳健、不冒险
- 事业：财务 / 投资 / 实业
- 注意：太稳易错过机会

**案例 B**：武曲 + 贪狼在丑（先贫后富格）

- 倾向：大运转换期发财、晚发
- 注意：早年勿急功近利

**案例 C**：女命武曲化忌坐夫妻宫

- 倾向：婚姻冷淡 / 易因钱与配偶冲突
- 建议：婚前充分沟通财务观，建议婚后财务独立 + 共同账户结合
- 反对：直接断"必离婚"
