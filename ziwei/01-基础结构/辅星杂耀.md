# 辅星杂耀

## 1. 核心定义

**辅星杂耀**：14 主星以外的所有星曜的统称。

紫微斗数除 14 主星外，约有**100+ 颗辅星 / 杂耀**。本笔记按以下分层组织：

```
辅星杂耀
├─ 六吉（增辉）：左辅、右弼、文昌、文曲、天魁、天钺
├─ 禄存（财禄主星）
├─ 六煞（减辉 / 激变）：火星、铃星、擎羊、陀罗、地空、地劫
├─ 四化（动态变量）：化禄、化权、化科、化忌
│   └─ 详见 02-动态系统/四化-禄权科忌.md
└─ 杂耀（修饰性，谨慎使用）：天马、天刑、天姚、红鸾、天喜、孤辰、寡宿、华盖、咸池、天空、截空、旬空、解神 等
```

**核心原则**（中州派立场）：
- 辅星杂耀**不能独立定吉凶**
- 必须与**主星 + 三方四正 + 四化**联合判读
- 杂耀只作**修饰** / 修色，不作单独结论

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷一·安星诀》

> **左辅右弼**生月安，**文昌文曲**生时安，**天魁天钺**生年干安，**禄存**生年干安，**擎羊陀罗**禄存前后安，**火星铃星**生年支与时安，**地空地劫**生时安。

白话翻译（笔者所加）：辅星的安立各有规则，分别由生月 / 生时 / 生年干 / 生年支 决定（详见下文表格）。

### 2.2 《紫微斗数全书·卷四·骨髓赋》

> 左辅文昌会**吉星**，**尊居八座**。
> 右弼天相福**来临**，左右单守命宫，离宗庶出。

白话翻译（笔者所加）：左辅右弼 + 文昌（吉星会聚）主大贵；但左右单守命宫（仅一颗辅星会照而无主星）反主出身复杂（古夸张说法）。

URL：https://ctext.org/wiki.pl?if=gb&res=857569 — 访问 2026-05-27

## 3. 现代解释 — 逐组详解

### 3.1 六吉（增辉之星）

| 星名 | 五行 | 主意义 | 安星依据 |
|---|---|---|---|
| **左辅** | 土 | 辅佐 / 助力 / 兄弟 / 同事帮助 | 生月顺数 |
| **右弼** | 土 | 辅佐 / 助力 / 姐妹 / 异性贵人 | 生月逆数 |
| **文昌** | 金 | 文星 / 学业 / 理科逻辑 / 文书 | 生时顺数 |
| **文曲** | 水 | 文星 / 才艺 / 文科口才 / 异性缘 | 生时逆数 |
| **天魁** | 火 | 阳贵人 / 男性长辈贵人 / 提携 | 生年干（六甲子序列） |
| **天钺** | 火 | 阴贵人 / 女性长辈贵人 / 提携 | 生年干 |

**六吉关键点**：
- **左辅 + 右弼**同宫或夹命宫：**大助力格**
- **文昌 + 文曲**同宫或夹命宫：**学业 / 才艺 / 文化职业**最有利
- **天魁 + 天钺**会照：**贵人提携**多
- **六吉俱全**会照：**君臣庆会格**（紫微 + 六吉合）— 详见 [03-格局应期/格局/君臣庆会.md](../03-格局应期/格局/君臣庆会.md)

**反对**：单一辅星不构成"吉" — 古籍"左右单守离宗庶出"现代不取字面理解。

### 3.2 禄存

| 星名 | 五行 | 主意义 | 安星依据 |
|---|---|---|---|
| **禄存** | 土 | 财禄 / 储蓄 / 衣食 / 稳定收入 | 生年干 |

**禄存关键点**：
- 禄存是**常驻财星**，与"化禄"不同（化禄是动态化气）
- 禄存 + 主星财位 → **大富格**之一
- 禄存周围必有**擎羊（前）+ 陀罗（后）** — 二煞夹禄存，主**财气有保护但不可外露**
- 古义"羊陀夹忌"：禄存 + 化忌同宫 → 羊陀夹忌格 → 重灾（详见下文）

**禄存 vs 化禄区别**：

| 项 | 禄存 | 化禄 |
|---|---|---|
| 性质 | 常驻星 | 化气（动态） |
| 安立 | 生年干 | 生年干引主星化禄 |
| 表现 | 稳定财气 | 主星之财激发 |
| 周围 | 必夹羊陀 | 不一定 |
| 流年 | 看落宫 | 看大限 / 流年化曜 |

### 3.3 六煞（减辉 / 激变之星）

| 星名 | 五行 | 主意义 | 安星依据 |
|---|---|---|---|
| **火星** | 火 | 暴烈 / 突发 / 冲突 / 急躁 | 生年支 + 生时 |
| **铃星** | 火 | 阴火 / 持久火 / 内伤 / 慢性冲突 | 生年支 + 生时 |
| **擎羊**（羊刃） | 金 | 刑伤外伤 / 外露之煞 / 直接冲突 | 禄存前一宫 |
| **陀罗** | 金 | 拖延内伤 / 暗中煞 / 反复 | 禄存后一宫 |
| **地空** | 火 | 思想空 / 灵性 / 出世 / 内空 | 生时顺数 |
| **地劫** | 火 | 物质劫 / 破财 / 入世之劫 / 外劫 | 生时逆数 |

**六煞关键点**：

1. **火星 + 铃星**：与贪狼同宫 → **火贪 / 铃贪格**（暴发格，反凶为吉）
2. **擎羊 + 陀罗**：禄存前后夹击，二煞紧贴禄存
3. **地空 + 地劫**：
   - 与贪狼同宫 → 欲望被空，反成清心
   - 与化禄同宫 → 财气被劫，破财
   - 与紫微同宫 → 帝星空虚，孤君
4. **羊陀夹忌**：禄存 + 化忌同宫，且擎羊陀罗夹 → 重灾格（详见下文）

**六煞**并非全是坏 — **激发型煞星**可成大格局（火贪 / 铃贪 / 化煞为权）。中州派强调"煞星需具体看其相位"，反对"见煞即凶"。

### 3.4 四化（动态变量）

详见 [02-动态系统/四化-禄权科忌.md](../02-动态系统/四化-禄权科忌.md)。

简表：

| 化曜 | 主意义 |
|---|---|
| **化禄** | 财利 / 贵人缘 / 增益 / 顺利 |
| **化权** | 权力 / 主导 / 强化 / 争胜 |
| **化科** | 名声 / 学业 / 缓和 / 文教 |
| **化忌** | 阻滞 / 是非 / 损耗 / 执念 |

### 3.5 杂耀（修饰性，谨慎使用）

| 星名 | 主意义 | 项目立场 |
|---|---|---|
| **天马** | 驿马 / 迁移 / 外出 / 行业流动 | 中性，常用。**重要**：天马是判断"出国 / 异地发展"的关键星 |
| **天刑** | 刑罚 / 自律 / 医术 / 法律 | 中性，与廉贞 / 武曲组合主法律或医疗职业 |
| **天姚** | 桃花 / 应酬 / 人际魅力 | 中性，**不与"咸池"混说邪淫** |
| **红鸾** | 婚喜 / 桃花 | 仅作修饰，不单独定婚期 |
| **天喜** | 婚喜 / 喜事 | 同上 |
| **孤辰** | 孤独感 | **反对**"必孤独"死断 |
| **寡宿** | 寡居感 / 同孤辰 | 同 |
| **华盖** | 孤高 / 宗教 / 艺术倾向 | **反对**"必出家"死断 |
| **咸池**（沐浴） | 古义桃花 | **反对**单独以咸池论邪淫 |
| **天空** | 空亡 / 超脱 | 中性 |
| **截空** | 时间性空亡（截断） | 修饰，不独断 |
| **旬空** | 时间性空亡（旬内） | 修饰，不独断 |
| **解神** | 解厄 / 化解灾难 | 中性，需配合主星 |
| **天巫** | 升迁 / 遗产 | 修饰 |
| **三台 / 八座** | 文教贵气 / 仪表 | 修饰 |
| **恩光 / 天贵** | 贵气 / 名声 | 修饰 |

**杂耀使用纪律**（中州派强调）：
- 杂耀**只修饰 / 修色**主星结论，不作单独结论
- 古义"咸池 / 桃花 → 邪淫" 一概**反对**
- 古义"孤辰寡宿 → 必孤独" 一概**反对**
- 古义"华盖 → 必出家" 一概**反对**

## 4. 例子（结构性，非实证）

### 4.1 君臣庆会格（左右昌曲魁钺会聚）

紫微在午 + 左辅右弼夹 + 文昌文曲三合 + 天魁天钺会照
→ **君臣庆会格** → 主大贵 + 大格局

### 4.2 火贪格（六煞激发主星）

贪狼在子 + 火星同宫
→ **火贪格** → 突发机遇 / 暴发但易暴落

### 4.3 羊陀夹忌（六煞 + 化忌组合，重灾）

禄存在卯 + 巨门化忌（坐卯）+ 擎羊在辰 + 陀罗在寅
→ **羊陀夹忌** → **重灾格**：财气受冲 + 化忌煞气夹击

**应对**：大限 / 流年走至该宫时，避险驾驶 / 远离法律边界 / 不冒险投资。

### 4.4 文星不显（文昌单见，无文曲）

文昌坐命无文曲会照 → 仅理科逻辑型
**反对**：单守不必"离宗"古义。

## 5. 流派分歧

| 议题 | 中州派 | 飞星派 | 现代 |
|---|---|---|---|
| 杂耀地位 | 修饰性，不独断 | 同 | 同 |
| 六煞激发主星 | 主流认同（火贪 / 铃贪等） | 同 | 同 |
| 羊陀夹忌严重性 | 重灾 | **极凶** | 同 |
| 君臣庆会要素 | 左右昌曲魁钺 + 紫微 | 同 | 同 |
| 古义贬义杂耀 | 反对死断 | 反对 | **明确反对** |
