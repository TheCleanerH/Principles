# 12 宫位

## 1. 核心定义

**12 宫位**：紫微斗数命盘的核心坐标系，将人生分为 12 个领域，每个宫位对应一类人生主题。命主的每个人生层面都"住在"某个宫，宫内的主星 + 辅星 + 四化共同决定该层面的形态与变化。

12 宫名（按顺序）：

| 序 | 宫名 | 别称 | 一句话主管 |
|---|---|---|---|
| 1 | **命宫** | — | 本人核心人格 / 一生大方向 |
| 2 | **兄弟宫** | — | 同辈关系 / 合作伙伴 / 兄弟姐妹 |
| 3 | **夫妻宫** | — | 配偶 / 感情对象 / 婚姻状态 |
| 4 | **子女宫** | — | 子女 / 性 / 创造力 / 下属 |
| 5 | **财帛宫** | — | 现金流 / 理财观 / 财富获取方式 |
| 6 | **疾厄宫** | — | 健康 / 灾厄 / 情绪 / 体质 |
| 7 | **迁移宫** | — | 外出 / 旅行 / 外部环境 / 远方机遇 |
| 8 | **交友宫** | 奴仆宫 | 朋友 / 下属 / 同事 / 人际网络（古义"奴仆"，现代多用"交友"） |
| 9 | **官禄宫** | 事业宫 | 事业 / 工作 / 官运 / 学业（学生时代） |
| 10 | **田宅宫** | — | 房产 / 家族环境 / 居住氛围 / 不动产 |
| 11 | **福德宫** | — | 精神面貌 / 福分 / 享受 / 嗜好 / 内在动机 |
| 12 | **父母宫** | — | 父母 / 长上 / 文书 / 学业（早年） |

**关键认知**：12 宫之间**不孤立**。任何一宫的解读必须看其**三方四正**（本宫 + 对宫 + 两个三合宫），共 4 宫联动。

**身宫**：叠加在 6 宫之一（命 / 夫妻 / 财帛 / 迁移 / 官禄 / 福德），代表后天发力点。详见 [排盘原理.md §3.2](./排盘原理.md)。

## 2. 古籍出处

### 2.1 12 宫名总论（《紫微斗数全书·卷一》）

> 《紫微斗数全书·卷一·安十二宫例》：
> > **命、兄弟、夫妻、子女、财帛、疾厄、迁移、奴仆、官禄、田宅、福德、父母**，共一十二宫。

白话翻译（笔者所加）：以上 12 宫覆盖人生主要领域，从自身到亲属到事业到内心。

### 2.2 命宫的根本地位

> 《紫微斗数全书·卷一·命宫》：
> > 命宫者，所主之宫也，**总论一生之贵贱、寿夭、贫富、吉凶**。

白话翻译（笔者所加）：命宫是看一个人整体格局高低的总宫，最关键。

### 2.3 太微赋（论 12 宫互联）

> 《紫微斗数全书·卷四·太微赋》：
> > 命无正曜，**夭折孤贫**；吉星入庙，则得**贵之相**。
> > **诸宫吉凶相杂**，须看强弱以推之。

白话翻译（笔者所加）：命宫无主星时（"命无正曜"），需借助对宫和三合宫推断。各宫之间的吉凶要综合权衡，不可只看单宫。

（**待考**：上文"命无正曜，夭折孤贫"是骨髓赋原句，现代学者反对字面理解 — 详见 [流派立场.md §2 反对清单](../00-元知识/流派立场.md)）

## 3. 现代解释（逐宫详解）

### 3.1 命宫

| 维度 | 内容 |
|---|---|
| **核心** | 本人核心人格、价值观、人生大方向、一生主要走势 |
| **看什么** | 命主是什么类型的人；先天本质 |
| **主星意义** | 命宫主星 = 命主"主导人格"。紫微 / 武曲 / 七杀的人和天同 / 太阴的人活法完全不同 |
| **命无正曜** | 命宫无 14 主星时，借对宫（迁移宫）主星看 — 现代不再字面理解古籍"夭折孤贫"，反而常见"灵活、外向、依环境而变"的命格 |
| **与子平派对照** | 类比"日主 + 月令"功能，但紫微以"人格画像"为核心，比子平五行能量结构更直观 |
| **三方四正联动** | 命宫 + 迁移（对宫）+ 财帛（三合）+ 官禄（三合）= **命三方** |

**中州派要点**（王亭之）：命宫主星看"本质"，迁移宫主星看"环境对其的塑造"。命迁两宫合看是最基础的分析。

### 3.2 兄弟宫

| 维度 | 内容 |
|---|---|
| **核心** | 同辈关系（兄弟姐妹、合作伙伴、好友） |
| **看什么** | 命主与同辈的相处模式；是否有助力 / 竞争 / 冲突 |
| **现代延伸** | 商业合伙人、创业搭档、合作关系 |
| **三方四正** | 兄弟 + 交友（对宫）+ 父母（三合）+ 子女（三合）= **兄弟三方** |

**反对**：古籍"兄弟宫主星多则兄弟多"的字面理解 — 现代社会兄弟数受计划生育等政策影响，不能直接推。

### 3.3 夫妻宫

| 维度 | 内容 |
|---|---|
| **核心** | 配偶形象、婚姻状态、亲密关系模式 |
| **看什么** | 命主选什么样的配偶；婚姻吉凶；感情起伏 |
| **关键洞察** | 夫妻宫不仅看配偶，更看**命主自己在亲密关系里的样子**（投射） |
| **三方四正** | 夫妻 + 官禄（对宫）+ 福德（三合）+ 迁移（三合）= **夫妻三方** |

**慧心斋主立场**：女命夫妻宫不只代表"夫"，**更代表女命自己在婚姻中的状态**。反对"夫妻宫好坏决定女命一生"的旧说。

**紫云"三十六岁前后论"**：36 岁前主要看命宫 + 父母宫（受原生家庭塑造）；36 岁后看夫妻宫 + 福德宫（自我成熟期主导）。

### 3.4 子女宫

| 维度 | 内容 |
|---|---|
| **核心** | 子女 / 性 / 创造力 / 下属 |
| **看什么** | 与子女缘分；性生活质量；创造性输出能力；带领下属能力 |
| **现代延伸** | 创业者的"作品 / 产品" 也归子女宫看（创造性产出） |
| **三方四正** | 子女 + 田宅（对宫）+ 兄弟（三合）+ 疾厄（三合） |

**反对**：古籍"子女宫凶则无子"的死断 — 现代生育受医学 / 政策 / 个人选择多重因素影响。

### 3.5 财帛宫

| 维度 | 内容 |
|---|---|
| **核心** | 现金流、理财观、财富获取方式 |
| **看什么** | 命主如何赚钱；钱的来源 / 流向；理财态度 |
| **关键区分** | 财帛宫 = 现金流 / 田宅宫 = 不动产 / 福德宫 = 享受。三宫合看才是"财富全貌" |
| **三方四正** | 财帛 + 福德（对宫）+ 命宫（三合）+ 官禄（三合） |

**反对**：报具体金额（"百万""千万"）。详见 [流派立场.md](../00-元知识/流派立场.md)。

### 3.6 疾厄宫

| 维度 | 内容 |
|---|---|
| **核心** | 健康、灾厄、情绪、体质 |
| **看什么** | 命主体质倾向（如易得心脏 / 消化 / 神经类疾病）；情绪稳定性；意外灾厄风险 |
| **关键** | 疾厄宫的星情对应**身体部位**和**疾病类型**，需配合中医脏腑学说理解 |
| **三方四正** | 疾厄 + 父母（对宫）+ 兄弟（三合）+ 子女（三合） |

**严格立场**：紫微疾厄宫给出的是**倾向**和**风险点**，不是医学诊断。**任何身体不适都应先就医，不能依命理判断**。

### 3.7 迁移宫

| 维度 | 内容 |
|---|---|
| **核心** | 外出、旅行、外部环境、远方机遇 |
| **看什么** | 命主在外发展是否顺利；出国 / 异地是否合适；外人对其评价 |
| **关键** | 迁移宫是**命宫的对宫**，二宫合看才是命主"本我 + 环境表达"全貌 |
| **三方四正** | 迁移 + 命宫（对宫）+ 福德（三合）+ 夫妻（三合） |

**对韩国留学命主特别重要**：迁移宫直接关系"是否适合留学 / 异国发展"。

### 3.8 交友宫（奴仆宫）

| 维度 | 内容 |
|---|---|
| **核心** | 朋友、下属、同事、人际网络 |
| **看什么** | 命主结交什么样的朋友；朋友圈是否对其有助力；下属是否听话 / 得力 |
| **古义** | 古称"奴仆宫"（封建社会主仆关系）；现代用"交友宫"更准确 |
| **三方四正** | 交友 + 兄弟（对宫）+ 田宅（三合）+ 父母（三合） |

### 3.9 官禄宫（事业宫）

| 维度 | 内容 |
|---|---|
| **核心** | 事业、工作、官运、学业（学生时代） |
| **看什么** | 命主适合什么行业；事业起伏；是否能升迁 / 立业 |
| **关键** | 官禄宫主星 → 职业倾向；化禄化权化忌 → 事业起落时机 |
| **三方四正** | 官禄 + 夫妻（对宫）+ 命宫（三合）+ 财帛（三合）= **事业三方** |

**学生阶段**：官禄宫主要看学业；进入职场后切换为事业。

### 3.10 田宅宫

| 维度 | 内容 |
|---|---|
| **核心** | 房产、家族环境、居住氛围、不动产 |
| **看什么** | 命主是否有房产；家族环境（原生家庭氛围）；居住环境对其影响 |
| **现代延伸** | 长期投资标的（不动产、长期资产）；公司（如果命主创业，公司归田宅宫看） |
| **三方四正** | 田宅 + 子女（对宫）+ 交友（三合）+ 疾厄（三合） |

### 3.11 福德宫

| 维度 | 内容 |
|---|---|
| **核心** | 精神面貌、福分、享受、嗜好、内在动机 |
| **看什么** | 命主心理状态；是否享受人生；兴趣爱好；内在驱动力 |
| **关键** | 福德宫好 → 即使外在条件一般也能**心安自得**；福德宫差 → 即使富贵也**心烦意乱** |
| **三方四正** | 福德 + 财帛（对宫）+ 夫妻（三合）+ 迁移（三合） |

**慧心斋主重点**：女命福德宫极重要，关系一生**精神福分**。反对"以夫为天"的旧说。

**反对**："福德宫差就该出家"的死断 — 福德宫的解读必须配合命宫看，不能孤立断。

### 3.12 父母宫

| 维度 | 内容 |
|---|---|
| **核心** | 父母、长上、文书、学业（早年） |
| **看什么** | 与父母缘分；早年家庭环境；学业（特别是 36 岁前）；与长辈关系 |
| **关键** | 父母宫**主早年塑造**，紫云"三十六岁前后论"强调 36 岁前的人格 60-70% 由父母宫决定 |
| **三方四正** | 父母 + 疾厄（对宫）+ 交友（三合）+ 兄弟（三合） |

## 4. 例子（结构性，非实证）

### 4.1 三方四正 — 命三方示例

**虚构案例**：紫微在午、武曲在寅、廉贞在戌（命宫在午紫微独坐）

```
        ┌────┐
        │ 福 │
        ├────┤
        │ 田 │
   ┌────┼────┼────┐
   │ 官 │ 命 │ 迁 │  ← 命宫午（紫微）+ 迁移子（贪狼对照）
   ├────┤    ├────┤
   │ 友 │    │ 疾 │
   └────┴────┴────┘
        │ 兄 │
        ├────┤
        │ 夫 │
```

**命三方** = 命宫（午 · 紫微）+ 迁移（子 · 贪狼）+ 财帛（寅 · 武曲）+ 官禄（戌 · 廉贞）

**联动判读**：
- 命宫紫微 → 主性格端庄、有领导欲
- 财帛武曲 → 重财、理财严谨（"财帛主"驻财帛宫，本位）
- 官禄廉贞 → 事业带"次桃花"色彩，可能涉公关 / 文创 / 政界
- 迁移贪狼 → 外出多机遇 / 应酬 / 桃花
- **结论倾向**：命主适合公关 / 政界 / 文创类事业；理财能力强；外出有助力 + 桃花

**反对**：上述只是**结构性倾向**，不构成"命主一定如此"的预言。

### 4.2 命无正曜处理

如果命宫无 14 主星，看对宫（迁移宫）主星：
- 借迁移主星视作命宫主星（中州派做法）
- 命主性格更依赖外部环境塑造，**未必"夭折孤贫"**（古义已不适用现代）

## 5. 流派分歧

| 议题 | 中州派 | 飞星派 | 慧心斋主 |
|---|---|---|---|
| 命无正曜 | 借对宫看 | 借对宫 + 看四化飞星 | 同 |
| 夫妻宫女命解读 | 看夫为主 | 看夫 + 四化飞动 | **看自己在婚姻中的状态**为主，反对"看夫" |
| 父母宫与命宫关系 | 二宫并看 | 二宫并看 + 四化飞动 | 紫云尤重"36 岁前父母塑造"论 |
| 福德宫地位 | 中等重要 | 同 | **尤其重要**（女命） |
| 官禄宫 vs 财帛宫主次 | 官禄主"事业方向"、财帛主"赚钱方式"，并重 | 同 | 同 |

## 6. 待考疑问

1. 12 宫的对宫和三合宫关系是否每宫都按"相隔 6 位 = 对宫，相隔 4 位 = 三合"严格成立？— 是的，盘面结构如此，无例外
2. 身宫叠加宫位对解读的优先级（35 岁前是否完全不影响？35 岁后是否覆盖叠加宫位）— 紫云说有"权重转移"，但具体阈值不严格
3. 现代"无亲生子女但有领养 / 试管"，子女宫如何解读 — 待与现代实证派对照
4. 同性恋命主的夫妻宫解读 — 现代命理体系尚无成熟方法学，**待研究**
