# 飞星派四化补充（辅线）

## 1. 核心定义

> ⚠️ **本笔记内容为辅线**。本项目主线为中州派 + 三合派传统。本笔记记录飞星派的核心方法，便于横向理解和分辨流派分歧，但**不替代中州派结论**。

**飞星派**（亦称**钦天四化派**）：以**四化飞星**为核心方法的紫微斗数现代流派。

**核心区别于中州派**：
- 中州派：四化是"附在主星上的化曜"，看落宫
- 飞星派：四化在**宫位之间互飞** — 命宫飞财宫、财宫飞夫宫…形成"四化轨迹"

| 维度 | 中州派 | 飞星派 |
|---|---|---|
| 四化静态 | 落宫意义 | 起点宫位 |
| 四化动态 | 大限 / 流年触发 | **本命宫位间互飞** |
| 自化概念 | 不强调 | **核心概念** |
| 应期细化 | 流年颗粒度 | 流年 + 飞星轨迹 |
| 系统复杂度 | 中等 | 高 |
| 易过度解读 | 较少 | **较多** |

## 3. 现代解释

### 3.1 飞星派的核心概念

#### 3.1.1 生年四化（本命四化）

由生年天干引发的 4 颗化曜，与中州派同。是飞星派的**起点**。

#### 3.1.2 宫位四化（飞星）

**每个宫位都有自己的天干**（按"五虎遁"由生年干推算 12 宫天干）

每个宫位天干都能引发**4 颗化曜**，飞向 12 宫的对应主星。这些化曜形成"飞星轨迹"。

例：某命主命宫天干为戊
- 戊干四化：贪狼化禄 / 太阴化权 / 右弼化科 / 天机化忌
- 即**命宫飞出"贪狼化禄"** → 看本命盘上贪狼在哪宫 → 该宫被"命宫禄入"

#### 3.1.3 自化（飞星派核心）

**自化**：宫位自身天干引发的化曜，**正好附在该宫的主星上**。

例：某宫天干为甲，宫内主星为廉贞 → 甲干廉贞化禄 → **该宫自化禄**

自化分 4 种：
- **自化禄**：宫位天干 → 化禄主星 = 宫内主星 → 该宫"自化禄"
- **自化权**：宫位天干 → 化权主星 = 宫内主星 → 该宫"自化权"
- **自化科**：宫位天干 → 化科主星 = 宫内主星 → 该宫"自化科"
- **自化忌**：宫位天干 → 化忌主星 = 宫内主星 → 该宫"自化忌"

#### 3.1.4 飞星派的"四化飞动"组合

| 飞星组合 | 意义 |
|---|---|
| 禄入 | 该宫被 X 宫"送来"化禄 → X 宫之利输入 |
| 禄出 | 该宫飞化禄至 X 宫 → 本宫之利输出 |
| 忌入 | 该宫被 X 宫"送来"化忌 → X 宫之祸输入 |
| 忌出 | 该宫飞化忌至 X 宫 → 本宫之祸输出 |
| 双忌 | 两宫互飞化忌 → 重灾 |
| 禄忌交 | 同宫禄忌并存 → 利祸并存 |

### 3.2 飞星派的"看盘流程"（简化）

1. 起本命盘 + 生年四化
2. 推 12 宫天干（五虎遁）
3. 每宫飞 4 化 → 形成"四化网"
4. 看**生年四化 + 宫位互飞 + 自化** 三层叠加
5. 大限 / 流年同样飞 4 化
6. 综合判读

### 3.3 飞星派与中州派的"看盘焦点差异"

| 焦点 | 中州派 | 飞星派 |
|---|---|---|
| 主星本质 | **重** | 轻 |
| 三方四正 | **重** | 中等 |
| 四化飞动 | 中等 | **重** |
| 自化 | 不取 | **重** |
| 杂耀 | 修饰 | 修饰 |
| 应期推法 | 大限 → 流年 | 大限 → 流年 + 飞星触发 |

### 3.4 飞星派的"易过度解读"风险

飞星派系统复杂，**每宫 4 化 × 12 宫 = 48 颗化曜**飞来飞去，加上自化、生年四化、大限四化、流年四化，**信息量爆炸**。

**风险**：
- **过拟合**：用 48 颗化曜中的"巧合组合"解释任何已发生的事
- **后见之明偏误**：知道结果后倒推飞星轨迹，看似准确实则无预测力
- **不可证伪**：化曜组合太多，几乎任何事都能"找到理由"

**项目立场**：
- 学飞星派**为了解流派分歧 + 提供辅助视角**
- **不**作为主线判读方法
- **不**用飞星派结论冒充中州派
- 任何引用飞星派结论必须**显式标注**"飞星派认为"

### 3.5 戊干化科分歧 — 飞星派 vs 中州派

最典型分歧：**戊干化科**

| 流派 | 戊干化科 |
|---|---|
| 中州派（主流） | **右弼** |
| 飞星派部分（梁若瑜系统） | **太阳** |
| 飞星派部分（蔡明宏系统） | **右弼** |
| 少数 | **太阴** |

**项目立场**：取**中州派主流"右弼"**为本命四化判读基础。

## 4. 例子（结构性，非实证）

### 4.1 飞星派 vs 中州派对同一命主的差异

某命主：本命武曲化忌（壬干）在夫妻宫

**中州派结论**：
- 武曲化忌坐夫妻 → 婚姻寒 / 易因钱与配偶冲突
- 建议：婚前充分沟通财务观

**飞星派结论**：
- 武曲化忌坐夫妻 → 夫妻宫"忌出"或"忌入"看具体飞星
- 如**夫妻宫天干 = 壬** → 夫妻宫自化忌 → 重灾
- 如**夫妻宫天干 = 甲** → 甲干太阳化忌 → 飞向本命太阳所在宫 → 看具体落宫
- 还要看夫妻宫飞向命宫、官禄宫、福德宫的化曜组合

**对比**：中州派结论**单一稳定**；飞星派结论**信息量多但易过拟合**。

### 4.2 自化的典型例子

某命主命宫天干 = 戊，命宫主星 = 贪狼
- 戊干贪狼化禄 → 命宫自化禄
- 飞星派：**命宫自化禄主一生有"自来财" + 应酬带利**
- 中州派：不强调自化，仅看本命四化（如生年是壬，看天梁化禄落宫）
