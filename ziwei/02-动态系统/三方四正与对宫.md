# 三方四正与对宫

## 1. 核心定义

**三方四正**（Sān Fāng Sì Zhèng）：紫微斗数的**核心判读法**。

**任何一宫的解读**，都必须看其**三方四正**联动，即：
- **本宫**
- **对宫**（正对面，相隔 6 位）
- **三合宫 1**（本宫前 4 位）
- **三合宫 2**（本宫后 4 位）

共 4 宫联动，称"三方四正"。

| 名称 | 来源 | 主要作用 |
|---|---|---|
| 本宫 | 当前判读的宫 | 主要星情 |
| 对宫 | 正对（相隔 6） | **外部环境** / 反向力量 |
| 三合宫 | 三合关系（地支三合） | **隐性影响** / 长期力量 |

**核心原则**：
- 单看一宫**永远不够**
- 三方四正是紫微看盘的**最低单位**
- 杀破狼、机月同梁等格局都是三方四正成立的

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷四·斗数发微论》

> 一宫之吉凶，**须看三方四正**；
> **本宫无主星**，须借**对宫**主星。

白话翻译（笔者所加）：任何一宫的吉凶判断，必须看三方四正联动；本宫无主星时，借对宫主星看。

### 2.2 《紫微斗数全书·卷四·重补斗数彀率》

> 看命之法，**先观三方四正**，再看吉凶煞曜。

白话翻译（笔者所加）：看命的方法，先看三方四正，再看具体的吉星 / 煞星。

## 3. 现代解释

### 3.1 三方四正的"几何关系"

12 宫盘上，对宫永远相隔 6 位，三合永远相隔 4 位（按地支三合关系）：

**地支三合**：
- 申子辰三合水局
- 寅午戌三合火局
- 巳酉丑三合金局
- 亥卯未三合木局

例：本宫在子
- 对宫：午（子 + 6 = 午）
- 三合 1：申（子 + 8 = 申，逆数 4）
- 三合 2：辰（子 + 4 = 辰，顺数 4）
- 三方四正 = 子 + 午 + 申 + 辰

### 3.2 12 宫的"三方四正分组"

| 宫 | 对宫 | 三合 1 | 三合 2 | 三方四正合 |
|---|---|---|---|---|
| 命宫 | 迁移 | 财帛 | 官禄 | **命三方** = 命 + 迁 + 财 + 官 |
| 兄弟 | 交友 | 父母 | 子女 | 兄弟三方 |
| 夫妻 | 官禄 | 福德 | 迁移 | 夫妻三方 |
| 子女 | 田宅 | 兄弟 | 疾厄 | 子女三方 |
| 财帛 | 福德 | 命宫 | 官禄 | **财三方** = 财 + 福 + 命 + 官 |
| 疾厄 | 父母 | 兄弟 | 子女 | 疾厄三方 |
| 迁移 | 命宫 | 福德 | 夫妻 | 迁移三方 |
| 交友 | 兄弟 | 田宅 | 父母 | 交友三方 |
| 官禄 | 夫妻 | 命宫 | 财帛 | **官三方** = 官 + 夫 + 命 + 财 |
| 田宅 | 子女 | 交友 | 疾厄 | 田宅三方 |
| 福德 | 财帛 | 夫妻 | 迁移 | 福德三方 |
| 父母 | 疾厄 | 交友 | 兄弟 | 父母三方 |

**关键观察**：
- **命三方** = 命 + 迁 + 财 + 官 → "**本人 + 环境 + 钱 + 事业**"，决定**人生主干**
- **官三方** = 官 + 夫 + 命 + 财 → "**事业 + 配偶 + 本人 + 钱**"，决定**事业层级**
- **财三方** = 财 + 福 + 命 + 官 → "**钱 + 享受 + 本人 + 事业**"，决定**财富层级**

### 3.3 对宫的"反向力量"原理

对宫不是简单的"对立"，而是：

- **互相补充**：命宫 ↔ 迁移宫 = "我"+"外部环境"
- **互相牵制**：命宫紫微 + 迁移贪狼 → 帝王气 + 应酬气，互相调和或冲突
- **借对宫看"无主星"**：命宫无主星时，借迁移主星看 — 这是中州派 / 飞星派**一致的方法**

### 3.4 三合宫的"隐性影响"

三合宫**不在视线内**但**长期影响**本宫：

- 命宫 + 财帛三合 → 财气长期助命
- 命宫 + 官禄三合 → 事业长期助命

**重要**：三合宫的影响**慢但深** — 它不像对宫那样"立即冲击"，而是"长期渗透"。

### 3.5 三方四正联动判读的"加权"

不同流派对三方四正的权重略有差异。中州派常用结构性权重：

| 宫 | 权重 |
|---|---|
| 本宫主星 | 50% |
| 对宫主星会照 | 25% |
| 三合宫主星会照 ×2 | 25%（每 12.5%） |

（**注**：上述百分比是结构性估算，非实证数据。实际判读中权重会因主星类型、辅星煞星组合而调整）

### 3.6 "三方四正皆吉"vs"皆凶"

- **三方四正皆吉**（如命三方四颗主星都是紫府武等吉星，无煞冲）→ 上格命
- **三方四正皆凶**（如命三方见多颗化忌 + 火铃陀羊 + 空劫齐凑）→ 下格命（**反对**死断"下格"，仅作结构性参考）
- **三方四正吉凶杂**（多数命主）→ 普通命，看具体细节

## 4. 例子（结构性，非实证）

### 4.1 命三方的判读示例

某命主：
- 命宫午：紫微独坐
- 迁移子：贪狼独坐
- 财帛寅：武曲 + 天府
- 官禄戌：廉贞 + 天相

**联动判读**：
- 命宫紫微 → 端庄、领导欲
- 迁移贪狼 → 外出多机遇 / 应酬 / 桃花
- 财帛武曲 + 天府 → 财库稳厚 / 实业财
- 官禄廉贞 + 天相 → 公职 + 公关 / 印星 + 复杂

**结论倾向**：命主**领导型 + 应酬型 + 财库型 + 公职公关型** → 适合**政商两栖** / 公关高层 / 实业老板 + 外交应酬

### 4.2 无主星 + 借对宫

某命主命宫无主星（命无正曜），对宫迁移宫坐紫微 + 七杀

**判读**：
- 命宫借迁移看 → 命主性格受环境塑造 + 紫杀格的杀伐果断
- 反对古义"命无正曜夭折孤贫" → 现代命主更可能"灵活、外向、依环境而变"

### 4.3 三合宫的"长期渗透"

某命主：
- 命宫天同（享福但易懒）
- 财帛宫（三合）武曲（决断 + 重财）
- 官禄宫（三合）廉贞（公关 + 复杂）

**判读**：
- 命宫主"懒"
- 但三合财帛武曲长期推动 → 命主在财气上**长期不会松懈**（隐性力量）
- 三合官禄廉贞 → 命主在事业上**长期需要公关力**

**结论倾向**：表面享福但实际事业 / 财气推动力强 — 这是单看命宫看不出的。
