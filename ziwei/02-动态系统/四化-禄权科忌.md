# 四化 · 禄权科忌

## 1. 核心定义

**四化**（Sì Huà）：紫微斗数最重要的**动态变量**。

由**生年天干**飞出 4 颗化曜（**化禄、化权、化科、化忌**），附在 4 颗主星 / 辅星上，从静态命盘转入"有时间方向的解读"。

| 化曜 | 拼音 | 一句话主意义 |
|---|---|---|
| **化禄** | huà lù | **增益** / 财利 / 贵人 / 顺利 / 缘分 |
| **化权** | huà quán | **强化** / 权力 / 主导 / 争胜 / 决断 |
| **化科** | huà kē | **名声** / 学业 / 缓和 / 文教 / 贵人扶持 |
| **化忌** | huà jì | **阻滞** / 是非 / 损耗 / 执念 / 灾难 |

**四化的两层维度**：

1. **本命四化**（生年天干 → 4 颗化曜固定）：命主**先天**的化曜配置，伴随一生
2. **大限 / 流年四化**（大限宫天干 / 流年天干 → 4 颗化曜浮动）：动态触发点，决定**应期**

**核心争议**：中州派 vs 飞星派对四化的使用方式分歧最大（见 §5）。

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷一·安四化诀》

> **甲廉破武阳**，乙机梁紫阴，
> 丙同机昌廉，丁阴同机巨，
> 戊贪阴右机，己武贪梁曲，
> 庚阳武府同，辛巨阳曲昌，
> 壬梁紫府武，癸破巨阴贪。

白话翻译（笔者所加）：每个天干飞 4 化（按**禄权科忌**顺序），如"甲"年生人为"廉贞化禄、破军化权、武曲化科、太阳化忌"。

**重要**：戊干、庚干、壬干的化科 / 化忌**版本众多**，需分流派对照。本笔记按"主流《全书》版"列出（**待考**：少数版本有出入）。

### 2.2 《紫微斗数全书·卷四·骨髓赋》

> 科明禄暗，**位列三台**。
> 化禄化权化科为吉，**化忌为大忌**。

白话翻译（笔者所加）：化科明显 + 化禄暗藏，主大贵；化禄化权化科主吉，化忌是大忌。

### 3.2 化禄详解

**化禄主什么**：
- **财利**：财源开通
- **贵人缘**：人际增益
- **顺利**：事情容易做成
- **缘分**：感情 / 合作机会

**主星化禄的具体表现**（举几个例）：

| 主星 + 化禄 | 表现 |
|---|---|
| 紫微化禄 | 不存在（紫微不入禄） |
| 武曲化禄（**己干**） | 财源大旺 / 实业财 |
| 太阴化禄（**丁干**） | 田宅 / 不动产之利 / 阴柔财 |
| 天同化禄（**丙干**） | 享福 + 财 / 安稳财 |
| 太阳化禄（**庚干**） | 光明事业财 / 公职财 |
| 贪狼化禄（**戊干**） | 应酬 / 桃花财 |
| 巨门化禄（**辛干**） | 口才财 / 用嘴吃饭的收益 |
| 天梁化禄（**壬干**） | 长辈助 / **飞星派"不喜"，主是非财** |
| 天机化禄（**乙干**） | 智慧策划之财 |
| 廉贞化禄（**甲干**） | 公关 / 桃花 / 应酬财 |
| 破军化禄（**癸干**） | 破中得利 / 变革成功 |
| 七杀化禄 | 不入禄 |
| 天府化禄 | 不入禄 |
| 天相化禄 | 不入禄 |

### 3.3 化权详解

**化权主什么**：
- **权力**：决策力 / 主导力
- **强化**：星情被加强
- **争胜**：竞争中胜出
- **决断**：行动力 + 决心

主星化权多主"积极向上的强化"。

### 3.4 化科详解

**化科主什么**：
- **名声**：扬名 / 学术地位
- **学业**：考试 / 学术
- **缓和**：减轻化忌 / 煞星的伤害
- **贵人扶持**：得长辈 / 老师 / 师长助

**化科的特殊作用**：能**缓解化忌**。同宫化忌 + 化科 → 化忌伤害降低 30-50%（结构性估计，**待实证**）。

### 3.5 化忌详解

**化忌主什么**：
- **阻滞**：事情卡住
- **是非**：口舌 / 官司
- **损耗**：破财 / 健康损
- **执念**：心结 / 不放下
- **灾难**：意外 / 重病

**化忌不等于"必坏"**：
- 化忌**驻命宫**：易让命主**深入研究 / 执着某事** → 可成专家
- 化忌**驻官禄**：**事业偏执** → 可成大业（同时易过劳）
- 化忌**驻六亲宫**：缘分淡 → 与该亲属关系紧张

**化忌的杀伤等级**（中州派结构性排序）：

| 等级 | 主星 + 化忌 | 主要伤害 |
|---|---|---|
| **极凶** | 廉贞化忌（丙干） | 血光 / 法律 / 重病 |
| **极凶** | 武曲化忌（壬干） | 破财 / 手术 / 牙齿 / 婚姻寒 |
| **大凶** | 太阳化忌（甲干） | 男性人物缘 / 父 / 夫 |
| **大凶** | 太阴化忌（乙干） | 女性人物缘 / 母 / 妻 / 情绪 |
| **大凶** | 巨门化忌（丁干） | 口舌 / 官司 / 食物中毒 |
| **中凶** | 天机化忌（戊干） | 神经质 / 思虑过度 |
| **中凶** | 文昌化忌（辛干） | 文书错 / 学业不顺 |
| **中凶** | 文曲化忌（己干） | 才艺受阻 / 口才受挫 |
| **轻凶** | 贪狼化忌（癸干） | 欲望受挫 / 感情失败 |
| **轻凶** | 天同化忌（庚干） | 慵懒 / 拖延 / 慢性病 |

### 3.6 四化的"位置语义"（中州派核心方法）

四化**落入不同宫位**意义完全不同：

| 化曜 + 宫位 | 意义 |
|---|---|
| 化禄在命 | 一生顺利 / 财源开 |
| 化禄在官禄 | 事业财源 / 升迁顺 |
| 化禄在财帛 | 财源大旺 |
| 化禄在夫妻 | 配偶带财 / 婚姻顺 |
| **化忌在命** | 一生执着某事 / 心结多 |
| **化忌在官禄** | 事业偏执 / 易过劳 |
| **化忌在财帛** | 财源不稳 / 易破财 |
| **化忌在夫妻** | 婚姻不顺 / 感情心结 |
| 化权在命 | 自信 / 决断力强 |
| 化科在父母 | 父母有学问 / 关系融洽 |

### 3.7 四化的"应期触发"

**本命四化**：先天，看一生倾向
**大限四化**：每 10 年大限宫天干 → 4 颗化曜 → 看 10 年大趋势
**流年四化**：每年地支天干 → 4 颗化曜 → 看 1 年具体应期

**关键应期判断**：本命四化的**主星 + 大限化曜重合** = 该年应期触发

例：本命武曲化禄在财帛 + 大限走至己干 → 大限武曲化禄 → 财帛宫双化禄 → **大财之年**

## 4. 例子（结构性，非实证）

### 4.1 本命四化分析（甲年生人）

甲年生人：廉贞化禄 / 破军化权 / 武曲化科 / **太阳化忌**

- 廉贞化禄在某宫 → 该宫主公关 / 桃花 / 应酬有利
- 破军化权在某宫 → 该宫主变革 / 创业有力
- 武曲化科在某宫 → 该宫主财气有名 / 财务管理有功
- **太阳化忌在某宫** → 该宫主与男性人物 / 父亲 / 男领导关系紧张

### 4.2 大限四化应期

某甲年生人，大限走至己干（己未限）：
- 大限四化：武曲化禄 / 贪狼化权 / 天梁化科 / 文曲化忌
- 重点：本命太阳化忌 + 大限文曲化忌 → 双化忌之年，文书 / 言论领域有大灾
- 建议：该限内避免发表敏感言论 / 谨慎处理文书

### 4.3 化科救化忌

某命主本命廉贞化忌（重灾）+ 大限化科照入廉贞宫
→ **化科救化忌** → 重灾减半（结构性估计）
→ 建议：该限内仍需谨慎，但有外援可解

## 5. 流派分歧 — **重点**

### 5.1 中州派 vs 飞星派的四化使用方式

| 议题 | 中州派 | 飞星派 |
|---|---|---|
| 本命四化地位 | 主 | 起点 |
| 四化用法 | 看落宫意义 | **四化飞星 / 自化** — 四化在宫位之间互飞 |
| 大限四化 | 看 10 年趋势 | 大限化曜引出"忌出"/"忌入"/"禄出"/"禄入"等 |
| 自化 | 不强调 | **核心概念**：宫位自身天干引发本宫主星化 |
| 应期推法 | 大限 → 流年 → 流月 | 同 + 四化触发点更细 |

### 5.2 戊 / 庚 / 壬干化科分歧

| 年干 | 中州派化科 | 飞星派化科 | 备注 |
|---|---|---|---|
| 戊 | **右弼** | **太阳**（部分）/ 右弼 | 戊干争议最大 |
| 庚 | **太阴** | **天府**（部分）/ 太阴 | 部分流派主张天府 |
| 壬 | **左辅** | **天府**（部分）/ 左辅 | 部分流派主张天府 |

**项目立场**：以中州派为主线 — 戊化右弼、庚化太阴、壬化左辅。

### 5.3 庚干化忌分歧

| 年干 | 主流化忌 | 少数说法 |
|---|---|---|
| 庚 | **天同** | 太阴 |

**项目立场**：庚干化忌取天同（主流）。
