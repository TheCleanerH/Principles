# 婚姻应期专题

## 1. 看婚姻的"四宫联动"

紫微看婚姻**不是只看夫妻宫**，而是 4 宫联动：

| 宫位 | 看什么 |
|---|---|
| **夫妻宫** | 配偶形象 + 婚姻状态 + 自身在婚姻中的样子 |
| **官禄宫**（对宫） | 事业对婚姻的影响 / 配偶事业 |
| **福德宫**（三合） | 内心对婚姻的态度 / 精神满足度 |
| **迁移宫**（三合） | 外部环境 / 异地恋 / 跨文化婚姻 |

## 3. 婚姻应期的"触发时机"

### 3.1 大限触发

| 大限走向 | 主什么 |
|---|---|
| 大限走至**夫妻宫** | 该 10 年婚姻变动 / 配偶相关 |
| 大限走至**红鸾天喜宫** | 该 10 年婚喜倾向 |
| 大限走至**化禄宫**（在夫妻三方） | 该 10 年婚姻顺利 |
| 大限走至**化忌宫**（在夫妻三方） | 该 10 年婚姻挑战 |

### 3.2 流年触发

| 流年触发 | 应期 |
|---|---|
| 流年红鸾天喜进夫妻 + 化禄 | 该年**婚喜窗口** |
| 流年化禄进夫妻 | 该年感情顺 / 结识机会 |
| 流年化忌进夫妻 | 该年感情挑战 / 冷战 / 分手 |
| 流年武曲化忌进夫妻 | **极重灾年** — 财务冲突致婚姻问题 |

## 5. 合盘（男女对盘）方法

**合盘**：用两个人的紫微盘做对照，看二人关系。

### 5.1 紫微合盘的"7 个维度"

1. **命宫主星互动**：性格匹配度
2. **夫妻宫主星**：双方对"另一半"的期待
3. **三方四正交叉**：四宫互照
4. **化禄化忌互飞**：是否互相增益或冲突
5. **大限同步度**：双方大限走势是否能契合
6. **六亲宫交叉**：父母 / 兄弟宫的互看
7. **疾厄宫合**：生育 / 健康配合

### 5.2 合盘的"理想配对"

| 维度 | 理想配置 |
|---|---|
| 命宫主星 | **互补**（如紫微 + 天府、武曲 + 天府、太阳 + 太阴） |
| 夫妻宫 | **互相在对方的夫妻宫见庙旺主星 + 化禄** |
| 大限 | **双方大限同步顺逆** 主长期一致 |
| 化曜互飞 | **A 的化禄进 B 的命宫** / **B 的化禄进 A 的命宫** |

### 5.3 合盘的"警惕配置"

- **双方化忌互飞** → 易冲突
- **双方夫妻宫都见破军 + 化忌** → 婚姻不稳
- **大限走势严重错位** → 长期不同步

### 5.4 合盘的"反神秘化"

- 合盘**只看倾向**，不预言"必合必分"
- 双方主观努力 > 紫微合盘的结构性预测
- **反对**单凭合盘结果劝合 / 劝分
