# 出国 / 留学 / 迁移应期专题

> **命主特别相关**：你正在韩国留学 + 未来可能海外发展。本专题重点服务于命主的实际人生路径。

## 1. 看出国 / 迁移的"四宫联动"

| 宫位 | 看什么 |
|---|---|
| **迁移宫**（命宫对宫） | **核心** — 外部环境对命主的影响 |
| **命宫** | 本人是否适合远行 |
| **田宅宫** | 长期居住地是否易变 |
| **父母宫** | 与原生家庭的距离 |

## 2. 出国 / 迁移的"核心星曜"

### 2.1 主要星

| 星 | 主什么 |
|---|---|
| **天马** | **驿马 / 迁移 / 外出**（最核心） |
| **化禄** | 出外得利 |
| **化忌** | 出外不利 / 旅途警惕 |
| **太阳** | 跨国 / 跨文化（与巨门组合特别有利） |
| **巨门** | 用嘴 / 跨文化 / 异国语言 |
| **破军** | 远离故土 / 海外发展 |
| **七杀** | 远行打拼 / 异地创业 |
| **贪狼** | 应酬 / 异地机遇 |

### 2.2 重要格局

| 格局 | 出国 / 迁移含义 |
|---|---|
| **巨日格**（巨门 + 太阳在寅 / 申） | **跨文化 / 外国发展大格** |
| **马头带剑**（天马 + 擎羊） | **异地打拼 + 风险并存** |
| **财禄夹马**（天马 + 禄存 + 化禄） | **远方致富** / 海外创业 |
| **杀破狼 + 天马** | **海外创业 / 远行打拼** |
| **太阳在寅卯辰巳 + 化禄** | 东方崛起方向（**韩国在东**，可能吻合命主） |

## 3. 出国应期的"5 个判断维度"

### 3.1 是否适合出国（命格层）

| 配置 | 倾向 | 概率区间 |
|---|---|---|
| 迁移宫见庙旺主星 + 化禄 + 天马 | **极适合出国** | 70-85% |
| 迁移宫见**巨日格** | 跨文化路径吻合 | 65-80% |
| 迁移宫见**破军 / 七杀** | 远行打拼 | 60-75% |
| 命宫破军 + 化禄 + 天马 | 远离故土发展 | 60-75% |
| 田宅宫主星不稳 / 化忌 | 不动产易变 → 易迁移 | 50-65% |
| 迁移宫见**多吉星 + 化禄** | 海外有贵人助 | 60-75% |

### 3.2 不适合出国的配置

| 配置 | 倾向 |
|---|---|
| 迁移宫见**化忌 + 多煞** | 出外不利 / 旅途风险 |
| 迁移宫见**羊陀夹忌** | 重灾 — 不宜远行 |
| 命宫天府 + 田宅紫微 | 守土型 — 远行难成 |
| 父母宫强 + 命宫弱 | 依赖家庭 — 远行心理负担 |

### 3.3 出国应期的"大限触发"

| 大限 | 倾向 |
|---|---|
| 大限走至**迁移宫** | 该 10 年远行 / 出国机会 |
| 大限走至**天马宫** | 该 10 年迁动多 |
| 大限化禄进迁移 | 该 10 年出国得利 |
| 大限化禄进田宅 | 该 10 年不动产变化（含搬家 / 海外置业） |

### 3.4 出国应期的"流年触发"

| 流年触发 | 应期 |
|---|---|
| 流年走至**天马宫** | 该年迁动多 |
| 流年走至**迁移宫** + 化禄 | 该年出国 / 远行顺利 |
| 流年化禄进迁移 | 该年异地机会 |
| 流年化忌进迁移 | 该年远行警惕 / 旅途风险 |
| 流年天马 + 化忌 + 擎羊 | 该年旅途意外风险 |

### 3.5 命主路径专项分析（韩国留学 + 未来发展）

**命主已知信息**：
- 男性
- 在韩国留学 AI 硕士
- 出生地待命主提供（影响真太阳时）
- 未来可能：留韩、回中、其他海外

**结构性分析框架**（命主提供盘后填具体内容）：

| **回中 vs 其他海外** | 田宅宫主星 + 化曜方向 |

| **未来配偶国籍** | 夫妻宫 + 天马 + 跨文化星 |

## 5. 出国后的"适应度"判断

| 维度 | 配置 |
|---|---|
| **语言学习** | 文昌文曲 + 巨门 → 语言学习快 |
| **跨文化适应** | 巨日格 + 化禄 → 适应外国文化 |
| **海外人际** | 迁移宫见六吉星 → 海外贵人多 |
| **思乡度** | 父母宫强 → 易思乡；父母宫弱 / 化忌 → 适应远离 |
| **回国 vs 留外** | 田宅宫稳 + 国内 → 倾向回国；田宅宫动 + 海外 → 倾向留外 |

## 6. 出国应期的"反神秘化清单"

- ❌ 不死断"必出国 / 必回国"
- ❌ 不预言"X 国必合"
- ❌ 不用"驿马咸池"独断旅途桃花
- ✅ 用结构性概率
- ✅ 强调命主主动选择空间
- ✅ 强调"出国与否 ≠ 命格高下"

## 7. 中韩文化差异下的"紫微判读注意"

| 议题 | 注意 |
|---|---|
| 韩国时区（KST 东经 135°）| 真太阳时校正 -30 分钟（首尔约值） |
| 韩国出生命主（少数情况） | 按 KST 转真太阳时 |
| 在韩生活 / 工作的中国命主 | 排盘按出生地，**不按当前所在地** |
| 韩国紫微圈说法 | 韩国有"四柱命理"主流（八字派），紫微较少。本笔记主要中文紫微传统 |
