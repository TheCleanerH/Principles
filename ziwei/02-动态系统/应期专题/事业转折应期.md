# 事业转折应期专题

## 1. 看事业的"官三方联动"

紫微看事业必须 **4 宫联动**：

| 宫位 | 看什么 |
|---|---|
| **官禄宫**（事业宫） | 适合行业 / 升迁 / 事业起伏 |
| **夫妻宫**（对宫） | **配偶 / 婚姻对事业的影响** |
| **命宫**（三合） | 本人核心能力 |
| **财帛宫**（三合） | 事业带来的财 |

**官三方** = 官 + 夫 + 命 + 财

## 4. 事业应期的"5 个判断维度"

### 4.1 适合行业（命格层）

按主星倾向 + 三方四正组合判断。详见 §2 表 + [09-现代映射/职业-星情映射表.md](../09-现代映射/职业-星情映射表.md)（如已建）。

### 4.2 升迁应期（化禄 + 化权）

| 配置 | 升迁应期 |
|---|---|
| 大限化禄进官禄 | 10 年事业顺 / 升迁机会 |
| 大限化权进官禄 | 10 年事业掌权 / 实权地位 |
| 流年化禄进官禄 | 该年升迁 / 加薪 / 重要项目 |
| 流年化权进官禄 | 该年掌权 / 主导力强 |
| 大限走至**阳梁昌禄宫** | 学术 / 公职大成 |

### 4.3 创业应期（杀破狼 + 火贪 / 铃贪）

| 配置 | 创业应期 |
|---|---|
| 大限走至**杀破狼** | 10 年创业窗口 |
| 大限化禄进命 / 财 / 官 | 创业大成机会 |
| 火贪 / 铃贪 + 大限触发 | 突发暴富 / 创业大成 |
| **破军 + 化禄 + 天马** | 海外创业 |

### 4.4 事业挫折应期（化忌 + 煞星）

| 配置 | 挫折应期 |
|---|---|
| 大限化忌进官禄 | 10 年事业挑战 |
| 流年化忌进官禄 | 该年失业 / 降职 / 项目失败 |
| 武曲化忌 + 大限触发 | 财务危机致事业问题 |
| 廉贞化忌 + 大限触发 | 法律 / 公关危机 |
| **刑忌夹印**在官禄 | 重大事业损失 |
| 七杀 + 化忌 + 流年触发 | 创业失败 / 武职受挫 |

### 4.5 转折应期（重大职业变动）

| 配置 | 转折应期 |
|---|---|
| 大限走至破军 | 改革 / 转行 / 重大变动 |
| 大限走至七杀 | 创业 / 离职 / 独立 |
| 大限走至贪狼 + 火铃 | 突发机会 / 转型 |
| 流年化禄 + 化权 + 化忌三齐凑 | 重大转折之年 |

## 5. 命主未来事业路径推演（结构性框架）

命主提供盘后，按以下框架推演：

### Step 1：当前阶段（硕士在读）
- 看大限：当前第几大限？走至哪个宫？
- 看流年：当年化禄化忌在哪个宫？
- 学业 / 论文应期 → 父母宫 + 文昌文曲 + 化科

### Step 2：硕士毕业后 1-3 年（25-28 岁附近）
- 看大限：是否走至官禄 / 化禄 / 迁移宫？
- 决策点：留韩 / 回中 / 其他国家
- 决策点：学术 / 工业 / 创业

### Step 3：30-35 岁
- 关键应期：通常杀破狼命格 30+ 大转折
- 关键决策：创业窗口 / 婚姻应期

### Step 4：35+
- 紫云"36 岁前后论"：从父母 / 命宫 → 夫妻 / 福德
- 长期事业方向定型

## 8. 事业应期的"反神秘化清单"

- ❌ 不死断"必当官 / 必创业"
- ❌ 不报具体职位 / 公司
- ❌ 不预言"X 年必升 X 级"
- ❌ 不死断"必失业"
- ✅ 用结构性概率
- ✅ 强调命主主动选择
- ✅ 强调"命格只决定倾向，不决定结果"
