# 财运应期专题

## 1. 看财运的"三宫联动"（财三方）

紫微看财运不是只看财帛宫，而是 **3 宫联动**：

| 宫位 | 看什么 |
|---|---|
| **财帛宫** | 现金流 / 财源类型 / 理财观 |
| **官禄宫**（三合） | 事业带来的财 |
| **福德宫**（对宫） | 享受财 / 内在驱动决定财气 |
| **命宫**（三合，间接） | 本人理财能力的"主语" |

## 2. 财运的"4 类来源"

| 财类 | 主星倾向 | 现代职业 |
|---|---|---|
| **正财** | 武曲 / 天府 / 太阴 | 工资 / 实业 / 不动产 / 长期积累 |
| **偏财** | 贪狼 / 廉贞 / 破军 | 投资 / 应酬 / 销售 / 暴发 |
| **辛苦财** | 七杀 / 巨门 / 太阳 | 创业 / 用嘴 / 公职辛苦 |
| **不显之财** | 天梁 / 天同 | 长辈助 / 福气财 / 慢热型 |

## 3. 财运应期的"5 个判断维度"

### 3.1 财源开通（化禄 + 禄存）

| 配置 | 应期 |
|---|---|
| 大限**双禄朝垣** | 10 年财源大旺 |
| 大限化禄进财帛 | 该 10 年财气开 |
| 流年化禄进财帛 | 该年财源开 |
| 流月化禄进财帛 | 该月有进财机会 |
| 武曲化禄 + 大限走至该宫 | 实业财大开 |
| 太阴化禄 + 大限走至田宅 | 不动产收益 |

### 3.2 财运挑战（化忌 + 煞星）

| 配置 | 应期 |
|---|---|
| 大限化忌进财帛 | 10 年财气不稳 |
| 流年化忌进财帛 | 该年破财警惕 |
| 武曲化忌 + 大限触发 | **极重灾** — 破财 + 手术 + 婚财冲突 |
| 廉贞化忌 + 大限触发 | 法律 / 重大破财 |
| 财帛宫 + 空劫 + 化忌 | 财气被空 / 投资亏 |
| 财帛宫 + 火铃陀羊 | 财来财去 / 易意外破财 |

### 3.3 暴发应期（火贪 / 铃贪 / 创业）

| 配置 | 应期 |
|---|---|
| 火贪 / 铃贪格 + 大限走至该宫 | 突发机遇窗口 |
| 火贪 / 铃贪 + 化禄触发 | **暴发应期** |
| 杀破狼 + 化禄 + 火贪 | 创业大成机会 |

**暴发后必须建退路**：火贪 / 铃贪暴发后易暴落，**留 50% 保险**。

### 3.4 守财能力（天府 / 禄存）

| 配置 | 守财能力 |
|---|---|
| 天府坐财帛 | 守财强 / 长期累积 |
| 禄存 + 天府 | 极强守财 |
| 禄存被擎羊陀罗夹 | 财气有保护但不可外露 |
| 财帛 + 空劫 | **守财弱** — 财来财去 |

### 3.5 财运的"诚实概率估算"

**警告**：财运应期是**结构性而非实证概率**，绝不报具体金额。

| 触发等级 | 描述 | 结构性概率（财运层级） |
|---|---|---|
| ★★★★★ | 本命 + 大限 + 流年三层化禄 + 火贪 / 铃贪 | 60-75%（重大财利机会） |
| ★★★★ | 双层化禄 / 火贪触发 | 45-60% |
| ★★★ | 单层化禄 / 大限化禄 | 30-45% |
| ★★ | 流年化禄单 | 20-35% |
| ★ | 杂耀财星会照 | 10-20% |

## 5. 财运的"反神秘化清单"

- ❌ **绝不报具体金额**（"百万千万"）
- ❌ 不死断"必富必贫"
- ❌ 不用神煞断财（如"破军 = 必破财"）
- ❌ 不预言"X 年大财"
- ✅ 用结构性概率区间
- ✅ 强调**结构性而非实证**
- ✅ 强调命主主动经营的空间
