# 健康应期专题

## 1. 严格立场（开篇必读）

⚠️ **紫微疾厄宫给出的是"倾向" + "风险点"，绝不是医学诊断**。

| 立场 | 内容 |
|---|---|
| 紫微提供 | 体质倾向 + 高风险疾病类型 + 应期时间窗口 |
| 紫微不提供 | 具体诊断 / 治疗方案 / 药物建议 |
| 命主行动 | 任何身体不适必须**先就医**，紫微只作辅助参考 |

## 5. 健康应期的"5 个判断维度"

### 5.1 体质先天倾向（命宫 + 疾厄宫主星）

| 配置 | 体质倾向 |
|---|---|
| 紫微 / 天府坐命 + 疾厄稳定 | 体质中等偏强 |
| 太阳 / 武曲坐命 + 疾厄强 | 强壮但易高血压 / 呼吸道问题 |
| 天同 / 太阴坐命 + 疾厄稳定 | 易胖 / 内分泌 / 长期型 |
| 杀破狼坐命 + 疾厄煞 | 早年易外伤 / 30+ 后渐稳 |
| 廉贞坐命 + 疾厄火 | 易血光 / 心脏 / 火气 |

### 5.2 慢性病倾向（疾厄宫主星）

| 疾厄宫主星 | 慢性病倾向 |
|---|---|
| 天同 | 消化系统慢性病 / 易胖 |
| 太阴 | 内分泌 / 经期问题 |
| 天机 | 神经系统 / 失眠 / 焦虑 |
| 天梁 | 长寿型慢性病（关节 / 高血压等）|
| 巨门 | 口腔 / 胃 / 暗病 |

### 5.3 急症 / 意外风险（煞星组合）

| 配置 | 风险 |
|---|---|
| 疾厄 + 火铃 | 急性病 / 高热 |
| 疾厄 + 擎羊 | 外伤 / 手术 |
| 疾厄 + 陀罗 | 慢性内伤 / 拖延病 |
| 疾厄 + 空劫 | 意外 / 突发 |
| 疾厄**廉贞化忌** | **极严重** — 血光 / 手术 / 重病 |
| 疾厄**武曲化忌** | 手术 / 金属伤 / 牙齿 / 呼吸道 |
| **羊陀夹忌**在疾厄 | **极重灾** — 重大健康事件 |

### 5.4 重大健康应期（大限 + 流年）

| 触发 | 应期 |
|---|---|
| 大限走至**疾厄宫** | 该 10 年健康警惕 |
| 大限化忌进疾厄 | 该 10 年慢性问题易显 |
| 流年化忌进疾厄 | 该年健康事件 |
| **流年廉贞化忌** + 疾厄 | **极重健康警惕年** |
| **流年武曲化忌** + 疾厄 | 重灾年 — 手术 / 金属伤 |
| 大限 + 流年双化忌同宫 | **极重灾年** |

### 5.5 长寿 / 短寿判断

| 配置 | 寿命倾向 |
|---|---|
| 命宫 + 疾厄 + 福德 多吉星 + 化禄 | 长寿（80+） |
| 天梁 + 紫微 / 天府 + 庙旺 | 长寿 |
| 命宫 + 疾厄 + 多煞 + 化忌 | 短寿警惕（**不死断**） |
| 廉贞化忌 + 武曲化忌 + 多煞夹疾厄 | 重大健康风险 |

**反对**："X 岁必死"古义死断 — 现代医学条件下命主可主动调养延寿。
