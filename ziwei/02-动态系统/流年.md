# 流年

## 1. 核心定义

**流年**（Liú Nián）：紫微斗数的**1 年应期**周期。

每个流年 = 1 年（按当年农历干支），从命盘上找到当年地支所在宫 → 该宫成为"流年命宫"。

| 维度 | 内容 |
|---|---|
| 周期 | 1 年 |
| 起点 | 当年地支所在的宫位 |
| 推算 | 每年地支轮换，流年命宫每年顺时针前进一宫 |
| 与大限关系 | 流年是大限的**精细化** — 在大限 10 年大趋势内定具体年份 |
| 子平派对应 | 流年（直接对应） |

**核心方法论**：流年看 4 个层面：
1. **流年宫的本命星情**
2. **流年宫的大限叠加**
3. **流年天干引发的四化**
4. **流年宫的杂耀触发**

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷一·安流年诀》

> **流年**以**当年太岁**所到之宫为流年命宫，**顺数**十二宫。

白话翻译（笔者所加）：每年的"太岁地支"所在宫即流年命宫，按顺时针重定 12 宫。

## 3. 现代解释

### 3.1 流年命宫的定位

**Step 1**：取当年农历地支（如 2026 年为丙午年 → 地支"午"）

**Step 2**：找命盘上"午"宫，该宫即为 2026 年的"流年命宫"

**Step 3**：从流年命宫起，按 12 宫顺序逆数（同本命 12 宫顺序）：
- 流年命 → 流年兄弟 → 流年夫妻 → 流年子女 → 流年财帛 → 流年疾厄 → 流年迁移 → 流年交友 → 流年官禄 → 流年田宅 → 流年福德 → 流年父母

### 3.2 流年的"四层叠加"判读

**第一层：本命**

流年命宫在本命盘上的星情：哪些主星 / 辅星驻该宫？

**第二层：大限**

当年所在的大限是什么？该大限对流年宫的影响是什么？

**第三层：流年四化**

当年天干（如 2026 年丙年）引发的 4 颗化曜：
- 2026 丙年：天同化禄、天机化权、文昌化科、廉贞化忌

→ 看这 4 颗化曜分别落在本命的哪个宫，触发该宫的应期

**第四层：流年杂耀**

流年还会激活一些**流年特有的杂耀**：
- 流年天马：与流年地支相关，主该年外出 / 迁移
- 流年红鸾天喜：主该年婚喜
- 流年丧门白虎：主该年灾厄（**慎用**，反对死断）

### 3.3 流年应期的关键判断

| 流年触发模式 | 主什么 |
|---|---|
| 流年命宫见**本命化禄** | 该年顺利、有财利、贵人到 |
| 流年命宫见**本命化忌** | 该年阻滞 / 是非 / 健康警惕 |
| 流年命宫见**流年化禄** | 该年新机会 / 财源开 |
| 流年命宫见**流年化忌** | 该年新挑战 / 心结 |
| 流年命宫**本命 + 流年双化禄** | **大顺之年** |
| 流年命宫**本命 + 流年双化忌** | **大灾之年**（需主动避险） |
| 流年命宫**化禄 + 化科** | 名利双收 |
| 流年命宫**化禄 + 化忌** | 表面顺利 + 暗藏隐忧 |
| 流年命宫**化忌 + 化科** | 困境中得援 |

### 3.4 流年六亲宫的应期

**流年父母宫见化忌** → 该年与父母 / 长辈关系紧张
**流年夫妻宫见化忌** → 该年婚姻 / 感情挑战
**流年子女宫见化忌** → 该年与子女 / 创造性输出受阻
**流年财帛宫见化禄** → 该年财源旺
**流年疾厄宫见化忌** → 该年健康警惕
**流年官禄宫见化禄** → 该年事业 / 升迁顺
**流年迁移宫见化禄 / 天马** → 该年外出 / 出国 / 异地发展吉

### 3.5 流年的"应期等级"（中州派结构性）

| 等级 | 触发条件 | 应期严重度 |
|---|---|---|
| ★★★★★ | 本命 + 大限 + 流年三层化忌同宫 | **极重灾年**（10 年一遇） |
| ★★★★ | 本命 + 流年双化忌 / 流年命宫见多煞 | 重灾年 |
| ★★★ | 流年单化忌 + 煞星 | 中度警惕年 |
| ★★ | 流年单化忌或单煞 | 轻度警惕年 |
| ★ | 杂耀凶星会照（无主星化忌） | 几乎不构成"灾年" |

**反对**：单靠杂耀（如"丧门""白虎"）定灾年 — 中州派不取。

## 4. 例子（结构性，非实证）

### 4.1 2026 丙午年流年分析模板

假设某命主：
- 本命：紫微在午
- 大限：第 4 限（33-42 岁，大限在午）
- 流年：丙午年（流年命宫在午）

**叠加效应**：
- 本命紫微 + 大限午宫 + 流年午宫 → **三限聚焦同一宫**
- 流年丙年四化：天同化禄 / 天机化权 / 文昌化科 / **廉贞化忌**
- 命宫紫微 + 流年化忌不在命宫（廉贞不在午）→ 命宫本身相对稳定
- 看廉贞在本命何处 → 假设在子女宫 → 子女 / 创造性输出有阻
- 看天同在本命何处 → 假设在福德宫 → 福德有禄 → 享福之年

**结构性结论**：2026 年命主**总体稳定 + 子女 / 创造性输出有阻 + 福德享受多**

## 5. 流派分歧

| 议题 | 中州派 | 飞星派 | 现代 |
|---|---|---|---|
| 流年命宫定位 | 按当年地支 | 同 | 同 |
| 流年四化重要性 | 触发应期 | **触发四化飞星** | 同 |
| 流年杂耀（丧门白虎等） | 仅修饰，不独断 | 同 | 同 |
| 流年与小限关系 | 流年为主，小限辅助 | 流年为主 | 同 |
| 太岁同宫 / 冲太岁 | 不取迷信民俗 | 不取 | 同 |

**反对**："本命年""犯太岁"等民俗化判断 — 中州派 / 飞星派 / 现代实证派**一致不取**。
