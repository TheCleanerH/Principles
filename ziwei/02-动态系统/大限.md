# 大限

## 1. 核心定义

**大限**（Dà Xiàn）：紫微斗数的**10 年大运**周期。

每个大限 = 10 年，从命宫起算，按命主性别 + 五行局确定起始岁数和顺逆。

| 维度 | 内容 |
|---|---|
| 周期 | 10 年 / 限 |
| 起始岁 | 由五行局决定（水二局 2 岁起、木三局 3 岁起、金四局 4 岁起、土五局 5 岁起、火六局 6 岁起） |
| 顺逆 | **男阳女阴顺行** / **男阴女阳逆行**（按生年天干阴阳分） |
| 起点 | 命宫 |
| 推算 | 命宫起第一限，按顺逆方向流转至下一宫为第二限 |
| 子平派对应 | 大运（直接对应，颗粒度相同） |

**核心方法论**：大限不只看大限宫的星情，还看：
1. **大限宫主星**：10 年主基调
2. **大限四化**（大限宫天干引发的 4 颗化曜）：10 年的"动态变量"
3. **大限三方四正**：大限命宫 + 大限迁移 + 大限财帛 + 大限官禄四宫联动
4. **大限与本命叠加**：大限主星 × 本命主星双层判读

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷一·定大限诀》

> 男阳女阴**顺行**，男阴女阳**逆行**。
> **水二局**起二岁、**木三局**起三岁、**金四局**起四岁、**土五局**起五岁、**火六局**起六岁。

白话翻译（笔者所加）：大限起始岁数由五行局决定，顺逆方向由生年阴阳 + 性别决定。

### 2.2 《紫微斗数全书·卷一·安大限诀》

> **命宫起第一限**，**顺数（或逆数）**至每宫为下一限。

白话翻译（笔者所加）：命宫为第一大限，按顺 / 逆方向流转至下一宫为下一大限。

## 3. 现代解释

### 3.1 大限的起算 — 详细步骤

**Step 1**：确定五行局（详见 [01-基础结构/排盘原理.md](../01-基础结构/排盘原理.md)）

| 五行局 | 起始岁 | 大限范围 |
|---|---|---|
| 水二局 | 2 | 2-11, 12-21, 22-31, 32-41… |
| 木三局 | 3 | 3-12, 13-22, 23-32, 33-42… |
| 金四局 | 4 | 4-13, 14-23, 24-33, 34-43… |
| 土五局 | 5 | 5-14, 15-24, 25-34, 35-44… |
| 火六局 | 6 | 6-15, 16-25, 26-35, 36-45… |

**Step 2**：确定顺逆方向

| 性别 | 生年天干 | 大限方向 |
|---|---|---|
| 男 | 阳干（甲丙戊庚壬） | **顺行** |
| 男 | 阴干（乙丁己辛癸） | **逆行** |
| 女 | 阳干 | **逆行** |
| 女 | 阴干 | **顺行** |

**Step 3**：从命宫起第一大限，按方向流转 12 宫

例：男命甲年生人 + 木三局 + 命宫在卯
- 第 1 限：3-12 岁，命宫卯（顺行）
- 第 2 限：13-22 岁，下一宫辰（顺数）
- 第 3 限：23-32 岁，巳
- 第 4 限：33-42 岁，午
- 第 5 限：43-52 岁，未
- 第 6 限：53-62 岁，申
- 第 7 限：63-72 岁，酉
- 第 8 限：73-82 岁，戌
- …

### 3.2 大限的"双层判读"

每个大限的判读，必须**同时看**：

| 层 | 内容 |
|---|---|
| **本命层** | 大限宫在本命盘上的星情（哪些主星 / 辅星驻该宫） |
| **大限层** | 大限宫天干引发的四化飞星（哪些主星化禄 / 化权 / 化科 / 化忌） |
| **流年层** | 当年地支落入哪个宫位 |
| **流年化** | 当年天干引发的四化 |

**例**：本命武曲在大限官禄宫 + 大限走至己干 → 大限武曲化禄 → 本命武曲 × 大限化禄 → **大限事业大旺**

### 3.3 大限三方四正

大限不只看大限命宫，**大限的三方四正**同样重要：

```
大限命宫 + 大限迁移宫（对宫）+ 大限财帛宫（三合）+ 大限官禄宫（三合）
```

四宫联动看 10 年总体走势。

**重要**：大限的"宫位重新定义" — 当大限走到第 N 宫时，该宫成为"大限命宫"，其对宫成为"大限迁移宫"，依此类推。即每个大限期间，命主有自己的"10 年期 12 宫盘"。

### 3.4 大限与本命的关系（中州派立场）

中州派强调：**本命定本质，大限定时机**。

| 情况 | 解读 |
|---|---|
| 本命好 + 大限好 | 顺风顺水期（人生高峰） |
| 本命好 + 大限差 | 暂时受挫但底蕴在 |
| 本命差 + 大限好 | 困境中现机会 |
| 本命差 + 大限差 | 重灾期，必须主动避险 |

### 3.5 大限的"应期落点"

大限主**10 年趋势**，具体应期看流年。

判断大限应期的关键：

1. **大限四化驻宫**：化禄 / 化权 → 顺利方向；化忌 → 警惕方向
2. **本命四化触发**：大限走到本命化忌宫 → 该限内本命化忌触发
3. **大限六亲宫**：大限父母 / 夫妻 / 子女宫的变化 → 该限内与六亲关系变动

## 4. 例子（结构性，非实证）

### 4.1 案例：男命甲年生人，木三局，命宫卯（紫微）

- 第 1 限（3-12 岁）：紫微在卯 → 早年端庄、家境好 / 父母重视
- 第 2 限（13-22 岁）：大限走至辰宫（假设辰宫为天府）→ 中学 / 大学期，稳重学习
- 第 3 限（23-32 岁）：大限走至巳宫（假设巳宫为太阴 + 天同）→ 工作初期 / 婚姻期
- 第 4 限（33-42 岁）：大限走至午宫（假设午宫为贪狼）→ 应酬密集 / 桃花期 / 职场冲刺
- 第 5 限（43-52 岁）：大限走至未宫（假设未宫为巨门）→ 口才 / 影响力期 / 但需警惕口舌

### 4.2 大限四化触发应期

某命主大限走至己干（己卯限），己干四化：
- 武曲化禄、贪狼化权、天梁化科、文曲化忌

如果本命**武曲在该限的财帛宫** + 大限引发武曲化禄 → **该限财源大开**

同时如果本命**文曲在该限的夫妻宫** + 大限引发文曲化忌 → **该限婚姻 / 感情有口舌纠纷**

→ 综合应期：财利顺但感情有挑战的 10 年
