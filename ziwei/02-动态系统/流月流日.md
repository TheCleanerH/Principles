# 流月 / 流日

## 1. 核心定义

**流月**（Liú Yuè）：紫微斗数的**1 个月应期**周期。
**流日**（Liú Rì）：紫微斗数的**1 天应期**周期。
**流时**（Liú Shí）：紫微斗数的**1 时辰应期**周期（极少用）。

| 周期 | 颗粒度 | 实用价值 |
|---|---|---|
| 大限 | 10 年 | 大趋势 |
| 流年 | 1 年 | 年度规划 |
| **流月** | **1 个月** | **重要事件 / 项目应期** |
| **流日** | **1 天** | **重要决定 / 出差择日** |
| 流时 | 1 时辰 | 极少用，仅占卜用 |

**核心方法论**：流月 / 流日是**流年的细化**，必须在流年大背景下解读。

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷一·安流月诀》

> 流月以**流年命宫**为起点，正月起流年命宫，**顺数**至本月止，即为流月命宫。

白话翻译（笔者所加）：流月命宫从流年命宫起算，按月份顺时针前进。

## 3. 现代解释

### 3.1 流月命宫定位

**Step 1**：先定流年命宫（详见 [流年.md](./流年.md)）

**Step 2**：流年命宫即为**流年正月**（农历）

**Step 3**：从流年命宫起，**顺时针**数至当前月份

例：2026 丙午年，流年命宫在午
- 流年正月（农历）：午宫
- 二月：未宫
- 三月：申宫
- 四月：酉宫
- 五月：戌宫
- 六月：亥宫
- 七月：子宫
- 八月：丑宫
- 九月：寅宫
- 十月：卯宫
- 十一月：辰宫
- 十二月：巳宫

**Step 4**：流月命宫确定后，按 12 宫顺序重定流月兄弟 / 流月夫妻 …

### 3.2 流月四化（飞星派立场）

流月四化由**流月所在月份的天干**引发（按"五虎遁"推算）：

例：2026 丙午年正月（农历正月）
- 用"五虎遁"：丙辛之年寅月起庚寅（即正月天干为庚）
- 流月天干 = 庚 → 流月四化：太阳化禄、武曲化权、太阴化科、天同化忌

中州派**部分主张流月不需要单独起四化**，仅看流月命宫的本命 / 大限 / 流年星情。本笔记按中州派立场，**流月四化作为辅助参考**。

### 3.3 流日命宫定位

**Step 1**：先定流月命宫

**Step 2**：流月命宫即为流月初一

**Step 3**：从流月命宫起，按**农历日数顺数**

例：2026 丙午年正月（命宫午），正月初一为午宫
- 正月初一：午
- 正月初二：未
- …

流日颗粒度细，**实用主要在"择日决定 / 出差 / 重要事件"**。

### 3.4 流月 / 流日 vs 流年的关系

**重要原则**（中州派强调）：
- 流月 / 流日**不能独立判读** — 必须在流年大背景下
- 流月化忌 + 流年化禄 → 流年顺利但当月有挑战
- 流月化禄 + 流年化忌 → 流年困难但当月有机会窗口

**应期细化路径**：

```
本命星情 → 大限趋势 → 流年应期 → 流月窗口 → 流日选择
                                  ↓
                          重要决定 / 项目启动 / 出差等
```

### 3.5 流月 / 流日的实用场景

| 场景 | 用流月 / 流日 |
|---|---|
| 重要会议 / 谈判 | 流月看月份大趋势，流日选具体日 |
| 出差 / 远行 | 流月看天马星动 |
| 婚嫁择日 | 流月红鸾天喜 + 流日福德 |
| 项目启动 | 流月化禄 + 流日化禄 |
| 手术 / 医疗 | 避开流月 / 流日化忌 + 廉贞 / 武曲 |
| 投资决定 | 流月财帛宫 + 流日化禄 |

**反对**：把流月 / 流日推到迷信化（"今日不宜出门"）— 紫微的流月流日只主"结构性倾向"，不主"必然吉凶"。

## 5. 流派分歧

| 议题 | 中州派 | 飞星派 | 现代 |
|---|---|---|---|
| 流月四化是否独立起 | 辅助参考 | **独立起 + 自化** | 现代实证派部分主张不需独立起 |
| 流月与流年关系 | 流年为主 | 同 | 同 |
| 流日实用性 | 中等 | 高 | 仅作择日参考 |
| 流时 | 极少用 | 极少用 | 不取 |
