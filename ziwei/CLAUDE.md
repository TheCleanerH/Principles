## 5. 隐私红线（**严格遵守**）

1. **紫微圈和八字圈一样小，这事不公开**。所有内容默认私有。
2. **命主自盘信息仅口头提供**。落地到 `04-案例/10_命主.md` 后**绝不录入 INDEX / 进度.md / 任何索引文件**。
3. **不要把内容传给任何其他 AI agent**（Hermes / Mindlogic / GPT / Gemini / Grok / 等等）。
4. **不使用子 agent / Task agent 处理命主信息**（即便子 agent 是 Claude，也算另一个 invocation）。
5. **是否推 GitHub 由命主明示**。在命主未明示前，只本地 commit，不 push。

## 6. 工作风格

- 中文为主，关键术语保留英文 / 古文
- markdown 1500-2500 字 / 篇为常规
- 表格频繁
- 不要废话开场
- 不谄媚、不空洞鸡汤、不"很有道理"
- 反神秘化：质疑无理之格、无理之断
- 概率以区间值给出，标"结构性而非实证"
