# 形性赋 · 逐句解读

> 《紫微斗数全书·卷四》论 14 主星与人**形貌 + 性格**关系的赋文。
> **重要立场**：形性赋的"长相描述"是古代观察，现代不字面理解。本笔记重点解读**性格特征**，对形貌描述只作历史记录。

## 逐句解读（按 14 主星顺序）

### 紫微

> **紫微肥满，面紫色。**

| 项 | 内容 |
|---|---|
| 古义 | 紫微坐命者体型丰满，面带紫红气色。 |
| 现代修正 | **形貌不字面理解** — 现代命主有瘦的、不红面的，不影响紫微特质。重点在**端庄气场 + 自尊**。 |
| 性格关键 | 稳重端庄、自尊强、有领导欲、责任感重。 |

### 天机

> **天机不长不短之资，情怀好善。**

| 项 | 内容 |
|---|---|
| 古义 | 天机坐命者身材中等，性情向善。 |
| 现代修正 | "好善"在现代 = **善学习 / 善思考 / 善变通**。 |
| 性格关键 | 聪明、机敏、善变、多思、易焦虑。 |

### 太阳

> **太阳乃圆满之相，相貌堂堂。**

| 项 | 内容 |
|---|---|
| 古义 | 太阳坐命者面相方圆，相貌堂堂。 |
| 现代修正 | "堂堂"指**气场开阔**而非纯外貌。陷地太阳此特质减弱。 |
| 性格关键 | 光明磊落、博爱、奉献、急躁、易过劳。 |

### 武曲

> **武曲乃短小之资，性刚果决。**

| 项 | 内容 |
|---|---|
| 古义 | 武曲坐命者身材偏短小，性格刚毅决断。 |
| 现代修正 | 身材"短小"不可信（统计无依据）。**性格刚硬 + 决断**是核心。 |
| 性格关键 | 刚毅、决断、重财、直率、不善表达。 |

### 天同

> **天同肥满，眉清目秀。**

| 项 | 内容 |
|---|---|
| 古义 | 天同坐命者多肥满，眉目清秀。 |
| 现代修正 | "肥满"反映**易享福 + 易胖**的体质倾向。**眉清目秀**反映**福相**气质。 |
| 性格关键 | 温和、慈祥、安逸、易享福、易拖延。 |

### 廉贞

> **廉贞眉宽口阔，面横色尖。**

| 项 | 内容 |
|---|---|
| 古义 | 廉贞坐命者眉宽嘴大，面带横气，气色尖锐。 |
| 现代修正 | "面横"反映**复杂内心**和**双面性**。 |
| 性格关键 | 复杂、双面、公关力、易血光、桃花。 |

### 天府

> **天府面方圆，温和厚重。**

| 项 | 内容 |
|---|---|
| 古义 | 天府坐命者面相方圆，温和厚重。 |
| 现代修正 | "方圆 + 厚重"反映**稳重 + 守财**性格。 |
| 性格关键 | 稳重、厚道、守财、保守、不冒险。 |

### 太阴

> **太阴面圆白，身材端正。**

| 项 | 内容 |
|---|---|
| 古义 | 太阴坐命者面圆肤白，身材端正。 |
| 现代修正 | "白"反映**阴气**重 / 内敛。男命太阴现代不取性别气质判断。 |
| 性格关键 | 阴柔、内敛、细腻、储蓄观、易抑郁。 |

### 贪狼

> **贪狼为善恶之星，入庙必应**长大**；陷地则瘦小**。

| 项 | 内容 |
|---|---|
| 古义 | 贪狼是善恶兼有的星，庙旺者高大，陷地者瘦小。 |
| 现代修正 | "善恶兼有"准确反映**贪狼欲望的双重性**。形貌描述不字面理解。 |
| 性格关键 | 欲望强、多才多艺、应酬高手、桃花多。 |

### 巨门

> **巨门敦厚肥胖。**

| 项 | 内容 |
|---|---|
| 古义 | 巨门坐命者多体型敦厚偏胖。 |
| 现代修正 | "敦厚"反映**外形 vs 内心**的反差（外厚内复杂）。 |
| 性格关键 | 口才好、善辩、多疑、暗中思虑、易卷入是非。 |

### 天相

> **天相端庄，重仪表。**

| 项 | 内容 |
|---|---|
| 古义 | 天相坐命者端庄重仪表。 |
| 现代修正 | "重仪表"现代 = **重穿着 + 重礼仪 + 重表面整洁**。 |
| 性格关键 | 稳重、端庄、辅佐型、重仪表、善协调。 |

### 天梁

> **天梁性傲清高。**

| 项 | 内容 |
|---|---|
| 古义 | 天梁坐命者性格清高傲然。 |
| 现代修正 | "清高"反映**不慕世俗 + 重精神**。可能曲高和寡。 |
| 性格关键 | 稳重、长者气、慈善、孤高、清高。 |

### 七杀

> **七杀目大，面色青黄。**

| 项 | 内容 |
|---|---|
| 古义 | 七杀坐命者眼睛大、面色青黄。 |
| 现代修正 | "目大"反映**目光锐利 + 杀气**。形貌不字面理解。 |
| 性格关键 | 刚强、决断、独立、不服管、创业。 |

### 破军

> **破军面色青白，腰背欠平。**

| 项 | 内容 |
|---|---|
| 古义 | 破军坐命者面色青白，腰背微驼。 |
| 现代修正 | "腰背欠平"现代无统计依据。**核心是变革气质**。 |
| 性格关键 | 求变、不安稳、创新、冒险、不重传统。 |

## 辅星形性补充

### 左辅 / 右弼
> 左辅右弼**温和厚重**，眉**清秀**。
- 反映**辅佐型性格** + **人际圆融**。

### 文昌 / 文曲
> 文昌文曲**清秀**，**机巧**之相。
- 反映**文采气质** + **才艺禀赋**。

### 天魁 / 天钺
> 天魁天钺**威仪**之相。
- 反映**贵人气场**。

### 火星 / 铃星
> 火星**眉浓发赤**；铃星**眉浓发黄**。
- 反映**急躁 + 暴气**。

### 擎羊 / 陀罗
> 擎羊**面横**；陀罗**面瘦**。
- 反映**刑伤气** / **拖延气**。

### 地空 / 地劫
> 地空**清瘦**，地劫**面青**。
- 反映**空亡 / 入世劫**之气。

## 形性赋的"现代解读纪律"

1. **不字面理解形貌**：现代命主长相多元，单星形貌描述不可信
2. **性格特征更可信**：14 主星性格描述有古今一致性
3. **气质 / 气场**：可作为辅助参考（如紫微"气场端庄"vs 武曲"气场刚硬"）
4. **避免相貌歧视**：禁止用形性赋判断"长得像 X 星所以是 X 命格"
