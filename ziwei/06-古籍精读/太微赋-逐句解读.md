# 太微赋 · 逐句解读

> 《紫微斗数全书·卷四》开篇大赋，紫微斗数的**总纲**。
> 本笔记采用"原文 / 白话 / 现代修正"三栏式逐句解读。
> 修正立场：中州派为主 + 慧心斋主反神秘化 + 反古义贬义。

## 全篇结构

太微赋约 800 字（不同版本字数有出入），分四部分：
- **第一部分**：总论 — 紫微斗数的地位和方法
- **第二部分**：格局总纲
- **第三部分**：星情关键 — 14 主星 + 辅星 + 煞星的概要
- **第四部分**：女命 + 应期总结

## 第一部分：总论

### 句 1.1
> 斗数至玄至微，**理**虽**深奥**。

| 项 | 内容 |
|---|---|
| 白话 | 紫微斗数玄妙微细，道理深奥。 |
| 现代修正 | 强调"玄"不是迷信，是说**信息量大、系统复杂** — 不是"神秘不可言"。 |
| 命主认识 | 学的时候要把"玄"理解为"高维信息处理"，不是"超自然"。 |

### 句 1.2
> 安星依**生月**、**生时**、**五行局**而行。

| 项 | 内容 |
|---|---|
| 白话 | 安星按生月、生时、五行局推算。 |
| 现代修正 | **真太阳时校正必须做** — 古籍未明说的现代要求。 |
| 关联 | [排盘原理.md](../01-基础结构/排盘原理.md) |

### 句 1.3
> 看**命**先看**身**，**身命同宫**者**福**厚。

| 项 | 内容 |
|---|---|
| 白话 | 看命格时先看身宫，身宫与命宫同位的人福气深。 |
| 现代修正 | 身宫的"权重"35 岁后增大（紫云三十六岁前后论）。**身命同宫**仅生年支为子 / 午时成立。 |
| 关联 | [12宫位.md §3.1 身宫](../01-基础结构/12宫位.md) |

## 第二部分：格局总纲

### 句 2.1
> 紫府同宫，**终身福厚**。

| 项 | 内容 |
|---|---|
| 白话 | 紫微 + 天府同坐命宫（仅寅 / 申），主一生福气深厚。 |
| 现代修正 | **不等于"自动大富贵"** — 需配辅星 + 无煞冲。 |
| 关联 | [紫府同宫.md](../03-格局应期/格局/紫府同宫.md) |

### 句 2.2
> 君臣庆会，**才善经邦**。

| 项 | 内容 |
|---|---|
| 白话 | 君臣庆会格主有治国之才。 |
| 现代修正 | 现代延伸 = 跨国 CEO / 国家级领导 / 学界领袖。 |
| 关联 | [君臣庆会.md](../03-格局应期/格局/君臣庆会.md) |

### 句 2.3
> 日月并明，**主大贵**。

| 项 | 内容 |
|---|---|
| 白话 | 太阳 + 太阴同庙旺会照，主大贵。 |
| 现代修正 | 标准吉格，**子位太阴 + 午位太阳**为典型。 |
| 关联 | [日月并明.md](../03-格局应期/格局/日月并明.md) |

### 句 2.4
> 杀破狼**逢**陀火铃，**身命遭凶**；得辅佐吉星，**显贵**。

| 项 | 内容 |
|---|---|
| 白话 | 杀破狼遇煞星齐凑则凶；得吉星辅佐反成大贵。 |
| 现代修正 | 杀破狼**不是凶格** — 是变动型命格，配置决定走向。 |
| 关联 | [杀破狼.md](../03-格局应期/格局/杀破狼.md) |

### 句 2.5
> 机月同梁**作吏人**。

| 项 | 内容 |
|---|---|
| 白话 | 机月同梁格主公务员 / 文职 / 行政工作。 |
| 现代修正 | "吏人"在现代扩展为**所有稳定型职业**（公务员、教师、医生、AI 研究员）。 |
| 关联 | [机月同梁.md](../03-格局应期/格局/机月同梁.md) |

## 第三部分：星情关键

### 句 3.1
> 紫微居子午，**科权禄拱**，为至贵。

| 项 | 内容 |
|---|---|
| 白话 | 紫微在子或午且有化禄化权化科会照，是顶级大贵。 |
| 现代修正 | 子位优于午位（子为北方，对应北极星本位）。 |
| 关联 | [紫微.md](../01-基础结构/14主星/紫微.md) |

### 句 3.2
> 太阳居午，**日丽中天**。

| 项 | 内容 |
|---|---|
| 白话 | 太阳在午宫（最旺），主大富大贵。 |
| 现代修正 | **男命太阳在午**优势明显；女命太阳在午是现代独立事业型女性的标志。 |
| 关联 | [太阳.md](../01-基础结构/14主星/太阳.md) |

### 句 3.3
> 太阴居亥，**月朗天门**。

| 项 | 内容 |
|---|---|
| 白话 | 太阴在亥宫（最旺），主大贵 / 富 / 名声。 |
| 现代修正 | 太阴在亥的命主特别适合**艺术 / 金融 / 不动产**。 |
| 关联 | [太阴.md](../01-基础结构/14主星/太阴.md) |

### 句 3.4
> 武曲贪狼，**先贫后富**。

| 项 | 内容 |
|---|---|

| 关联 | [武曲.md](../01-基础结构/14主星/武曲.md) + [贪狼.md](../01-基础结构/14主星/贪狼.md) |

> 贪狼**火星**居庙旺，**名镇诸邦**。

| 项 | 内容 |
|---|---|

> 火铃陀羊，**身命遭凶**。

### 句 4.1

|---|---|

| 现代修正（慧心斋主立场）| **明确反对** — 这些杂耀只作修饰，不可独断"孤""淫"。 |

### 句 4.2
> 女命**夫妻**宫为主。

| 项 | 内容 |
|---|---|
| 白话 | 女命以夫妻宫为主要看盘焦点。 |
| 现代修正（慧心斋主立场）| **反对古义** — 现代女命应以**命宫 + 福德 + 夫妻**三宫并看，反对"以夫为天"。 |

### 句 4.3
> **吉凶随时变**，**化禄化忌**为枢机。
