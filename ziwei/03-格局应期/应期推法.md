# 应期推法

## 1. 核心定义

**应期推法**：根据紫微命盘 + 大限 + 流年 + 流月 + 流日的层级判读，**定位具体事件的发生时间**。

| 颗粒度 | 用途 |
|---|---|
| **大限**（10 年） | 大趋势 / 人生阶段 |
| **流年**（1 年） | 年度规划 / 重要事件 |
| **流月**（1 月） | 项目应期 / 重要决定 |
| **流日**（1 日） | 重大决定择日 |
| 流时（1 时辰） | 占卜 / 极少用 |

**应期推法的核心原则**（中州派立场）：
1. **由粗到细**：先看大限，再流年，再流月，再流日
2. **三层叠加**：本命 × 大限 × 流年 三层判读
3. **关键节点**：化禄 / 化忌 / 煞星 / 重要主星的"激活"是应期触发点
4. **结构性而非实证**：所有应期判断是**倾向性**，不是"必然"

## 3. 现代解释

### 3.1 应期推法的"5 步流程"

**Step 1**：先定大限

确定当前所在的大限（哪个 10 年）→ 看大限宫的本命星情 + 大限四化

**Step 2**：在大限内定流年

看具体年份的流年命宫 → 看流年宫的本命星情 + 大限叠加 + 流年四化

**Step 3**：在流年内定流月

看具体月份的流月命宫 → 看流月宫的本命星情 + 大限 + 流年 + 流月四化叠加

**Step 4**：在流月内定流日（如需）

看具体日子的流日命宫

**Step 5**：综合判读

四层叠加 → 应期定位

### 3.2 应期触发的"4 类关键事件"

#### 3.2.1 财运应期

| 触发 | 应期类型 |
|---|---|
| 本命财帛 + 大限化禄 + 流年化禄 | **大财之年** |
| 本命财帛化忌 + 大限化忌 | **重大破财年** |
| 流年化禄进财帛 | 该年财气开 |
| 流年化忌进财帛 | 该年破财警惕 |
| 武曲化禄触发 + 大限走至武曲宫 | 实业财开 |

#### 3.2.2 婚姻 / 感情应期

| 触发 | 应期类型 |
|---|---|
| 流年红鸾天喜入夫妻 + 化禄触发 | **婚喜之年** |
| 流年化忌进夫妻 + 武曲化忌 | **婚姻危机年** |
| 大限夫妻宫见禄 | 10 年内有结婚机会 |
| 大限夫妻宫见忌 | 10 年内婚姻有挑战 |
| 流年化禄 + 流月红鸾 | 当月有桃花 / 结识机会 |

#### 3.2.3 事业 / 升迁应期

| 触发 | 应期类型 |
|---|---|
| 本命官禄 + 大限化禄化权 | 大限内升迁 / 创业机会 |
| 流年化禄进官禄 | 该年升迁顺利 |
| 流年化忌进官禄 | 该年事业挑战 / 易失业 |
| 大限走至化禄宫 + 紫微 / 武曲 | 大限事业高峰 |
| 流年走至火贪 / 铃贪宫 | 该年突发机遇 / 暴发窗口 |

#### 3.2.4 健康 / 灾难应期

| 触发 | 应期类型 |
|---|---|
| 流年化忌进疾厄 | 该年健康警惕 |
| 大限走至刑忌夹印宫 | 10 年内法律 / 刑伤 / 失业风险 |
| 流年廉贞化忌 | **极重健康警惕**（手术 / 重病 / 法律） |
| 流年武曲化忌 | 破财 / 手术 / 牙齿 / 金属伤 |
| 大限 + 流年双化忌同宫 | **极重灾年** |

### 3.3 应期的"修正因素"

不是所有应期触发都能 100% 应验。**修正因素**：

| 因素 | 影响 |
|---|---|
| 化科救（化科会照化忌宫） | 减伤 30-50% |
| 化禄救（化禄会照化忌宫） | 减伤 20-40% |
| 主动避险（择日 / 行为调整） | 减伤 10-30% |
| 反向化忌（化忌叠加化忌） | **加重 30-50%** |
| 煞星加凑 | **加重 20-40%** |

### 3.4 应期判断的"诚实概率"框架

按命主要求"诚实概率估算"，应期判断按以下结构性概率（**非实证数据**）：

| 触发等级 | 描述 | 结构性概率 |
|---|---|---|
| ★★★★★ | 三层叠加（本 + 大 + 流）化忌 + 多煞 | 60-75%（重大事件发生） |
| ★★★★ | 双层化忌或单层 + 多煞 | 45-60% |
| ★★★ | 单层化忌 + 单煞 | 30-45% |
| ★★ | 单层化忌或单煞 | 20-35% |
| ★ | 杂耀凶星会照 | 10-20% |

**警告**：以上概率为**结构性内部逻辑**，不是实证数据。命理框架内部一致 ≠ 现实必然发生。

## 4. 例子（结构性，非实证）

### 4.1 应期推法实例

假设某命主：
- 本命：武曲化忌在夫妻宫（壬年生）
- 当前大限：第 3 限（23-32 岁），走至化忌宫（夫妻宫）
- 当前流年：2026 丙午

**Step 1 大限分析**：第 3 限直接踩武曲化忌 → 婚姻 / 感情挑战的 10 年

**Step 2 流年分析**：2026 丙年 → 廉贞化忌 → 看廉贞落本命何宫
- 假设廉贞在子女宫 → 该年子女 / 创造性输出受阻

**Step 3 叠加**：
- 本命武曲化忌 + 大限走至该宫 + 流年廉贞化忌（不在夫妻宫）
- 婚姻挑战 = 主要风险（大限触发）
- 子女 / 创作 = 次要风险（流年触发）

**Step 4 概率估算**：
- 婚姻冲突或感情挑战：50-65%（结构性）
- 子女 / 创作受阻：30-45%
- 健康整体风险：20-35%

**Step 5 建议**：
- 主动经营婚姻 / 感情沟通
- 不冒险投资创业（子女宫主创造性输出）
- 定期体检
