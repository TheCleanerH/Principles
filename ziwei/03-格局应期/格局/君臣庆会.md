# 君臣庆会格

## 1. 核心定义

**君臣庆会格**：紫微（"君"）+ 多颗辅佐之星（"臣"）会聚命三方。

| 维度 | 内容 |
|---|---|
| 成立条件 | 紫微坐命（或紫府同宫）+ 左辅右弼 + 文昌文曲 + 天魁天钺 多星会照 / 同宫 / 夹命 |
| 性质 | **顶级正格**之一 |
| 主格意 | **大富大贵 / 帝臣俱在 / 大成就** |

**核心隐喻**：紫微是"君"，左右昌曲魁钺是"臣"。臣全到位，君才能成大用。

**与紫府同宫的关系**：紫府同宫 + 君臣庆会 → 顶配中的顶配格局。

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷四·骨髓赋》

> 紫府**朝垣**，**食禄万钟**。
> **左右昌曲**会**紫微**，**位极人臣**。

白话翻译（笔者所加）：紫府朝垣主大富贵；左右昌曲会紫微（即君臣庆会基础），主官至极品。

### 2.2 《紫微斗数全书·卷四·骨髓赋》（续）

> **君臣庆会**，**才善经邦**。

白话翻译（笔者所加）：君臣庆会格主有治国之才。

## 3. 现代解释

### 3.1 "君臣"配置详解

| 君 | 臣（必备） | 臣（加强） |
|---|---|---|
| 紫微（或紫府同宫） | 左辅右弼 + 文昌文曲 + 天魁天钺 | 化禄 / 化权 / 化科 / 禄存 / 三台八座 / 恩光天贵 |

**最严格的君臣庆会**：**所有臣星齐凑会照** + **无煞冲** + **化禄 / 化权触发**

**宽松版的君臣庆会**：紫微 + **任意 4 颗以上**臣星会照即可

### 3.2 君臣庆会的"现代命格"

历史上的君臣庆会命主多为：
- 帝王（古义直接对应）
- 大臣 / 宰相
- 大商人 / 大富豪
- 大学者 / 大政治家

**现代延伸**：
- 跨国企业 CEO / 创始人
- 国家级领导 / 高级政务官
- 大学者 / 学界领袖
- 文化界 / 学术界顶级人物

### 3.3 "君臣不全"的降级

| 降级条件 | 降到什么格 |
|---|---|
| 紫微独坐 + 仅 1-2 颗臣星 | "孤君无臣"，普通命格 |
| 紫微 + 部分臣星 + 多煞 | "君遭乱" → 上位但多波折 |
| 紫微 + 多臣星 + 但夹忌或空劫破 | "君臣失序" → 名实不符 |

**反对**：未达"君臣庆会"标准就断"大贵"。

### 3.4 君臣庆会的"应期"

君臣庆会命主**早年即显**（不像杀破狼需 30+ 后才发）：
- 第 1 限：早慧 / 受重视
- 第 2 限：青年才俊
- 第 3 限：事业初动
- 第 4 限：大成期开始
- 第 5 限：人生巅峰
- 第 6 限及后：保持地位

## 4. 例子（结构性，非实证）

### 4.1 严格版君臣庆会

- 命宫：紫微在午
- 命宫**夹宫**：左辅 + 右弼
- 三合：文昌 + 文曲
- 会照：天魁 + 天钺
- 化曜：化禄 + 化权 + 化科
- 无煞冲

→ **严格君臣庆会**
→ 极顶级命格 — 历史上传说"乾隆""康熙"等帝王命格类似（**待具体盘验证**）

### 4.2 宽松版君臣庆会

- 命宫：紫府同宫在寅
- 辅星：左辅、右弼、文昌、天魁 4 颗（缺文曲、天钺）
- 化禄
- 微煞

→ **宽松版君臣庆会**
→ 政商高位 / 大企业领导 / 学界领袖

### 4.3 "君臣失序"破格

- 命宫：紫微在子
- 辅星：左辅、文昌、天魁
- 但：地空地劫夹命 + 化忌冲

→ **君臣失序**
→ 看似大格实则**名实不符** / 早发晚衰

## 5. 流派分歧

| 议题 | 中州派 | 飞星派 | 现代 |
|---|---|---|---|
| 君臣庆会定义 | 紫微 + 六吉星会照 | 同 | 同 |
| 严格 vs 宽松 | 严格 = 全凑无煞，宽松 = 部分凑 | 同 | 现代实证派多用宽松标准 |
| 君臣失序 | 重伤格 | 同 + 看四化飞动 | 同 |
| 现代女命君臣庆会 | 大成就女性 | 同 | 慧心斋主：女命君臣庆会主大成，反对古义"以夫为天" |
