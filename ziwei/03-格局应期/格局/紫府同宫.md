# 紫府同宫格

## 1. 核心定义

**紫府同宫格**：紫微 + 天府**同坐命宫**（仅在**寅 / 申**两宫成立）。

| 维度 | 内容 |
|---|---|
| 成立条件 | 紫微 + 天府同坐命宫（寅或申） |
| 仅成立宫 | **寅宫**（紫微在寅 / 天府在戌的格不算 — 须同宫）/ **申宫** |
| 性质 | **顶级正格**之一 |
| 主格意 | 帝星 + 财库同坐，主**大格局 / 富贵双全** |

**为什么仅在寅 / 申**：紫微与天府的对应关系是"关于辰戌轴对称"，紫微在某宫则天府在固定的对称宫。两星**同宫**仅发生在轴心点 — 即寅 / 申。

## 3. 现代解释

### 3.1 紫府同宫的"双帝合体"

- 紫微 = **动态帝星**（进取 / 领导）
- 天府 = **静态库星**（守成 / 财库）
- 二者同宫 → 既有领导力又有守财力，**进退兼备**

### 3.2 紫府同宫的"必备条件"（中州派立场）

紫府同宫**不等于**自动大格 — 需配合：

| 配合条件 | 作用 |
|---|---|
| **左辅右弼**会照 / 同宫 | 助力到位，成"君臣庆会"基础 |
| **文昌文曲**会照 / 同宫 | 文采加身，主学问名声 |
| **天魁天钺**会照 | 贵人扶持 |
| **化禄 / 化权 / 化科**之一 | 动态触发 |
| **无煞冲**（火铃陀羊不齐 / 空劫不强） | 格局不破 |

**全凑成立 → 君臣庆会格** → 顶级命格

**反对**：单凭紫府同宫断"必大富贵" — 没有辅星和无煞冲，仅是"稳重命格"而已。

### 3.3 紫府同宫"破格"的情况

| 破格条件 | 影响 |
|---|---|
| 紫府 + 地空 / 地劫 | **空露库** / 帝星空虚 → 名实不符 / 易破财 |
| 紫府 + 化忌邻宫夹击 | 受困 / 大格降为中格 |
| 紫府 + 火铃陀羊齐凑 | 帝库受冲 → 重伤 |
| 紫府 + 桃花星（红鸾天姚等）多 | 帝星沾桃花 → 易因感情误事 |

## 4. 例子（结构性，非实证）

### 4.1 顶级紫府同宫格

紫府同宫在寅 + 左辅右弼夹 + 文昌文曲三合 + 天魁天钺会照 + 化禄 + 无煞

→ **顶级君臣庆会格**
→ 历史上典型：**乾隆皇帝**据传命格类似（**待核实历史考证**）

### 4.2 普通紫府同宫格

紫府同宫在寅 + 仅天魁会照 + 少量煞星

→ **稳重命格但非顶级**
→ 命主有领导力 + 守财能力，但需自己努力，不会"天降福气"

### 4.3 破格紫府同宫

紫府同宫在申 + 地空地劫同宫 + 化忌冲

→ **名实不符 / 易破财**
→ 命主看似格局好，实际多波折
