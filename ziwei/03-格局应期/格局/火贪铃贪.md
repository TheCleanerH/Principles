# 火贪 / 铃贪格

## 1. 核心定义

**火贪格**：贪狼 + 火星同坐命宫（或同坐三方四正）
**铃贪格**：贪狼 + 铃星同坐命宫（或同坐三方四正）

| 维度 | 内容 |
|---|---|
| 成立条件 | 贪狼 + 火星 / 铃星 同宫，且在庙旺位 |
| 性质 | **暴发格 / 反凶为吉格** |
| 主格意 | **突发机遇 / 暴富暴贵，但来得快去得快** |

**核心反直觉**：火星 + 铃星本为煞星（六煞之二），但与贪狼同宫**反凶为吉** — 古籍最有名的"煞星激发主星成大用"案例。

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷四·骨髓赋》

> 贪狼**火星**居**庙旺**，**名镇诸邦**。
> 贪狼**铃星**会**辰戌丑未**，**威权**赫奕。

白话翻译（笔者所加）：贪狼 + 火星在庙旺位主大名声；贪狼 + 铃星在四墓宫（辰戌丑未）主大权威。

## 3. 现代解释

### 3.1 火贪 / 铃贪的"反凶为吉"原理

- 贪狼本主**欲望 + 机遇 + 应酬**
- 火星 / 铃星本主**暴烈 + 突发**
- 二者结合 → **欲望 + 突发力** → **抓住突发机遇暴发**

### 3.2 火贪 vs 铃贪的"细微差异"

| 项 | 火贪格 | 铃贪格 |
|---|---|---|
| 五行 | 火 + 木兼水 | 阴火 + 木兼水 |
| 性质 | **外发 / 明显** | **内蕴 / 持久** |
| 暴发节奏 | 快速 / 直接 | 缓慢 / 内积 |
| 适合行业 | 销售 / 公关 / 应酬业 | 实业 / 制造 / 长期积累型行业 |
| 来去节奏 | 快来快去 | 来得慢 / 去得也慢 |

### 3.3 火贪 / 铃贪的"必备条件"

| 条件 | 作用 |
|---|---|
| 贪狼庙旺（辰戌丑未 / 子午 / 寅申最佳） | 主星稳 |
| 火星 / 铃星庙旺 | 煞星激发力强 |
| 大限走至该宫 | **应期触发** |
| 化禄 / 化权同时见 | **加强激发** |

### 3.4 火贪 / 铃贪的"破格"

| 破格条件 | 影响 |
|---|---|
| 火 / 铃 + 贪狼 + **空 / 劫** | 欲望被空 → 反成清心 / 不暴发 |
| 火 / 铃 + 贪狼 + **化忌** | 欲望受挫 → 暴发反成暴落 |
| 火 / 铃 + 贪狼 + 陀罗（拖延） | 暴发力被拖 → 不显 |
| 贪狼陷地 + 火 / 铃 | 主星不稳 → 暴而无功 |

### 3.5 火贪 / 铃贪的"应期模型"

火贪 / 铃贪命主**一生有 1-3 次"暴发窗口"**，通常在大限走至该宫时：
- 第一次：年轻时（第 2-3 限）抓住第一个机遇
- 第二次：中年（第 4-5 限）大成
- 第三次（如有）：晚年（第 6 限以后）再发

**反对**：把火贪 / 铃贪当"必然暴富"的死断 — 配置不足时（非庙旺 / 无化禄 / 有破格）仍可能不显。

### 3.6 火贪 / 铃贪的"现代命主"

适合：
- **创业** / 风险投资 / 突发型行业
- **互联网 / 科技初创**（一夜成名）
- **娱乐 / 媒体 / 明星**（突然爆红）
- **销售 / 公关 / 应酬业**（快速成单）

**警告**：暴发后**易暴落** — 命主必须**主动建退路 + 不All In**。

## 4. 例子（结构性，非实证）

### 4.1 顶级火贪格

- 命宫：贪狼在午（庙）+ 火星同宫（庙）
- 三合：化禄 + 化权
- 大限走至命宫

→ **顶级火贪格**
→ 突发暴富 / 一夜成名 / 创业大成

### 4.2 标准铃贪格

- 命宫：贪狼在辰（四墓之一）+ 铃星同宫
- 辅星：左辅会照

→ **标准铃贪格**
→ 长期积累后暴发 / 实业老板 / 慢热型成功

### 4.3 破格火贪

- 命宫：贪狼在子（庙）+ 火星 + 地空地劫

→ **破格 → 反成清心**
→ 不暴发 / 命主可能转向宗教 / 学术 / 出世道路（也未必坏）

## 5. 流派分歧

| 议题 | 中州派 | 飞星派 | 现代 |
|---|---|---|---|
| 火贪 / 铃贪基础 | 一致 | 一致 | 一致 |
| 反凶为吉机制 | 煞星激发贪狼 | 同 + 看四化触发 | 同 |
| 火贪 vs 铃贪差异 | 火贪外发，铃贪内蕴 | 同 | 同 |
| 暴发后是否必暴落 | 高概率（无对冲措施） | 同 | 同 |
| 现代风险投资命主 | 火贪 / 铃贪结构性吻合 | 同 | 实证派多用 |
