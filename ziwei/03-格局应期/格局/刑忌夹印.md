# 刑忌夹印格

## 1. 核心定义

**刑忌夹印格**：天相（"印"）被**擎羊**（"刑"）+ **化忌**（"忌"）夹击。

| 维度 | 内容 |
|---|---|
| 成立条件 | 天相坐某宫 + 该宫两侧（前后邻宫）分别为擎羊 + 任意主星化忌 |
| 性质 | **重灾格** |
| 主格意 | **刑伤 / 是非 / 法律纠纷 / 失业 / 印权被夺** |

**核心隐喻**：
- **印** = 天相（化气为印 = 印鉴 / 贵气 / 辅佐）
- **刑** = 擎羊（刑伤之煞）
- **忌** = 化忌（阻滞之曜）
- **夹** = 两侧夹击，印星受困

## 2. 古籍出处

白话翻译（笔者所加）：天相被擎羊和化忌夹击，主刑伤 / 灾祸。

## 3. 现代解释

### 3.1 刑忌夹印的"成立条件"详解

**Step 1**：本命盘上找天相所在宫（设为宫 X）

**Step 2**：看宫 X 的前一宫（顺时针上一格）和后一宫（顺时针下一格）

**Step 3**：判断：
- 前邻宫有**擎羊**（或后邻宫有擎羊）
- 后邻宫有**化忌的主星**（或前邻宫有化忌的主星）
- 二者**分别在两侧**夹击天相

**Step 4**：如成立 → 刑忌夹印格

**注意**：擎羊和化忌**必须在不同邻宫**才构成"夹"。如二者同在一侧邻宫，不构成"夹"，仅"侧伤"，灾度较轻。

### 3.2 刑忌夹印的"灾难层级"

| 配置 | 严重度 |
|---|---|
| 擎羊夹 + 化忌夹 + 天相在重要宫（命 / 官 / 财） | **极重灾** |
| 擎羊夹 + 化忌夹 + 天相在六亲宫（夫妻 / 父母等） | **重灾** — 该六亲关系大动 |
| 擎羊夹 + 化忌夹 + 天相 + 化科救（化科在三方会照） | **降级**（减伤 30-50%） |
| 擎羊夹 + 化忌夹 + 天相 + 化禄会照 | **减伤但仍灾**（财气可缓解但不消除） |

### 3.3 刑忌夹印的"应期触发"

刑忌夹印的灾难**不一定立即发生**，需大限 / 流年触发：

- **大限走至刑忌夹印宫** → 该 10 年内灾难高发
- **流年触发** → 具体年份应期
- **本命刑忌夹印 + 大限化忌 + 流年化忌** → 三层叠加 = 极重灾年

### 3.4 刑忌夹印的"现代灾难类型"

| 灾难类型 | 概率倾向 |
|---|---|
| 刑伤外伤 / 手术 | 高 |
| 法律纠纷 / 官司 | 高 |
| 失业 / 职位被夺 | 中高 |
| 重大破财 | 中 |
| 重病（特别需要手术的） | 中 |
| 与配偶 / 家人重大冲突 | 中（如刑忌夹印在六亲宫） |

**应对建议**（结构性，非定论）：
- 大限走至该宫前 1-2 年，**主动准备**
- 避险驾驶 / 远离法律边界 / 不冒险投资
- 定期体检 / 重视健康
- 与重要人物保持良好关系

**反对**：把刑忌夹印作为"必然大灾"的死断 — 化解措施 + 化科救 + 大限不触发 → 灾难可能不显。

## 4. 例子（结构性，非实证）

### 4.1 标准刑忌夹印

- 命宫：天相在午
- 前邻宫（巳）：擎羊
- 后邻宫（未）：太阳化忌（甲年生人）

→ **标准刑忌夹印** → 命宫受夹击
→ 极重灾命格 → 一生需主动避险

### 4.2 六亲宫的刑忌夹印

- 夫妻宫：天相在子
- 夫妻前邻（亥）：擎羊
- 夫妻后邻（丑）：化忌主星

→ **夫妻宫刑忌夹印**
→ 婚姻易因刑伤 / 是非 / 重大冲突而破

### 4.3 化科救的刑忌夹印

- 命宫：天相在某宫被刑忌夹
- 但三方有**化科**会照

→ **化科救刑忌**
→ 灾难减伤但仍需警惕
