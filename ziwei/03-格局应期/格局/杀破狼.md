# 杀破狼格

## 1. 核心定义

**杀破狼格**：七杀 / 破军 / 贪狼 三颗主星形成**命三方**（命宫 + 财帛 + 官禄）的格局。

| 维度 | 内容 |
|---|---|
| 成立条件 | 七杀、破军、贪狼 三星分别坐命三方四正中的命 / 财 / 官（按地支三合关系，三星自动构成三方四正） |
| 性质 | **动态命格**的典型代表（与"机月同梁"静态格对应） |
| 主格意 | **波动 / 变化 / 创业 / 起伏大** |
| 数量占比 | 紫微斗数中约**33% 命主**为杀破狼格（按理论分布） |

**关键认知**：杀破狼**不是"凶格"** — 是**变化型命格**。
- 顺时：大成就
- 逆时：大波动
- 关键变量：**配辅星 + 化曜 + 大限配合**

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷四·骨髓赋》

> **杀破狼**会合**陀火铃**，**身命遭凶**。
> **杀破狼**得**辅佐吉星**，**显贵**。

白话翻译（笔者所加）：杀破狼遇煞星齐凑则凶；得辅星扶持反成大贵。

### 2.2 《紫微斗数全书·卷四·女命骨髓赋》

> 女命**杀破狼**，**多波折**。

白话翻译（笔者所加）：女命杀破狼主一生多变动 / 波折。

**慧心斋主立场**：女命杀破狼不必死断"多波折" — 现代女命杀破狼**多成功创业 / 改革型女性**，"波折"反映性格特质而非宿命。

## 3. 现代解释

### 3.1 杀破狼的"三星分工"

| 星 | 在三方四正中的位置（典型） | 主作用 |
|---|---|---|
| **七杀** | 命 / 财 / 官之一 | **决断 + 创业** |
| **破军** | 命 / 财 / 官之一 | **变革 + 破立** |
| **贪狼** | 命 / 财 / 官之一 | **机遇 + 应酬** |

三星自动构成命三方（按地支三合）。**七杀在哪宫，破军和贪狼分坐另两宫**。

### 3.2 杀破狼的"三种走向"

| 走向 | 配置 | 表现 |
|---|---|---|
| **大成就型** | 杀破狼 + 辅星齐 + 化禄 / 化权 + 火贪 / 铃贪 + 无重煞 | 创业大成功 / 改革家 / 政商高位 |
| **波动型** | 杀破狼 + 一般辅星 + 部分煞星 | 起伏大但有作为 |
| **重灾型** | 杀破狼 + 重煞齐凑（火铃陀羊空劫） + 化忌冲 | 多挫折 / 易意外 / 健康警惕 |

### 3.3 杀破狼最适合的现代职业

- **创业** / 创始人 CEO
- **科技** / 互联网 / AI / 区块链
- **金融** / 投资（特别风险投资）
- **改革** / 变革岗位
- **海外业务** / 跨国发展
- **新兴行业**

**不适合**：
- 守成型职业（公务员 / 大企业普通员工）
- 静态保守工作
- 长期同岗位

### 3.4 杀破狼的"应期波动"

杀破狼命主每个大限的**波动幅度**远大于机月同梁。

| 大限 | 杀破狼命主典型表现 |
|---|---|
| 第 1 限（童年） | 早熟 / 不安分 / 多变化 |
| 第 2 限（青少年） | 求学多波折 / 多兴趣 |
| 第 3 限（成年初期） | 创业初动 / 第一次大变动 |
| 第 4 限（30+） | 渐入佳境 / 事业转折 |
| 第 5 限（40+） | 大成 / 大败的关键期 |
| 第 6 限（50+） | 稳定期 |

## 4. 例子（结构性，非实证）

### 4.1 大成就型杀破狼

- 命宫：七杀在午
- 财帛：贪狼在寅
- 官禄：破军在戌
- 辅星：左辅右弼会照命 + 文昌化科 + 化禄在官
- 煞星：仅有一颗陀罗，无空劫

→ **大格局杀破狼**
→ 创业成大业 / 改革型领袖
→ 类比：**毛泽东、邓小平等改革型领导人**（结构性类比，**待具体盘验证**）

### 4.2 波动型杀破狼

- 命宫：破军在子
- 财帛：七杀在申
- 官禄：贪狼在辰
- 辅星：仅天魁会照
- 煞星：火星 + 陀罗

→ **波动型**
→ 创业有成但起伏大 / 50% 成功 50% 失败

### 4.3 重灾型杀破狼

- 命宫：贪狼在子
- 财帛：七杀在申
- 官禄：破军在辰
- 辅星：少
- 煞星：火铃陀羊齐凑 + 地空地劫 + 廉贞化忌冲

→ **重灾型**
→ 多挫折 / 健康警惕 / 易意外
