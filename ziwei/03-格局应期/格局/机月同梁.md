# 机月同梁格

## 1. 核心定义

**机月同梁格**：天机 / 太阴 / 天同 / 天梁 四颗主星形成**命三方**联动的格局。

| 维度 | 内容 |
|---|---|
| 成立条件 | 天机、太阴、天同、天梁 四星分别 / 部分坐命三方 |
| 性质 | **静态命格**的典型代表（与"杀破狼"动态格对应） |
| 主格意 | **稳定 / 公职 / 文教 / 服务 / 不重大变化** |
| 数量占比 | 紫微斗数中约**33% 命主**为机月同梁格 |

**关键认知**：机月同梁是**"吏人格"**（古义指公务员、文职、行政岗位）。

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷四·骨髓赋》

> **机月同梁**作**吏人**。

白话翻译（笔者所加）：机月同梁格主公务员 / 文职 / 行政性工作。

### 2.2 《紫微斗数全书·卷四·骨髓赋》（续）

> 机月同梁**逢**化禄**化权**，**升迁**有期。

白话翻译（笔者所加）：机月同梁见化禄 / 化权 → 升迁顺利。

## 3. 现代解释

### 3.1 机月同梁的"四星分工"

| 星 | 主作用 |
|---|---|
| **天机** | **智慧 + 策划** |
| **太阴** | **细腻 + 储蓄** |
| **天同** | **温和 + 安稳** |
| **天梁** | **长者气 + 庇荫** |

四星合一 → **稳重、有谋、温和、有福** 的命格

### 3.2 机月同梁最适合的现代职业

- **公务员** / 政府机关
- **教师** / 教育系统
- **医生** / 医疗（特别中医、内科）
- **行政** / 文职
- **服务业** / 客户经理
- **金融** / 银行（特别后台）
- **文教** / 出版 / 媒体（文字工作）

**不适合**：
- 高风险创业
- 体力劳动
- 销售前线 / 高强度应酬

### 3.3 机月同梁的"现代修正"

古义"作吏人"主要指公务员。**现代延伸**：

- 大企业稳定岗位（HR、行政、财务后台、内容运营）
- AI 研究 / 学术研究（命主作为 AI 硕士可能吻合）
- 长期型咨询师 / 法律顾问

### 3.4 机月同梁的"应期稳定性"

机月同梁命主每个大限的**波动幅度**远小于杀破狼。

| 大限 | 机月同梁命主典型表现 |
|---|---|
| 第 1 限（童年） | 稳重 / 听话 / 学习好 |
| 第 2 限（青少年） | 求学顺利 / 重视家庭 |
| 第 3 限（成年初期） | 稳定就业 / 早婚倾向 |
| 第 4 限（30+） | 稳定升迁 / 家庭稳定 |
| 第 5 限（40+） | 中层管理 / 中等收入 |
| 第 6 限（50+） | 退休前的稳定期 |

**反对**："机月同梁主一生平庸"的死断 — 机月同梁也可大成，但路径稳定而非剧烈。

## 4. 例子（结构性，非实证）

### 4.1 标准机月同梁

- 命宫：天机在卯
- 财帛：太阴在亥
- 官禄：天梁在未
- 迁移：天同照入
- 辅星：左辅右弼会照 + 化科

→ **标准机月同梁格**
→ 公务员或大企业稳定升迁

### 4.2 机月同梁 + 化禄化权

- 命宫：天梁
- 辅星：化禄 + 化权同时触发
- 大限走至化禄宫

→ **机月同梁升迁期**
→ 中层管理升至高管或重要技术岗位

### 4.3 机月同梁 + 煞星齐凑（破格）

- 机月同梁基础上 + 火铃陀羊齐凑 + 化忌冲

→ **破格**
→ 失去稳定特质 / 反成动荡 / 难升迁

## 5. 流派分歧

| 议题 | 中州派 | 飞星派 | 现代 |
|---|---|---|---|
| 机月同梁性质 | 稳定型 | 同 | 同 |

| 适合现代职业 | 公职 / 教师 / 医生 / 大企业稳定岗 | 同 | 现代加上"AI / 学术研究" |
