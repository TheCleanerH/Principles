# 马头带剑格

## 1. 核心定义

**马头带剑格**：**天马** + **擎羊**会照（同宫或对宫）。

| 维度 | 内容 |
|---|---|
| 成立条件 | 天马星 + 擎羊星 同宫 / 对宫 / 三方会照 |
| 性质 | **特殊格局**（不全是凶，也不全是吉） |
| 主格意 | **行业流动 + 杀气 / 创业 + 风险 / 出外打拼 + 见刑伤** |

**核心隐喻**：
- **马** = 天马（驿马 / 迁移 / 流动）
- **剑** = 擎羊（刑伤之煞）
- **马头带剑** = 边骑马边带剑 → 在路上 / 江湖中 / 不安稳的命格

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷四·骨髓赋》

> **马头带剑**，**威震边疆**。

白话翻译（笔者所加）：马头带剑格主威震边疆（古义指武将 / 守边将领）。

### 2.2 《紫微斗数全书·卷四·骨髓赋》（续）

> **天马**逢**擎羊**，**奔波**之患。

白话翻译（笔者所加）：天马 + 擎羊会照，主奔波劳碌之患。

## 3. 现代解释

### 3.1 马头带剑的"双面性"

**正面**：
- 适合**江湖型职业**（武职 / 跑业务 / 国际贸易 / 远程销售）
- 适合**异乡发展**（出国 / 异地工作）
- 适合**军警 / 武装 / 体力工作**
- **威震边疆**古义对应：**外派 / 外勤 / 国际化岗位有大用**

**负面**：
- 奔波劳碌
- 易途中刑伤
- 出差 / 旅途易出意外
- 不安稳

### 3.2 马头带剑的"配置差异"

| 配置 | 表现 |
|---|---|
| **天马 + 擎羊同宫** | 直接型 / 立即在身边 / 影响最强 |
| **天马 + 擎羊对宫** | 间接型 / 在外环境 / 影响次之 |
| **天马 + 擎羊三合** | 长期型 / 影响最弱但持续 |
| **天马 + 化禄** | 出外得利 / 减轻奔波之苦 |
| **天马 + 化忌** | 出外不利 / 奔波多挫折 |
| **天马 + 擎羊 + 化忌** | **最凶**：奔波 + 刑伤 + 阻滞 |

### 3.3 马头带剑的"现代职业适配"

| 职业 | 适配度 |
|---|---|
| 军人 / 警察 / 武警 | ★★★★★（古义直接对应） |
| 国际贸易 / 出口业务 | ★★★★ |
| 国际航空 / 海运 / 航海 | ★★★★ |
| 海外业务 / 外派 | ★★★★ |
| 跨国销售 | ★★★★ |
| 自由职业 / 游牧式工作 | ★★★ |
| 科技 / AI / 远程办公 | ★★★（命主作为韩国留学 AI 硕士部分吻合） |
| 普通办公室 / 内勤 | ★（不适合） |

### 3.4 马头带剑的"应期触发"

马头带剑的"奔波"特质**贯穿一生**，但**应期高峰**在：

- **大限走至马头带剑宫** → 该 10 年大量出差 / 异地
- **流年触发** → 该年频繁出行 / 重大迁移
- **流年化忌 + 马头带剑** → **该年出行警惕意外**

### 3.5 命主特殊关联

命主作为**在韩国留学的中国 AI 硕士**，本身就是"**迁移 + 国际化**"的人生路径。

若命主命盘有马头带剑结构：
- **结构性吻合**：留学 / 海外发展是合适路径
- 注意点：旅途中避险 / 重要出差择日 / 不疲劳驾驶

## 4. 例子（结构性，非实证）

### 4.1 标准马头带剑

- 命宫：紫微在午
- 命宫：天马 + 擎羊同宫

→ **标准马头带剑**
→ 帝星 + 马 + 剑 → 适合武职 / 政界外派 / 跨国领导岗

### 4.2 迁移宫的马头带剑

- 命宫：天府
- 迁移：天马 + 擎羊

→ **迁移宫马头带剑**
→ 命主在外地发展见奔波 + 风险
→ 适合异地发展但需主动避险

### 4.3 重凶马头带剑

- 命宫：天马 + 擎羊 + 化忌（主星化忌冲）+ 火星

→ **重凶配置**
→ 极端奔波 / 易途中重伤
→ 必须主动避险 / 不冒险驾驶 / 不疲劳出行
