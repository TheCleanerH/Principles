# 日月并明格

## 1. 核心定义

**日月并明格**：太阳 + 太阴**同时庙旺**且形成命三方联动。

| 维度 | 内容 |
|---|---|
| 成立条件 | 太阳 + 太阴 同坐命宫 / 对宫 / 三合宫 + **都在庙旺位** |
| 性质 | **正格**之一（亚顶级） |
| 主格意 | **名利双全 / 阴阳调和** |

**子格区分**：

| 子格 | 配置 | 表现 |
|---|---|---|
| **日月同临格** | 太阳 + 太阴**同宫**（仅在**丑 / 未**成立） | 阴阳同宫 / 同时在 + 同时陷的边界点 |
| **日月反背格** | 太阳陷 + 太阴陷 | 阴阳俱失辉 / 反主早年困苦 |
| **日月并明格**（标准） | 太阳庙 + 太阴庙 + 三合或会照 | **标准正格** |
| **日月夹命格** | 命宫被太阳 + 太阴夹 | 主贵气 |

## 2. 古籍出处

### 2.1 《紫微斗数全书·卷四·骨髓赋》

> **日月**并明，**主大贵**。
> **日月夹命**，**为奇格**。

白话翻译（笔者所加）：太阳 + 太阴同庙旺，主大贵；日月夹命宫，主奇贵。

### 2.2 《紫微斗数全书·卷四·骨髓赋》（续）

> **日月反背**，**主**贫贱**孤独**。

白话翻译（笔者所加）：太阳 + 太阴俱陷地，主早年贫贱孤独（**古夸张**，**慧心斋主反对死断**）。

## 3. 现代解释

### 3.1 太阳 + 太阴的"庙旺陷"地支

**太阳庙旺**（白天 / 上升期）：
- 寅 / 卯 / 辰 / 巳 / 午（午最旺）

**太阴庙旺**（夜晚 / 月光满）：
- 酉 / 戌 / 亥 / 子 / 丑（亥最旺）

**日月同时庙旺**的地支组合（关键）：
- 太阳在午 + 太阴在亥（最强）
- 太阳在巳 + 太阴在子
- 太阳在辰 + 太阴在丑
- 太阳在卯 + 太阴在酉（互对）— 这是"日月同临"前的格

**日月同时陷**的地支组合（反背）：
- 太阳在申 + 太阴在卯（俱陷）
- 太阳在酉 + 太阴在辰
- 太阳在戌 + 太阴在巳

### 3.2 日月并明的"性格特征"

| 维度 | 表现 |
|---|---|
| 性格 | 阴阳调和 / 既光明又内敛 / 既外向又细腻 |
| 才能 | 多面手 / 既能领导又能辅佐 |
| 人际 | 男女缘都好 / 长辈贵人多 |
| 名利 | 名利双收倾向（如配齐辅星） |

### 3.3 日月反背的"修正"

古义"日月反背主贫贱孤独"**现代不取字面理解**：

- 日月反背命主**早年多挫折**是事实
- 但**现代不必死断"贫贱孤独一生"**
- **晚发**为吉 — 30+ 后渐入佳境
- 适合**奋斗型 / 自立早 / 不靠家庭**的人生路径

### 3.4 日月并明的"应期"

| 大限 | 日月并明命主典型表现 |
|---|---|
| 第 1 限 | 早慧 / 受重视 / 阴阳调和 |
| 第 2 限 | 求学顺 / 多才多艺 |
| 第 3 限 | 事业初动 / 早成 |
| 第 4 限 | 大成期 |
| 第 5 限 | 人生巅峰 / 名利双收 |
| 第 6 限及后 | 保持地位 |

## 4. 例子（结构性，非实证）

### 4.1 标准日月并明

- 命宫：太阳在午（最旺）
- 三合：太阴在亥（最旺）
- 辅星：左右昌曲会照

→ **顶级日月并明**
→ 名利双收 / 公职 / 教育 / 媒体 / 跨国发展

### 4.2 日月夹命格

- 命宫：紫微在午
- 命宫前一宫（巳）：太阳
- 命宫后一宫（未）：太阴
- 二者夹紫微

→ **日月夹命格**
→ 奇贵之命 / 帝星受阴阳助力

### 4.3 日月反背

- 命宫：太阳在申（陷）
- 三合：太阴在卯（陷）

→ **日月反背**
→ 早年挫折 / 自立早
→ 反对死断"贫贱孤独"，现代多为晚发型 / 自立成功者
