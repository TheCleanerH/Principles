# 扩展格局合集（10+ 格局）

> 本文件收录 8 大主格局以外的扩展格局。
> 每个格局按"成立条件 / 古籍出处 / 现代解读 / 反神秘化校正"四区块简写。
> 8 大主格局见 [03-格局应期/格局/](../) 各独立文件。

## 1. 紫府朝垣格

| 项 | 内容 |
|---|---|
| 成立条件 | 紫微 + 天府**分别在命三方**（命 / 财 / 官），不同宫 |
| 与紫府同宫的区别 | 紫府同宫 = 二者同宫（寅 / 申）；紫府朝垣 = 二者在命三方但不同宫 |
| 古籍 | 《骨髓赋》"紫府朝垣，食禄万钟" |
| 现代解读 | **顶级正格之一** — 大格局 / 主大富贵 |
| 现代职业 | 政商高位 / 大企业 CEO / 顶级富豪 |
| 反神秘化 | 仍需辅星齐 + 无煞冲；单凭格局名不构成"必富贵" |

## 格局识别的判读顺序

1. 先看**双主星组合**（紫府 / 紫破 / 紫杀 / 紫贪 / 武贪 / 武府 等）
2. 再看**三星会照**（杀破狼 / 机月同梁 / 日月并明 / 阳梁昌禄 等）
3. 再看**辅星会聚**（君臣庆会 / 双禄朝垣 / 文星朝命）
4. 再看**煞星组合**（火贪 / 铃贪 / 火铃夹 / 空劫夹）
5. 最后看**夹宫格**（刑忌夹印 / 羊陀夹忌）
