# 案例 · 蒋介石

> **重要声明**：学习练习。蒋介石盘在两岸紫微圈有大量解读，本笔记仅作框架性整理。

## 1. 生辰信息

| 出生地 | 浙江奉化溪口 | 公开记载 |
| 出生地经度 | 约东经 121.4° | 地理 |

## 2. 真太阳时校正

- 1887 年中国无统一时区，用地方时
- 出生地溪口（东经 121.4°）= 当地真太阳时
- 午时记载较稳定 → 生时存疑度低

## 3. 命盘要点（按午时推算）

| 项 | 内容 |
|---|---|
| 年命 | 丁亥年男命（阴干 → **逆行**大限） |
| 五行局 | 待软件确认 |
| 命宫推算 | 寅起正月顺数九月 → 寅=正、卯=二、辰=三、巳=四、午=五、未=六、申=七、酉=八、戌=九 → 九月在戌宫 |
| 戌宫起子时逆数午时 | 戌=子、酉=丑、申=寅、未=卯、午=辰、巳=巳、辰=午 → **命宫在辰** |

**命宫推测为辰宫**。

## 4. 蒋介石历史行为特征

- **军事 + 政治领袖**
- **保守 + 守旧倾向**（与毛泽东形成对比）
- **重传统 + 中正之名**（自称"中正"）
- **多次掌权与失权**（北伐 / 抗战 / 内战败退 / 台湾 38 年）
- **长寿 88 岁**
- **基督徒 + 受妻子宋美龄影响极深**

**对应紫微星情倾向**：
- **紫微 / 天府 + 保守端庄**
- **武曲 / 廉贞 + 军事 + 公关**
- **天梁 + 长寿**
- **与配偶关系深** → 夫妻宫强
- **多次起伏** → 部分杀破狼或化忌触发

## 5. 主要格局识别（推测）

| 格局 | 可能性 |
|---|---|
| 紫府同宫 / 紫府朝垣 | 中高（保守 + 守成 + 顶级政治地位） |
| 君臣庆会 | 中（军政高位） |
| 机月同梁 + 部分杀破狼 | 中 |
| 日月并明 | 待核 |

**结构性推测**：**紫府 + 君臣庆会**为主，**部分杀破狼**点缀（多次起伏 → 杀破狼变动）

## 6. 大限对位 — 历史事件

| 大限 | 年龄 | 历史事件 | 推测紫微解读 |
|---|---|---|---|
| 第 1 限 | 6-15 | 童年溪口 + 启蒙 | 早年家境中等 |
| 第 2 限 | 16-25 | 日本陆军士官学校 + 同盟会 | 大限求学 + 军事启蒙 |
| 第 3 限 | 26-35 | 黄埔军校（37 岁前一年）+ 早期军事 | 大限化权触发 |
| 第 4 限 | 36-45 | **北伐成功（41 岁）+ 1928 全国统一** | **大限化禄化权巅峰** |
| 第 5 限 | 46-55 | **抗战（50 岁）** + 西安事变 | **大限延续巅峰** + 化忌（西安事变） |
| 第 6 限 | 56-65 | **抗战胜利 + 内战失败 + 1949 败退台湾（62 岁）** | **大限化忌触发** — 重大挫败 |
| 第 7 限 | 66-75 | 在台 + 1950s 政治改革 | 大限稳定期（守台） |
| 第 8 限 | 76-85 | 在台延续 + 中美关系变化 | 大限稳定 |
| 第 9 限 | 86-88 | 1975 病逝（88 岁） | 寿元终 |

**关键观察**：
- **1927 国共合作破裂（40 岁）+ 1928 北伐成功（41 岁）**：第 4 限中期，巅峰确立
- **1949 败退台湾（62 岁）**：第 6 限中期，**大限化忌触发**
- **1975 病逝（88 岁）**：长寿吻合天梁

## 8. 流派分歧

- **中州派**：蒋介石是"紫府 + 君臣庆会 + 部分杀破狼"，多次起伏但保守特质突出
- **飞星派**：会重点看 1949 节点的飞星轨迹
- **现代实证**：蒋介石的"信仰转变（基督教）+ 中正之名"反映**福德宫强**特质
