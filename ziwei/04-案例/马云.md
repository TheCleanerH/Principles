## 2. 真太阳时校正

- 1964 年中国实施北京时间（东经 120° 为准）
- 出生地杭州（东经 120°）= 北京时间（无经度时差）
- 1964 年无夏令时
- 真太阳时 ≈ 钟表时间（仅均时差微调）

**生时高度存疑**：
- 子时说（最常见）
- 酉时说
- 亥时说
- → **本笔记按子时推算**，但**实际可能错**

## 3. 命盘要点（按子时推算）

| 项 | 内容 |
|---|---|
| 年命 | 甲辰年男命（阳干 → **顺行**大限） |
| 五行局 | 待软件确认 |
| 命宫推算 | 寅起正月顺数八月 → 寅=正、卯=二、辰=三、巳=四、午=五、未=六、申=七、酉=八 → 八月在酉宫 |
| 酉宫起子时逆数子时 | 子时即起点 → **命宫在酉** |

**命宫推测为酉宫**（按子时）。

## 4. 马云历史行为特征

- **互联网创业 / 阿里巴巴创始人**
- **口才极佳 + 演讲家**
- **多次创业失败后大成**
- **争议人物**（金融监管 + 隐退）
- **国际化业务 + 美国上市**
- **2020 年后大幅退出公共视野**（蚂蚁集团 IPO 风波）

**对应紫微星情倾向**：
- **巨门 + 口才**（演讲家 + 善辩）
- **太阳 + 巨门** = **巨日格**（适合外国 / 跨文化 / 媒体）
- **杀破狼 + 创业**
- **化禄化权触发** — 阿里上市期
- **后期化忌触发** — 2020 蚂蚁风波

## 5. 主要格局识别（推测）

| 格局 | 可能性 |
|---|---|
| **巨日格**（太阳 + 巨门） | 高（演讲 + 媒体 + 跨国） |
| **杀破狼** | 高（多次创业 + 转型） |
| 火贪 / 铃贪 | 中（阿里突发暴富） |
| 君臣庆会 | 待核 |

**结构性推测**：**巨日格 + 杀破狼 + 部分火贪 / 铃贪** — 口才创业 + 突发暴富 + 多次转型

## 6. 大限对位 — 历史事件

| 大限 | 年龄 | 历史事件 | 推测紫微解读 |
|---|---|---|---|
| 第 1 限 | 5-14 | 童年杭州 + 英语自学 | 早年口才启蒙 |
| 第 2 限 | 15-24 | 高考三次落榜 + 杭师院 + 1988 毕业当英语教师 | **大限化忌触发**（高考挫折）+ 巨日格初动 |
| 第 3 限 | 25-34 | 1992 创海博翻译社 + 1995 创中国黄页（第一次互联网创业） | 大限化禄初动 + 互联网早期 |
| 第 4 限 | 35-44 | **1999 创立阿里巴巴 + 2003 淘宝 + 2004 支付宝** | **大限化禄化权巅峰开始** |
| 第 5 限 | 45-54 | **2014 阿里美国上市 + 2018 卸任** | **大限化禄延续 + 化权** — 巅峰期 |
| 第 6 限 | 55-64 | **2020 蚂蚁集团 IPO 暂停 + 退出公共视野** | **大限化忌触发** — 重大挫折 |
| 第 7 限 | 65-74 | （未来） | 待观察 |

**关键观察**：
- **三次高考失败**：第 2 限化忌触发期
- **1999 创阿里**（35 岁）：第 4 限初，**大限化禄化权触发**
- **2014 上市**（50 岁）：第 5 限中，**大限延续巅峰**
- **2020 IPO 风波**（56 岁）：第 6 限初，**大限化忌触发**
