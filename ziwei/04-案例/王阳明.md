## 4. 王阳明历史行为特征

- **极强思辨力 + 学术创建**（心学集大成者）
- **军事才能**（剿匪 + 平定宁王之乱）
- **教育影响力**（弟子遍天下，影响后世数百年）
- **晚发型**（35 岁龙场悟道，前期多挫折）
- **健康较差**（多次重病，56 岁病逝）
- **三立**：立德、立功、立言 — 三者俱备

**对应紫微星情倾向**：
- **天机 + 智巧思辨**（心学）
- **太阳 + 太阴**（日月并明？— 学术 + 教育光明）
- **七杀 / 破军 + 军事才能**（剿匪 + 平叛）
- **化忌 + 早年挫折**（科举落第 + 政治受贬）
- **疾厄宫煞** + 早逝（56 岁去世）
