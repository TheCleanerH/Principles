## 2. 真太阳时校正

- 1893 年中国无统一时区，用地方时
- 出生地韶山（东经 112.5°）= 当地真太阳时
- 辰时记载较稳定 → 生时存疑度低
- **不需要北京时间转换**

## 3. 命盘要点（按辰时推算）

| 项 | 内容 |
|---|---|
| 年命 | 癸巳年男命（阴干 → **逆行**大限） |
| 五行局 | 待软件确认 |
| 命宫推算 | 寅起正月顺数十一月 → 寅=正、卯=二、辰=三、巳=四、午=五、未=六、申=七、酉=八、戌=九、亥=十、子=十一 → 十一月在子宫 |

## 4. 毛泽东历史行为特征

- **极强变革欲 + 不服管**（叛逆型领袖）
- **军事 + 政治 + 文学三栖**
- **诗词大家**（文采过人）
- **建国伟人**（极顶级政治地位）
- **晚年大转折**（文革 + 个人崇拜）
- **健康较好，83 岁长寿**

**对应紫微星情倾向**：
- **紫微 + 帝王气**（极顶级地位）
- **破军 / 七杀 + 变革军事**
- **文昌文曲 + 文采**（诗词）
- **化禄化权 + 大限化禄触发**（事业巅峰）
- **晚年化忌触发**（文革决策争议）

## 6. 大限对位 — 历史事件

| 大限 | 年龄 | 历史事件 | 推测紫微解读 |
|---|---|---|---|
| 第 1 限 | 6-15 | 童年韶山务农 + 启蒙 | 早年家境普通 / 求知欲 |
| 第 2 限 | 16-25 | 长沙求学 + 接触马克思主义 | 大限求学期 + 思想觉醒 |
| 第 3 限 | 26-35 | 建党 + 早期革命 + 井冈山 | **大限化权触发** + 杀破狼初动 |
| 第 4 限 | 36-45 | 长征 + 遵义会议 + 抗战开始 | **大限化禄化权** + 杀破狼第二动 |
| 第 5 限 | 46-55 | 抗战胜利 + 解放战争 + 建国（1949 56 岁） | **大限化禄 + 紫微化权** — 巅峰期开始 |
| 第 6 限 | 56-65 | 建国初期 + 大跃进（争议） | 大限化禄延续 + 化忌触发争议决策 |
| 第 7 限 | 66-75 | **文革（1966 73 岁）** | **大限化忌触发** — 重大争议决策 |
| 第 8 限 | 76-83 | 文革末期 + 病重逝世（1976 83 岁） | 大限化忌延续 + 寿元终 |

**关键观察**：
- **1935 遵义会议（42 岁）**：第 4 限中期，权力实质确立
- **1949 建国（56 岁）**：第 5 限末期，大成就期
- **1966 文革（73 岁）**：第 7 限初期，**大限化忌触发**
- **1976 逝世（83 岁）**：第 8 限末期

## 8. 流派分歧

- **中州派**：毛泽东是"杀破狼 + 紫微"顶级格局，大限化禄 + 化权触发巅峰
- **飞星派**：会重点看 1949 / 1966 / 1976 三个节点的飞星轨迹
