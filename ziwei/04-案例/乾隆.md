> **重要声明**：学习练习。乾隆作为"顶级帝王"是紫微圈最常用案例之一。

## 2. 真太阳时校正

- 1711 年清代用"地方平太阳时"
- 出生地北京（东经 116.4°）= 当地真太阳时
- **子时跨日**：23:00-23:59 归前一日（八月十二）/ 00:00-00:59 归当日（八月十三） — 需进一步确认
- **本笔记按八月十三子时（00:00-00:59）**

## 3. 命盘要点（按子时推算）

| 项 | 内容 |
|---|---|
| 年命 | 辛卯年男命（阴干 → **逆行**大限） |
| 五行局 | 待软件确认 |
| 命宫推算 | 寅起正月顺数八月 → 寅=正、卯=二、辰=三、巳=四、午=五、未=六、申=七、酉=八 → 八月在酉宫 |
| 酉宫起子时逆数子时 | 子时即起点 → **命宫在酉** |

**命宫推测为酉宫**。

## 4. 乾隆历史行为特征

- **顶级帝王**（在位 60 年 + 太上皇 3 年 = 63 年实际掌权）
- **极顶级生活水平**（清代最盛"康乾盛世"末段）
- **文采过人**（诗作 4 万首 — 数量历代之最，质量褒贬）
- **十全武功**（自称"十全老人"，军事威名）
- **风流多情**（后宫故事多）
- **长寿 87 岁**（清代帝王中最长）

**对应紫微星情倾向**：
- **紫微 + 帝王气**（极顶级）
- **紫府同宫 / 君臣庆会**（顶级吉格）
- **文昌文曲 + 文采**
- **桃花星 + 风流**（贪狼 / 廉贞 / 红鸾天喜等）
- **天梁 + 长寿**
- **化禄化权化科齐凑** — 三吉化大格局

## 6. 大限对位 — 历史事件

| 大限 | 年龄 | 历史事件 | 推测紫微解读 |
|---|---|---|---|
| 第 1 限 | 6-15 | 皇孙期 + 康熙喜爱 | 早年福气深 / 君臣庆会触发早 |
| 第 2 限 | 16-25 | **登基（25 岁 1735）** | **大限化禄触发** — 提前继位 |
| 第 3 限 | 26-35 | 早期治国 + 平定准噶尔 | 大限化权 + 武功 |
| 第 4 限 | 36-45 | 中期治国 + 文化盛世 | 大限化禄化科 + 文采 |
| 第 5 限 | 46-55 | "十全武功"完成 + 巅峰期 | **大限延续巅峰** |
| 第 6 限 | 56-65 | 晚期治国 + 和珅时代 | 大限化忌渐显（贪腐） |
| 第 7 限 | 66-75 | 让位（85 岁 1796）+ 太上皇 | 退位但仍掌权 |
| 第 8 限 | 76-85 | 太上皇期 + 1799 病逝（87 岁） | 寿元终 |

**关键观察**：
- **25 岁登基**：第 2 限中期，与"早发型君臣庆会"吻合
- **60 年在位**：跨第 2-7 限，大限化禄化权连续触发
- **87 岁长寿**：天梁 / 紫微保健康

## 8. 流派分歧

- **中州派**：乾隆是"紫府同宫 + 君臣庆会"顶级帝王命格，多吉化齐凑
- **飞星派**：会重点看其登基（1735）和退位（1796）两个节点的飞星
- **现代实证**：紫云观点 36 岁前后看父母 / 福德 — 乾隆 36 岁正是治国中期，与"事业巅峰期"吻合
