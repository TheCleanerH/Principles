## 2. 真太阳时校正

- 1904 年中国无统一时区
- 出生地杭州（东经 120°）= 当地真太阳时
- **戌时存疑**：不同文献记载有差异 → 建议**戌时为主**，**亥时**或**酉时**作对照

## 4. 林徽因历史行为特征

- **建筑学家 + 诗人 + 才女**
- **复合型才能**（建筑 + 文学 + 翻译 + 设计）
- **婚姻**：与梁思成相伴一生 + 早年与徐志摩感情纠葛
- **病弱**（肺结核 + 1955 病逝 51 岁）
- **国徽 + 人民英雄纪念碑设计参与**
- **现代女性独立的代表**之一

**对应紫微星情倾向**（慧心斋主立场）：
- **太阴 + 阴柔 + 文学才能**
- **文昌文曲 + 文采 + 设计**
- **天机 + 智巧 + 多面才能**
- **桃花星 + 复杂感情**（徐志摩 / 金岳霖 / 梁思成）
- **疾厄宫煞** + 病弱（肺结核）
- **天梁陷地或化忌** + 短寿
