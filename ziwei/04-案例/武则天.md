## 3. 武则天历史行为特征

- **中国唯一女皇帝**（载初元年 690 年称帝，时年 67 岁）
- **极强权力欲 + 杀伐果决**（清除李唐宗室）
- **才学过人 + 用人之能**（重用狄仁杰等）
- **极长寿**（82 岁去世 705 年）
- **复杂感情**（唐高宗后宫 → 武皇后 → 女皇 → 多面首）
- **历史评价两极**

**对应紫微星情倾向**：
- **紫微 + 七杀 + 帝王 + 杀伐**
- **武曲 + 决断**
- **贪狼 + 化禄 + 桃花 + 应酬**
- **化权 / 化忌齐凑** — 权欲极强
- **天梁 + 长寿**

## 7. 流派分歧

- **中州派 + 古典**：武则天是"紫杀 / 紫府 + 桃花 + 化权"顶级帝王命格
- **慧心斋主**：**最强反对"女命孤克"古义** — 武则天证明女命可以有**任何顶级格局**

- **古义女命**：会用"女命骨髓赋"贬义解读 — **本项目坚决反对**
