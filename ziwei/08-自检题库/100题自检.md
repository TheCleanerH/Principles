# 100 题自检题库

> 命主自我测试用题库。每题答案后含**对应笔记位置**和**置信度评估**。
> 题目按难度分级：★（基础）/ ★★（中等）/ ★★★（进阶）/ ★★★★（专家）

## 第一部分：基础知识（★，30 题）

### 1. 紫微斗数命盘有多少宫？
**答**：12 宫 + 身宫（叠加）
**参考**：[12宫位.md](../01-基础结构/12宫位.md)

### 2. 12 宫的名称是什么？（顺序）
**答**：命 / 兄弟 / 夫妻 / 子女 / 财帛 / 疾厄 / 迁移 / 交友（奴仆） / 官禄 / 田宅 / 福德 / 父母

### 3. 紫微系有几颗主星？请列出。
**答**：6 颗 — 紫微 / 天机 / 太阳 / 武曲 / 天同 / 廉贞

### 4. 天府系有几颗主星？请列出。
**答**：8 颗 — 天府 / 太阴 / 贪狼 / 巨门 / 天相 / 天梁 / 七杀 / 破军

### 5. 14 主星中哪些不入四化系统？
**答**：天府 / 天相 / 七杀（主流）— 详见 [四化-禄权科忌.md](../02-动态系统/四化-禄权科忌.md)
**置信**：中（部分流派有差异）

### 6. 五行局有哪 5 种？分别对应大限起始岁？
**答**：水二局（2 岁起）/ 木三局（3 岁起）/ 金四局（4 岁起）/ 土五局（5 岁起）/ 火六局（6 岁起）

### 7. 大限的顺逆方向规则？
**答**：男阳女阴顺行 / 男阴女阳逆行

### 8. 紫微 + 天府同宫只在哪两个地支？
**答**：寅 / 申

### 9. 紫府同宫 vs 紫府朝垣的区别？
**答**：同宫 = 二者同宫（仅寅/申）/ 朝垣 = 二者在命三方但不同宫

### 10. 杀破狼指哪三颗星？
**答**：七杀 + 破军 + 贪狼（命三方分坐）

### 11. 机月同梁指哪四颗星？
**答**：天机 + 太阴 + 天同 + 天梁

### 12. 六吉是哪六颗辅星？
**答**：左辅 / 右弼 / 文昌 / 文曲 / 天魁 / 天钺

### 13. 六煞是哪六颗？
**答**：火星 / 铃星 / 擎羊 / 陀罗 / 地空 / 地劫

### 14. 四化是哪四颗？
**答**：化禄 / 化权 / 化科 / 化忌

### 15. 化禄、化权、化科、化忌分别主什么？
**答**：禄主财利、权主权力、科主名声、忌主阻滞

### 16. 三方四正指什么？
**答**：本宫 + 对宫（相隔 6）+ 三合两宫（相隔 4 各一）

### 17. 命三方包含哪 4 宫？
**答**：命 + 迁移 + 财帛 + 官禄

### 18. 太阳最旺在哪个地支？
**答**：午（日丽中天）

### 19. 太阴最旺在哪个地支？
**答**：亥（月朗天门）

### 20. 紫微最旺在哪两个地支？
**答**：子 / 午（紫微居子午，科权禄拱为至贵）

### 21. 武曲最旺在哪些地支？
**答**：丑 / 辰 / 戌 / 未（四墓宫）+ 子 / 午

### 22. 真太阳时校正公式是什么？
**答**：钟表时间 + 经度时差 + 均时差 - 夏令时调整
**经度时差**：(出生地经度 - 时区中心经度) × 4 分钟

### 23. 中国大陆时区中心是东经多少度？
**答**：东经 120°（北京时间基准）

### 24. 韩国时区中心是东经多少度？
**答**：东经 135°（KST）

### 25. 中国 1986-1991 实施过夏令时吗？
**答**：是 — 每年 5 月至 9 月（具体日期各年不同）

### 26. 身宫叠加在 12 宫中的哪 6 宫之一？
**答**：命 / 夫妻 / 财帛 / 迁移 / 官禄 / 福德

### 27. 子时跨日的处理（中州派主流）？
**答**：23:00-23:59 归前一日；00:00-00:59 归当日
**置信**：中（部分流派有差异，**待考**）

### 28. 流年命宫如何定？
**答**：以当年地支所在的宫为流年命宫

### 29. 大限一限多少年？
**答**：10 年

### 30. 流月命宫如何定？
**答**：以流年命宫为流年正月，按月份顺时针前进

## 第三部分：格局与组合（★★★，20 题）

### 51. 君臣庆会的"君"和"臣"分别指什么？
**答**：君 = 紫微；臣 = 左辅 + 右弼 + 文昌 + 文曲 + 天魁 + 天钺（六吉）

### 52. 紫府朝垣格的具体配置？
**答**：紫微 + 天府分坐命三方（命 / 财 / 官），不同宫

### 53. 日月并明的严格条件？
**答**：太阳 + 太阴**都庙旺** + 形成命三方

### 54. 日月反背指什么？
**答**：太阳 + 太阴**都陷地**

### 55. 火贪格的"庙旺"地支是？
**答**：贪狼 + 火星都在庙旺位（贪狼庙旺在四墓宫 + 子 / 午）

### 56. 刑忌夹印的具体配置？
**答**：天相被擎羊 + 化忌 **两侧夹击**（前后邻宫各一）

### 57. 羊陀夹忌的具体配置？
**答**：禄存 + 化忌同宫 + 擎羊（前邻）+ 陀罗（后邻）

### 58. 马头带剑的具体配置？
**答**：天马 + 擎羊 会照（同宫 / 对宫 / 三合）

### 59. 阳梁昌禄格的具体配置？
**答**：太阳 + 天梁 + 文昌 + 化禄 同时会照（主学术 / 公职大成）

### 60. 财禄夹马格的具体配置？
**答**：天马 + 禄存 + 化禄 同宫 / 会照（主远方致富）

### 61. 桃花泛水格的具体配置？
**答**：贪狼 + 太阴 + 红鸾天喜咸池天姚 多桃花星会聚

### 62. 巨日格的最适合现代职业是？
**答**：跨国 / 外交 / 外语 / 律师 / 国际媒体 / 跨文化沟通

### 63. 紫府同宫 + 君臣庆会 + 火贪 = 多格叠加，古籍如何命名？
**答**：古籍**没有明确命名**（**待考**）— 通常称"极顶级"或"超叠加"

### 64. 7-杀朝斗格的"斗"指什么？
**答**：北斗位（七杀在寅 / 申 / 子 / 午 庙旺位朝向北斗）

### 65. 月生沧海格的太阴位置？
**答**：子 / 亥（最旺位）

### 66. 文星朝命的具体配置？
**答**：文昌 + 文曲 + 化科 同时会照命宫

### 67. 双禄朝垣格的双禄是？
**答**：化禄 + 禄存（同会照命三方）

### 68. 君臣庆会需要紫微 + 多少颗辅星？
**答**：严格 = 六吉全凑；宽松 = 4 颗以上
**置信**：中（标准不统一）

### 69. 杀破狼成格的"严格度"？
**答**：严格 = 三星齐凑命三方；宽松 = 至少两星 + 三方会照
**置信**：中（标准不统一）

### 70. 多格叠加时如何判读？
**答**：先看双星组合 → 再看三星会照 → 再看辅星会聚 → 再看煞星组合 → 最后看夹宫格

## 第六部分：反神秘化（★★★★，5 题）

### 96. 命主问"我 X 年会发财吗"，正确的回答方式？
**答**：不报具体金额；用结构性概率区间；标"结构性而非实证"

### 97. 命主问"X 命主能活到几岁"，正确的回答方式？
**答**：不报具体寿命；只说"长寿倾向 / 健康风险点"；建议就医

### 98. 命主问"X 命主必出轨吗"，正确的回答方式？
**答**：不死断"必出轨"；用"易感情复杂 / 桃花多"倾向；强调主动经营空间

### 99. 命主问"X 是天梁 + 月曜女命，是不是淫贱"，正确的回答方式？
**答**：**明确反对**古义；现代是慈悲母性多情女性；古义反映封建偏见

### 100. 命主问"今年是本命年，会有大灾吗"，正确的回答方式？
**答**：**不取"本命年""犯太岁"民俗** — 中州派 / 飞星派 / 现代实证派一致不取
