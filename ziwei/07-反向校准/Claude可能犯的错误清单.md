# Claude 可能犯的错误清单（反向校准）

> 本笔记是 Claude 主动列出的"自己可能犯的错"，**目的是让命主反过来挑出我的错误**。
> 项目成功的衡量指标不是"Claude 学得多好"，而是**命主能否在 3 周后挑出 Claude 至少 3 个判断错误**。
> 本笔记按"错误类型 / 我可能犯的错 / 命主如何核验"三栏式。

## 1. 古籍引用类错误（最容易犯）

### 1.1 古籍篇目张冠李戴
- **我可能犯的错**：把某句"骨髓赋"的句子说成"太微赋"，或反之
- **核验方法**：命主用 ctext.org 搜原句，看出处篇目是否对
- **可疑句**：本笔记中所有标"《全书·卷四·XX赋》"的引文都需校
- **常见混淆**：
  - "杀破狼会合陀火铃，身命遭凶" — 出自骨髓赋还是太微赋？（**待校**）
  - "机月同梁作吏人" — 通行版作"机月同梁作吏人" — 字句可能有差异

### 1.2 古文断句错误
- **我可能犯的错**：将古文按现代标点断错
- **核验方法**：对照 ctext.org 原文断句
- **可疑句**：所有古文引用 — 古籍原文一般无现代标点，断句是后人加的

### 1.3 古文白话翻译过度
- **我可能犯的错**：把古文意思翻得过远（如"威震边疆"翻成"外派国际化"过度延伸）
- **核验方法**：对照其他注家的翻译版本
- **可疑句**：每个"白话翻译（笔者所加）"都需对照

### 1.4 古籍作者归属
- **我标的"待考"**：
  - 《紫微斗数全书》作者（陈希夷 vs 罗洪先）
  - 《十八飞星策天紫微斗数全集》作者
  - 各赋文的具体作者

## 2. 流派归属类错误

### 2.1 四化版本归属
- **我可能犯的错**：
  - 戊干化科：取"右弼"（中州派主流），但**部分流派**主张"太阳" / "太阴"
  - 庚干化忌：取"天同"，但**部分流派**主张"太阴"
  - 壬干化科：取"左辅"，但**部分流派**主张"天府"
- **核验方法**：对照《全书》四化原表 + 多家现代著作
- **本笔记位置**：[四化-禄权科忌.md](../02-动态系统/四化-禄权科忌.md) §5

### 2.2 主星归斗
- **我可能犯的错**：
  - 天机：南斗第三 vs 北斗（**待考**）
  - 天梁：南斗第二 vs 第三
  - 贪狼：北斗第一 vs 南北交叉
- **核验方法**：对照《全书·卷一·诸星总论》

### 2.3 中州派 vs 飞星派结论混
- **我可能犯的错**：在没显式标注的地方引用了飞星派结论却没说
- **核验方法**：命主对照王亭之 vs 梁若瑜两家的具体表述
- **CLAUDE.md 立场**：任何飞星派结论必须**前缀**"飞星派认为"

## 3. 排盘机制类错误

### 3.1 命宫定位口诀
- **我可能犯的错**：
  - "寅起正月顺数生月、起子时逆数生时"是否完全准确？
  - 闰月命主的处理 — 我没详细讲
  - 子时跨日的处理 — 我说"23:00-23:59 归前日 / 00:00-00:59 归当日"，但**部分流派主张子时全部归当日**（**待考**）

### 3.2 五行局
- **我可能犯的错**：
  - 命宫天干用"五虎遁"推 → 命宫干支配纳音 → 五行局
  - 流程是否准确？是否有更直接的方法？
  - 60 甲子纳音表是否所有项都正确？

### 3.3 起紫微星
- **我可能犯的错**：
  - 完整起紫微星表（30 日 × 5 局）我只列了前 5 行
  - 余数为 0 时的处理规则可能有差异
- **核验方法**：用通行排盘软件交叉验证

### 3.4 安星顺序
- **我可能犯的错**：
  - 紫微系顺布 → 隔 N 宫安各星
  - 天府系顺布 → 紧邻安太阴等
  - 这些"隔几宫"的具体数字可能有出入

### 3.5 真太阳时校正
- **我可能犯的错**：
  - 经度时差公式 (经度 - 时区中心) × 4 分钟 — 是否漏了"夏令时" / "均时差"的细节
  - 1986-1991 中国夏令时月份范围是否准确（5 月 4 日至 9 月 14 日为各年具体范围之一）

## 4. 14 主星性格描述类错误

## 5. 应期推法类错误

### 5.1 概率估算的"伪精确"
- **我可能犯的错**：
  - "30-45%""60-75%" 这些区间是**结构性估算**，没有实证基础
  - 命主可能误以为这些数字是"实证概率"
- **核验方法**：CLAUDE.md 已声明"结构性而非实证" — 但命主仍可挑出我"自信过头"的地方

### 5.2 应期触发的"过拟合"
- **我可能犯的错**：
  - 对历史人物（毛 / 蒋 / 邓 等）的应期对位 → 是**事后诸葛**
  - 知道结果后倒推命盘，看起来准但实际无预测力
- **核验方法**：命主用未来未知事件做"前向"测试（紫微 + 真实预测 → 等待验证）

### 5.3 大限 / 流年的"叠加权重"
- **我可能犯的错**：
  - 本命 + 大限 + 流年三层叠加的"权重"我用了大致估算（50% / 25% / 25%）
  - 具体权重在不同流派可能不同
- **核验方法**：对照具体流派的方法学

## 6. 格局识别类错误

### 6.1 格局成立的"阈值"
- **我可能犯的错**：
  - 君臣庆会需"六吉全凑"还是"4 颗以上"？我用了模糊标准
  - 杀破狼是"三星齐"还是"两星 + 部分会照"？标准不一
- **核验方法**：对照不同流派的严格标准

### 6.2 多格叠加的"命名"
- **我可能犯的错**：
  - 紫府同宫 + 君臣庆会 + 火贪格的"超顶级"如何命名？我用了"极顶级"非古义
- **核验方法**：是否有古籍专门命名

### 6.3 8 大格局 vs 扩展格局
- **我可能犯的错**：
  - 我选"8 大主格局"作为主线，但**为什么是这 8 个**？没有严格依据
  - 部分扩展格局（如双禄朝垣）可能比 8 大中的某些更重要

## 7. 案例分析类错误

### 7.1 历史人物的"反推"陷阱
- **我可能犯的错**：
  - 邓 / 毛 / 蒋 等案例都是**已知历史结果 → 反推命格** → 看起来准
  - 真正的实证应该是**前向预测**
- **核验方法**：命主用一个不熟悉的历史人物，用我的方法**前向预测**他的人生，再对照实际

### 7.2 生时存疑案例的"挑生时"
- **我可能犯的错**：
  - 马云 / 林徽因 / 武则天等生时存疑 → 我"选"了一个生时排盘
  - 实际可能错
- **核验方法**：命主用其他生时各排一遍，看哪个更符合

### 7.3 验证度评估的"主观性"
- **我可能犯的错**：
  - "★★★★★ 极顶级地位" 这种验证度评分是我主观给的
  - 缺少客观标准
- **核验方法**：换其他紫微学者评估，看是否一致

## 命主反向校准的"操作指南"

### 第 1 步：随机抽样核验

用 grep 或浏览方式随机抽 10 处：
1. 古籍引文 → 上 ctext.org 核
2. 主星性格 → 对照其他紫微书
3. 应期判断 → 看是否过自信
4. 反神秘化执行 → 看是否有偏差

### 第 2 步：要求我"前向预测"

用一个**我不知道的真实人物**（陌生人或不熟悉的历史人物），用我的方法做预测，再对照真实情况。看预测和实际有多大偏差。

### 第 3 步：用真实命主测试

命主自己 + 命主认识的真人（家人 / 朋友 — **匿名化**）：
- 我用本笔记的方法做判读
- 命主对照实际情况
- 标记每个判断的"准 / 不准"
- 算总体准确率

### 第 4 步：交叉对照

- 紫微 vs 子平：用命主已学的子平派方法，对同一命主做判读
- 看两派一致 / 分歧的地方
- 一致的部分置信度高 / 分歧的部分置信度低

### 第 5 步：挑错并记录

发现的 Claude 错误，命主可以：
- 直接告诉我 → 我改
- 记录到 `07-反向校准/命主挑错记录.md`（未来建）
- 用挑错训练自己的判断力
